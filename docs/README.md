## 기능 하나를 만드는 순서

1. **기획**: `기획/_템플릿.md`를 복사해 `기획/YYYY-MM-DD-이름.md`를 쓴다. 빈칸이 남으면 아직 시작할 때가 아니다.
2. **확인**: 기획서를 읽고 고칠 곳을 고친다. "완료 기준"에 동의하면 시작한다.
3. **구현 · 검증**: 완료 기준을 하나씩 확인한다 (테스트 · 화면 확인).
4. **기록**: `작업-기록.md`에 일지를 쓰고, 정한 게 있으면 `결정-기록.md`, 구조가 바뀌었으면 `프로젝트-이해.md`를 고친다.
5. **커밋**: 코드와 문서를 같은 커밋에 넣는다. 문서만 나중에 고치면 잊는다.
