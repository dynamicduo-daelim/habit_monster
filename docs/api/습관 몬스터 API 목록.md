# 습관 몬스터 API 목록

Oct 10, 2026 · @윤서

화면 명세(2026-10-10 확정 답변 반영) 기준으로 다시 뽑은 MVP API 목록입니다. 근거는 화면 명세, schema.sql, 04\_논리물리모델.md, 시스템 상세 설명서 v2입니다.

## 읽는 법

- 모든 요청은 로그인(JWT)과 "본인 데이터만 접근 가능" 확인이 공통입니다. 표의 "로그인 여부"는 이 공통 확인을 뜻합니다.
- "중복 요청 방지 키"는 클라이언트가 만든 UUID입니다. 같은 요청을 재전송해도 한 번만 처리됩니다.
- 하루의 경계는 새벽 4시(Asia/Seoul, 서버 계산)입니다.
- (미정) 표시는 아래 "아직 확인이 필요한 것"의 답에 따라 바뀌는 항목입니다.

**이번 버전에서 바뀐 규칙**

| 항목 | 이전 설계 | 확정 (2026-10-10) |
| --- | --- | --- |
| 성실볼 | 탐색 +1회 | 포획용. 던지면 100% 포획. 상점에서 골드로 구매 |
| 탐색 횟수 | 기본 3 + 볼 최대 2 | 하루 3회 고정 |
| 중복 몬스터 | 15G | 볼을 던져야 15G 지급 (같은 종 2마리 없음) |
| 등장 후 다시 탐색 | 해당 없음 | 등장한 몬스터는 사라지고 새로 탐색 |
| 초기 몬스터 | 사용자당 1마리 | 선택한 카테고리마다 1마리, 나중에 연 카테고리도 지급. 첫 대화 상대는 운동 카테고리 몬스터, 운동을 안 골랐으면 카테고리 순서상 첫 카테고리 몬스터 |
| 체크인 | 하루 1회 확정, 수정 불가 | 다시 체크 가능(오늘 기록만). 보상(골드·EXP·성실도)은 첫 제출만, 수정은 기록 수치와 통계 그래프에만 반영 |
| 체크인 입력 | 습관별 위젯 | 카테고리 탭마다 "했어/못했어" → 했어면 등록 단위의 선택지 |
| 출석체크 | 체크인 = 출석 | 출석체크와 체크인은 별개. 출석체크는 앱 접속 시 자동, 보상 없음 |
| 온보딩 저장 | 단계마다 저장 | 마지막 시작 버튼에서 한 번에 저장. 중간에 끄면 처음부터 |
| 목표 | 완료 후 취소·삭제 불가 | 동일. 삭제는 완료 전만 가능 |
| 카테고리 열기 | 해금권 자동 지급 | 도감 상단 슬롯 진행바가 차면 사용자가 열 카테고리를 고름 |

## 1. 회원·설정 (7개)

로그인·회원가입 화면은 제작 예정이고, 로그아웃·탈퇴는 상단 날짜 옆 설정 버튼 안에 있습니다.

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |
| --- | --- | --- | --- |
| 회원가입 버튼 | 이메일 회원가입 | 이메일 형식, 이미 가입된 이메일인지(소문자로 통일 후 비교), 비밀번호 빈 값 | 토큰, 온보딩 완료 여부 |
| 로그인 버튼 | 이메일 로그인 | 이메일·비밀번호 일치, 탈퇴 회원 아닌지 | 토큰, 온보딩 완료 여부 (미완료면 화면 1로) |
| 카카오/구글/애플 버튼 | 소셜 로그인 | 지원 중인 로그인 방식인지, 제공자 인증 토큰 유효 | 토큰, 신규 가입 여부, 온보딩 완료 여부 |
| (앱이 자동으로) | 토큰 재발급 | 리프레시 토큰 존재·만료·폐기 여부 | 새 토큰 |
| (앱이 자동으로) | 푸시 토큰 등록 | 로그인 여부, 플랫폼(ANDROID/IOS) | 성공 여부 |
| 설정 → 로그아웃 | 로그아웃 | 로그인 여부 | 성공 여부 (리프레시 토큰 폐기) |
| 설정 → 탈퇴 | 회원 탈퇴 | 로그인 여부, 이미 탈퇴한 계정이 아닌지 | 성공 여부 (인증 정보·토큰·AI 대화 삭제, 습관명·목표 텍스트 비움) |

## 2. 온보딩 — 화면 1\~4 (3개)

화면 1\~4에서 고른 내용은 앱이 들고 있다가 화면 4의 시작 버튼에서 한 번에 보냅니다. 그래서 습관 등록 버튼, 목표 추가 버튼은 서버를 부르지 않습니다. 박사 대사는 고정 문구라 앱에 둡니다.

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |
| --- | --- | --- | --- |
| 화면 2 열기 | 카테고리 목록 조회 | 로그인 여부 | 6개 카테고리(이름·속성·색·아이콘), 카테고리별 초기 몬스터 |
| 화면 3 열기 | 측정 단위·추천 습관 조회 | 로그인 여부 | 카테고리별 측정 단위(분·회·OX 등, 기본 목표, 입력 상한), 고를 수 있는 추천 습관 |
| 화면 4 시작 버튼 | 온보딩 완료 (일괄 제출) | 로그인 여부, 온보딩을 이미 마치지 않았는지, 카테고리 1\~3개, 습관 1\~5개이고 각 습관이 선택한 카테고리 것인지, 측정 단위가 그 카테고리 것인지, 습관 이름 빈 값(30자), 목표값 > 0 및 입력 상한, 기간(1주/1개월/3개월), 주간 목표 0\~3개·월간 0\~1개, 목표 이름 빈 값(50자) | 받은 초기 몬스터(카테고리마다 1마리, 필드 배치), 대화 상대(운동 카테고리 몬스터, 없으면 카테고리 순서상 첫 카테고리 몬스터), 등록된 습관·목표 |

## 3. 상단 바·메인 화면 — 화면 5 (13개)

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |
| --- | --- | --- | --- |
| 모든 화면 상단 | 상단 바 조회 | 로그인 여부 | 서버 기준 오늘 날짜, 연속 출석 일수, 골드, 성실볼 수, 남은 탐색 기회 |
| (앱이 자동으로) 앱 접속 시 | 출석체크 | 로그인 여부, 오늘 이미 출석했는지 | 연속 출석 일수 |
| 메인 진입 | 필드 몬스터 조회 | 로그인 여부 | 필드에 있는 몬스터(이름, 종, 레벨, 진화 단계 이미지) |
| 필드 몬스터 선택 → 팝업 | 몬스터 상세 조회 | 로그인 여부, 본인 몬스터인지 | 이름, 레벨, 이미지, 호감도, 카테고리·진화 단계·희귀도, EXP 진행바, 다음 진화까지 남은 레벨, 오늘 쓰다듬기·놀아주기 했는지, 대화 상대 여부 |
| 팝업 → 쓰다듬기 / 놀아주기 | 몬스터 교감 | 로그인 여부, 본인 몬스터인지, 오늘 같은 행동을 이미 했는지(하루 1회), 호감도 최대치 | 오른 호감도 수, 현재 호감도 |
| 팝업 → 간식 주기 | 간식 주기 (물약 사용) | 로그인 여부, 본인 몬스터인지, 하급·중급·상급 물약을 1개 이상 가졌는지, 최대 레벨이 아닌지, 중복 요청 방지 키 | 얻은 EXP, 레벨 전/후, 진화 여부, 남은 물약 수 |
| 팝업 → 말걸기 | 몬스터 대사 조회 | 로그인 여부, 본인 몬스터인지 | 호감도 단계에 맞는 대사 1개 |
| 팝업 → 가방에 넣기 / 가방 몬스터 탭 → 꺼내기 | 몬스터 위치 변경 | 로그인 여부, 본인 몬스터인지, 필드 마릿수 규칙(최소 1·최대 5) | 바뀐 위치 |
| 팝업 → 대화 상대로 | 대화 상대 변경 | 로그인 여부, 본인 몬스터인지 | 새 대화 상대 (1마리만 가능) |
| 상점 아이콘 | 상점 목록 조회 | 로그인 여부 | 판매 아이템(물약 3종, 성실볼)의 가격·효과, 내 골드 (상점 주인 대사는 앱 고정 문구) |
| 상점 → 구매 | 아이템 구매 | 로그인 여부, 판매 중인 아이템인지, 수량 > 0, 골드 충분(부족하면 거부), 중복 요청 방지 키 | 남은 골드, 가방 수량 |
| 가방 아이콘 | 가방 조회 | 로그인 여부 | 아이템 종류별 개수, 성실볼 수, 몬스터 탭(가방·필드 몬스터와 넣기/꺼내기 상태) |
| 스크롤탭 올리기 | 오늘 요약 조회 | 로그인 여부 | 습관 리스트, 오늘의 성실도(전체 진행바, 습관별 진행바), 오늘 획득 골드, 오늘 체크인 여부 |

오늘의 성실도는 보상 기준이라 첫 제출 값으로 보여줍니다. 다시 체크해서 바뀐 수치는 통계 그래프에만 반영됩니다.

## 4. 챗봇 — 화면 6 (7개)

**탐색 흐름**: 탐색하기 → 기회 1회 소모 → 꽝 / 신규 몬스터 등장 / 중복 몬스터 등장. 몬스터가 등장하면 볼 던지기(신규는 100% 포획, 중복은 15G) 또는 다시 탐색(등장한 몬스터는 사라지고 기회 1회 소모) 또는 그만. 볼이 없으면 던지기 대신 볼 사기. 탐색 버튼은 기회를 다 쓴 경우에만 막힙니다.

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |
| --- | --- | --- | --- |
| 챗봇 탭 열기 | 체크인 준비 조회 | 로그인 여부 | 카테고리 탭별 습관과 선택지(등록한 단위 기준: 분 단위 선택지 / O·X), 대화 상대, 호감도 단계, 오늘 이미 제출했다면 이전 답 |
| 상단 대화 상대 선택 | 대화 상대 변경 | (메인 팝업과 같은 API) 로그인 여부, 본인 몬스터인지 | 새 대화 상대 |
| 마지막 답변 후 (첫 제출) | 체크인 제출 | 로그인 여부, 오늘 아직 제출 전인지, 본인의 진행 중 습관인지, 선택값이 그 습관 단위의 선택지인지, "못했어"면 0, 중복 요청 방지 키 | 습관별 성실도·반영 여부(상위 3개), 획득 골드, 카테고리 EXP·레벨업, 기간 완주 보너스, 오늘 탐색 기회 3회 |
| 다시 체크 후 제출 | 체크인 수정 | 로그인 여부, 오늘 제출한 체크인이 있는지(어제 이전 기록은 수정 불가), 선택값 검사(위와 같음) | 바뀐 기록 수치 (골드·EXP·성실도 보상 변화 없음) |
| 챗봇 대사 표시 | 체크인 대사 요청 | 로그인 여부, 본인의 체크인 세션인지 | 대사 문구 (AI 실패·3초 초과 시 템플릿 대사) |
| 탐색하기 / 다시 탐색 | 탐색 실행 | 로그인 여부, 오늘 체크인 제출(보류: 전부 못했어인 경우), 남은 기회 ≥ 1, 중복 요청 방지 키 | 결과(꽝/신규 등장/중복 등장), 등장 몬스터, 남은 기회 |
| 던지기 | 몬스터 포획 | 로그인 여부, 방금 등장한 몬스터가 아직 유효한지(다시 탐색 전), 성실볼 ≥ 1, 중복 요청 방지 키 | 신규: 잡은 몬스터, 배치 위치(필드 5마리면 가방), 카테고리 슬롯 진행 변화 / 중복: 지급 골드 15G / 공통: 남은 성실볼 |

볼 사기 버튼은 메인의 아이템 구매 API를 그대로 씁니다. 그만 버튼은 서버를 부르지 않습니다.

## 5. 통계 — 화면 7 (1개)

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |
| --- | --- | --- | --- |
| 통계 탭 | 통계 조회 | 로그인 여부 | 연속 출석(현재·최장), 최근 14일 출석 여부, 최근 7일 요일별 성실도와 평균, 카테고리별 레벨(잠긴 카테고리 표시 / 열린 카테고리는 레벨·진행바·다음 레벨까지 남은 성실도·레벨업 골드) |

성실도 그래프는 다시 체크해서 바뀐 수치로 다시 계산한 값을 보여줍니다. 카테고리 레벨은 보상 기준(첫 제출)이라 바뀌지 않습니다. 화면이 세 덩어리라 응답이 커지면 셋으로 나눠도 됩니다.

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |

| 슬롯 진행바가 찼을 때 카테고리 고르기 | 카테고리 열기 | 로그인 여부, 열 수 있는 슬롯이 남았는지, 아직 안 연 카테고리인지 | 새로 연 카테고리, 그 카테고리의 초기 몬스터 |

## 7. 목표 — 화면 9 (5개)

| 화면의 행동 | 요청 이름 | 서버가 확인할 것 | 돌려주는 것 |
| --- | --- | --- | --- |
| 목표 탭 | 목표 목록 조회 | 로그인 여부 | 이번 주 주간 목표·이번 달 월간 목표(이름, 상세, 성공 시 골드, 완료 여부), 빈 슬롯 수 |
| 목표 추가 → 저장 | 목표 등록 | 로그인 여부, 주간 3개·월간 1개 한도, 이름 빈 값(50자), 상세 500자 | 등록된 목표 |
| 수정 → 저장 | 목표 수정 | 로그인 여부, 본인 목표인지, 완료 전인지 | 수정된 목표 |
| 삭제 | 목표 삭제 | 로그인 여부, 본인 목표인지, 완료 전인지 | 성공 여부 |
| 완료 라디오 버튼 | 목표 완료 | 로그인 여부, 본인 목표인지, 완료 전인지 | 지급 골드(주간 40G·월간 150G), 남은 골드 (해제 불가) |

완료한 목표는 수정·삭제·해제가 모두 막히므로, 화면에서도 완료 후에는 수정·삭제 버튼을 숨기거나 막아야 합니다.

## 8. 습관 관리 — 화면 추가 예정

온보딩 이후 습관을 추가·수정·종료하는 화면이 정해지면 채웁니다. 1주 습관은 7일 뒤 끝나므로 MVP에 꼭 필요합니다. 예상되는 API는 습관 목록 조회, 습관 등록, 습관 수정, 습관 종료입니다.
