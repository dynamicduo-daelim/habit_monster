# 제안: 온보딩 스타터는 1마리만

- 날짜: 2026-11-26 · 제안: 앱 쪽 (수연 · Claude) · 정할 사람: **윤서 (서버 · 명세 · DB 담당)**
- 관련: 사용자 피드백 "초반 루틴몬은 1마리로" (11-26) · 결정 D-96 · 명세 v10 `POST /onboarding` 응답 `starters`
- 상태: **제안** — 앱(시연 모드)만 바꿨고, 서버 · 명세는 그대로

## 지금
- `POST /onboarding`은 고른 카테고리마다 스타터를 1마리씩 준다 (`starters` 배열, 첫 파트너는 `partnerMonsterId`).
- 카테고리 3개를 고르면 처음부터 루틴몬이 3마리 → 처음 화면이 복잡하고, 탐색으로 만나는 재미가 줄어든다는 피드백.

## 바꾸자는 것
- 스타터는 **고른 첫 파트너(`partnerCategory`) 1마리만**. 안 보냈으면 첫 카테고리.
- 응답 모양은 그대로 두고 `starters`가 1개만 오면 된다 (앱은 이미 배열을 읽음).
- 나중에 카테고리를 열 때(`POST /categories/{code}/unlock`)의 스타터 지급은 그대로 (그 길의 첫 친구).
- 도감 · 카테고리 슬롯: 처음 가진 종이 1이 된다 → "도감 5/10/15마리마다 슬롯 +1"에 닿는 시점이 조금 늦어진다. 경제 영향 확인 필요.

## 앱
- 시연 모드: `GameState.completeOnboarding`이 첫 파트너 1마리만 준다 (11-26).
- 서버 모드: 서버가 바뀌면 앱은 고칠 것 없음.
