## 쓰는 법

위치: `docs/handoff/` (저장소 폴더 안). 새 Claude Code 세션을 저장소 폴더(또는 그 브랜치의 작업 폴더)에서 열고, 첫 메시지에 **두 파일을 붙여 넣거나** "`docs/handoff/00-공통.md`와 `03-1-온보딩.md`를 읽고 진행해줘"라고 한다:

1. `00-공통.md` — 매번 같이 (프로젝트 · 규칙 · 이미 만든 기반 · 함정)
2. 그 단계 파일 하나 — 예: `03-1-온보딩.md`

> 예: "아래 두 문서를 읽고 3-1단계를 진행해줘. 바꾸기 전에 계획부터 보여줘." + 두 파일 내용

한 세션에 한 단계만 시킨다. 단계가 끝나면 그 세션의 보고(한 일 · 확인한 것 · 정한 것)를 보고 커밋 · 푸시를 지시한다.

> 송윤서가 확인 · 숙지할 것, 결과 검토 방법: **`검토-체크리스트.md`**
