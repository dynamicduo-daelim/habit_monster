# [4단계] 습관 관리 · 목표 · 도감 · 카테고리 열기 · 통계

> 먼저 `00-공통.md`. 3-4 · 3-5까지 끝난 상태. API가 많으므로 **하위 단계 4-1 ~ 4-4로 나눠 커밋**하는 걸 추천 (계획 때 사용자에게 제안).

## 4-1. 습관 (명세 4장)
| API | 비고 |
| --- | --- |
| `GET /habits?status=ACTIVE,ENDED,STOPPED` | 생략 = ACTIVE,ENDED. `filledDays` · `periodDays` · `startDate`(현재 기간) |
| `POST /habits` | **`@Idempotent`**(A3). 이름 1 ~ 30자 · 목표값 범위 · 측정 항목이 그 카테고리 것(400), 열지 않은 카테고리 422 `CATEGORY_LOCKED`, ACTIVE + ENDED 5개 422 `HABIT_LIMIT` |
| `POST /habits/{id}/renew` | **`@Idempotent`**(A3). ENDED만(409 `HABIT_NOT_ENDED`). 새 `habit_period`(seq + 1, filled 0), 목표값 생략이면 이전 값 |
| `POST /habits/{id}/stop` | ACTIVE · ENDED 모두. 이미 STOPPED 409 `HABIT_ALREADY_STOPPED`. 진행 중이면 채운 날 · 받은 보상은 남고 보너스 없음 |

- **시작일 규칙**: 추가 · 연장 시 오늘 체크인을 안 냈으면 오늘, 냈으면 내일부터 (제출한 체크인에 끼어들지 않게)
- 그만둔 습관은 그날 다시 체크(PUT) 대상에는 남고 다음 날부터 빠짐 (3-3 규칙과 맞물림)
- 앱: 지금 "내 습관" 화면(`features/home/habit_manage_screen.dart`)은 추가 · 그만두기만 있음 → **기간 연장 화면**과 `/me/status`의 `endedHabitCount` 안내가 새로 필요 → **화면 흐름이 바뀌므로 `docs/기획/_템플릿.md`로 기획서를 먼저 쓰고 사용자 확인** (CLAUDE.md 원칙 ②). 디자인 기준은 `docs/design/prototype-source.dc.html` · `frontend/CLAUDE.md`
- 앱의 "습관 최소 1개" 규칙(D-14)과 명세(제한 없음, 대상 없으면 `NO_ACTIVE_HABIT`)가 다름 → 사용자에게 확인

## 4-2. 목표 (명세 8장)
| API | 비고 |
| --- | --- |
| `GET /goals` | 이번 주(월요일) · 이번 달(1일)만. 슬롯 · 보상 골드(`weekly_goal_gold` 40 · `monthly_goal_gold` 150) |
| `POST /goals` | **`@Idempotent`**(A3). 제목 1 ~ 50자 · 상세 0 ~ 500자, 슬롯 초과 422 `GOAL_SLOT_FULL` |
| `PATCH /goals/{id}` | 보낸 필드만, `null`이면 지움 (title은 null 400) — **"안 보냄"과 "null"을 구분**하는 요청 처리 필요 |
| `DELETE /goals/{id}` | 204 |
| `POST /goals/{id}/complete` | **`@Idempotent`**. 원장 `GOAL_WEEKLY`/`GOAL_MONTHLY`(ref `goal.id`). **등록한 날 완료 불가 → 409 `GOAL_TOO_EARLY`(C1, 새 오류 코드)** |
- 완료한 목표 수정 · 삭제 · 완료 → 409 `GOAL_COMPLETED`(트리거도 막음), 지난 기간 → 409 `GOAL_PERIOD_ENDED`, 남의 목표 404(C3)
- 유료 목표 칸은 MVP 밖 — 앱의 `unlockExtraWeeklySlot`은 서버 모드에서 숨기거나 로컬 유지 (사용자 확인)

## 4-3. 도감 · 카테고리 열기 (명세 7장)
| API | 비고 |
| --- | --- |
| `GET /dex` | `dexCount`(가진 종) · 다음 기준 · 남은 해금권, 카테고리별 `ownedCount` · `seenCount` · `totalCount` |
| `GET /dex/categories/{code}` | 종마다 `status`: OWNED(이미지 · 이름 · 레벨) / SEEN(이미지 · 이름) / UNKNOWN(**`imageKey`만** + 해금 정보, 이름 · speciesId 없음 — D6) |
| `GET /dex/species/{speciesId}` | 본 적 없는 종 404 `NOT_DISCOVERED` |
| `POST /categories/{code}/unlock` | **`@Idempotent`**. 해금권 사용 + `user_category`(TICKET) + 스타터(있으면) + `starter_grant`. 해금권 없음 422 `NO_TICKET`, 이미 연 카테고리 409 `ALREADY_OPENED` |
- **SEEN = `explore_log`에 그 종 ENCOUNTER 기록이 있음 (D-30, DB 변경 없음)**. 느리면 `explore_log (user_id, species_id)` 인덱스를 사용자에게 제안
- 앱: 도감 화면(`features/dex/dex_screen.dart`)에 SEEN 표시와 UNKNOWN 실루엣(같은 그림을 `ColorFiltered`로 검게) 추가 — 화면 변경이므로 기획서 먼저

## 4-4. 통계 (명세 6장)
| API | 비고 |
| --- | --- |
| `GET /stats` | 최근 14일 출석(`habit.attendance`) · 최근 7일 성실도(다시 체크한 최신 `overallRate`, 안 한 날 null) · 카테고리 레벨(`expRequired` — B2) |
