# [3-5단계] 상점 구매 · 물약 · 교감 · 말 걸기 · 필드/가방 · 대화 상대

> 먼저 `00-공통.md`. 3-2(조회)가 끝났으면 3-3 · 3-4와 따로 해도 된다. 명세 3장 해당 절을 읽고 시작.

## 범위
| API | 비고 |
| --- | --- |
| `POST /shop/purchases` | **`@Idempotent`**. 수량 1 ~ 99(400), 골드 부족 422 `NOT_ENOUGH_GOLD`. 합계는 서버가 계산(가격 스냅샷 `unit_price`). `shop.purchase`(idempotency_key) + inventory + 원장 `SHOP_PURCHASE`(ref `purchase.id`) 한 트랜잭션 |
| `POST /monsters/{id}/feed` | **`@Idempotent`**. 물약 없음 422 `NO_ITEM`, 최대 레벨 422 `MAX_LEVEL`. `item_consumption`(`FEED:<key>`) + EXP · 레벨 · 진화 + `monster.monster_growth_log` |
| `POST /monsters/{id}/affection` | `{action: PET\|PLAY}`. 오늘 이미 → 409 `ALREADY_DONE_TODAY` (`monster.affection_action`, 업무 날짜 — DB 유일 제약이 동시 요청도 막는지 확인). 최대면 gain 0 |
| `GET /monsters/{id}/line` | 호감도 단계별 대사 (`monster.species_line`) |
| `PATCH /monsters/{id}/location` | 필드 1마리일 때 넣기 · `field_max`일 때 꺼내기 → 422 `FIELD_LIMIT` |
| `PUT /me/partner` | 대화 상대 1마리 (`uq_user_partner`) — 바꿀 때 옛 상대 false → 새 상대 true 순서 |

공통: 남의 몬스터 → **404**(C3). 수치는 `BalanceConfig`(`affection_pet_gain` · `affection_play_gain` · `affection_max` · `monster_exp_per_level` · `monster_max_level` · `evolve_levels` · `field_max/min`).
잠금 순서: monster_user → inventory → wallet.

## 사용자에게 확인할 것
- **필드 끌기 호감도(D-20, 몬스터마다 하루 1번 +1)**: 앱에는 있는데 명세 · DB에 없다. `GameRepository.dragMonster`를 서버로 붙이려면 API(예: `affection`의 `action: DRAG`)와 DB(`affection_action` 행동 종류)를 더해야 한다 → 사용자에게 제안하고, 정해지기 전엔 로컬로 둔다
- 쓰다듬기 · 놀아주기에 **중복 방지 키**가 명세엔 없다(A3 결정: 앱이 `ALREADY_DONE_TODAY`를 성공처럼 처리). 그대로 갈지
- 앱 화면의 "간식 주기"가 물약 먹이기와 같은 기능인지 (명세 이름은 간식 = feed)

## 앱 작업
- `HttpGameRepository.buy` · `feed` · `pet` · `play` · `moveMonster` · `setPartner`를 서버로 (아이템 코드는 `Catalog.serverCodeOf`)
- 쓰다듬기 · 놀아주기: 서버 409 `ALREADY_DONE_TODAY`를 앱에선 "오늘은 이미 했어요"로 (토스트) — 실패처럼 보이지 않게
- 말 걸기를 서버 대사로 (지금은 앱 `Catalog` 대사)
- 응답으로 `GameState` 갱신 (골드 · 가방 수량 · 몬스터 레벨/호감도/위치/대화 상대)

## 테스트
- 구매: 정상 · 골드 부족 · 수량 범위 · 같은 키 재전송(골드 한 번만) · 다른 키 동시 두 건(잔액 음수 안 됨)
- 물약: 레벨업 · 진화 · 최대 레벨 · 물약 없음 · 재전송
- 교감: 하루 1회 · 다음 날 다시 가능 · 최대 호감도 gain 0
- 필드 제한 · 대화 상대 변경(가방에 있어도 됨) · 남의 몬스터 404

## 완료 기준
위 테스트 + 앱 상점 · 교감이 서버로 동작 + 문서
