# 결정 기록

무언가를 **정할 때마다** 한 건씩 맨 위에 추가한다. 발표에서 "왜 그렇게 했나요?"라는 질문에 답하기 위한 문서다.

쓰는 법:
- **무엇과 비교했는지**를 꼭 적는다. 비교 대상이 없으면 결정이 아니라 그냥 사실이다.
- 이유를 모르면 지어내지 말고 "이유 미기록"이라고 쓴다. 나중에 채운다.
- 결정이 뒤집히면 지우지 말고 새 건을 쓰고, 옛 건에 "→ D-00으로 바뀜"이라고 적는다.

```
## D-번호. 제목 (YYYY-MM-DD)
- 상황: 무엇을 정해야 했나
- 선택지: A / B / …
- 결정: 무엇으로 정했나
- 이유: 왜
- 영향: 바뀐 코드 · 문서, 남은 일
```

## D-18. 공식 스키마는 저장소 밖, 서버 추가분만 `backend/db/server_additions.sql` (2026-10-15)
- 상황: 로컬에서 PostgreSQL로 서버를 띄워야 하는데, 공식 `schema.sql`은 팀 규칙상 저장소에 넣지 않는다(10-10, DB 담당 원본은 공유 폴더). 서버는 중복 방지 키 테이블이 더 필요하다.
- 선택지: 공식 스키마를 저장소에 복사 / 공유 폴더를 Docker에 연결
- 결정: Docker Compose가 공유 폴더(`HM_DB_DIR`)를 읽기 전용으로 연결해 `schema.sql → seed.sql → server_additions.sql` 순서로 적용. 서버가 추가로 쓰는 테이블은 `server_additions.sql`에 두고 DB 담당에게 제안한다.
- 이유: 복사본을 두면 원본과 어긋난다(v1.4 → v1.5 때 실제로 겪음). 연결하면 항상 공유 폴더의 최신판을 쓴다.
- 영향: `backend/docker-compose.yml` · `backend/.env.example` · `backend/db/docker-init.sh` · `backend/db/server_additions.sql`. `docs/진행현황-및-계획.md` B6("v1.6을 레포에")은 이 결정으로 바뀜.

## D-17. 중복 방지 키: 요청 전체를 트랜잭션 하나로 + 행 잠금 (2026-10-15)
- 상황: API 명세 v4는 같은 키면 처음 결과를 돌려주라고 하지만, 처리 중에 서버가 죽거나 결과 저장과 실제 변경 중 하나만 남는 경우는 정하지 않았다 (검토 의견 A2).
- 선택지: ① 컨트롤러마다 직접 처리 / ② 필터에서 처리 + "처리 중" 표시를 60초 뒤 자동 해제 / ③ 필터에서 요청 전체를 트랜잭션으로 감싸고 키 행을 `FOR UPDATE NOWAIT`로 잠금
- 결정: ③. 2xx는 결과를 같은 트랜잭션에 저장해 함께 커밋, 4xx는 변경을 되돌리고 결과만 저장, 5xx는 저장하지 않음. 키가 필요한 API는 `@Idempotent`로 표시.
- 이유: ①은 API마다 같은 코드를 반복하고 빠뜨리기 쉽다. ②는 60초 안에 처리가 안 끝나면 두 번 실행될 수 있다. ③은 서버가 죽으면 DB가 잠금을 풀어 주고, 결과와 변경이 항상 같이 남거나 같이 사라진다.
- 영향: `idempotency/` 패키지, 테이블 `identity.idempotency_record`. 대가: 요청마다 DB 연결을 처음부터 끝까지 잡는다 (트래픽이 적은 지금은 문제 없음). 도메인 테이블의 `idempotency_key` UNIQUE는 마지막 방어선으로 그대로 둔다.

## D-16. 탈퇴 사용자는 요청마다 DB에서 확인해 막는다 (2026-10-15)
- 상황: access 토큰(JWT)은 서버에 저장하지 않아서, 탈퇴해도 만료(30분)까지 통과한다 (검토 의견 A1).
- 선택지: 만료까지 허용하고 문서에 적기 / access 토큰 수명을 5분으로 줄이기 / 요청마다 사용자 상태 확인
- 결정: 요청마다 `users`를 기본 키로 한 번 조회 (`UserGateFilter`). 같은 자리에서 온보딩 전 사용자도 막는다(403 `ONBOARDING_REQUIRED`).
- 이유: 기본 키 조회 1번은 싸고, 탈퇴 즉시 막힌다. 수명을 줄이면 재발급 요청만 늘고 완전히 막지는 못한다.
- 영향: `config/UserGateFilter.java`. 온보딩 전에 허용하는 경로 목록이 이 파일에 있다.
