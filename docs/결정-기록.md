# 결정 기록

무언가를 **정할 때마다** 한 건씩 맨 위에 추가한다. 발표에서 "왜 그렇게 했나요?"라는 질문에 답하기 위한 문서다.

쓰는 법:
- 송윤서가 정한(송윤서 작업에서 나온) 결정은 제목 끝에 `(송윤서)`를 붙인다.
- **무엇과 비교했는지**를 꼭 적는다. 비교 대상이 없으면 결정이 아니라 그냥 사실이다.
- 이유를 모르면 지어내지 말고 "이유 미기록"이라고 쓴다. 나중에 채운다.
- 결정이 뒤집히면 지우지 말고 새 건을 쓰고, 옛 건에 "→ D-00으로 바뀜"이라고 적는다.

```
## D-번호. 제목 (YYYY-MM-DD)
- 상황: 무엇을 정해야 했나
- 선택지: A / B / …
- 결정: 무엇으로 정했나
- 이유: 왜
- 영향: 바뀐 코드 · 문서, 남은 일
```
