# 출석을 "앱에 들어온 날" 기준으로

- 날짜: 2026-10-10
- 상태: 구현 완료 (아직 커밋 전)
- 관련: 결정 D-15 (D-07을 뒤집음), `기획/2026-10-10-튜토리얼-출석부-도움말.md`

## 1. 왜 바꾸나
- **문제**: 지금은 챗봇에서 습관 체크를 확정해야 출석이 된다. 앱에 들어왔는데도 출석부에 "아직 출석 전"이라고 나온다.
- **목표**: 앱에 들어오기만 하면 그날 출석이 된다.
- **하지 않는 것**: 출석 보상(골드), 출석 알림 창 · 토스트.

## 2. 누가 · 언제 쓰나
- 사용자: 매일 앱을 여는 사람.
- 사용 흐름: 로그인(또는 자동 로그인) 뒤 홈 화면이 뜨는 순간 그날 출석이 된다. 따로 누를 것은 없다.

## 3. 규칙
- **출석 = 그날 앱의 홈 화면에 들어온 것.** 하루에 한 번만 센다 (같은 날 여러 번 들어와도 1번).
- 상단 바의 "연속 N일"과 출석부의 "연속 N일"은 같은 숫자다. 둘 다 **접속 기준**으로 바뀐다. [가정] (전에는 체크인 기준이었다)
- 습관 체크와 출석은 이제 서로 다른 것이다.
  - 탐색 3회는 지금처럼 **체크인을 확정한 날에만** 생긴다 (바뀌지 않음).
  - 출석만 하고 습관 체크를 안 해도 연속 출석은 이어진다.
- 출석부를 열었을 때 오늘 습관 체크 전이면 "오늘 습관 체크하러 가기" 버튼이 보인다. [가정] (출석과 별개의 안내)
- 홈 출석 아이콘의 빨간 점은 없앤다. [가정] (전에는 "오늘 출석 전"이라는 뜻이었는데, 이제 들어오면 항상 출석이라 뜰 일이 없다)

## 4. 화면
- 출석부 문구: "오늘 출석 완료! 내일도 만나요." / 안내 "앱에 들어오면 그날 출석 도장이 찍혀요."
- 들어올 때 "출석 완료" 알림은 띄우지 않는다. [가정] (원하면 추가할 수 있다)

## 5. 예외 · 경계
- 온보딩 직후 처음 홈에 들어온 날도 출석 1일이다.
- **한계 (전부터 있던 것)**: 앱이 날짜를 저장하지 않아서 "하루가 바뀌었는지"를 모른다. 지금은 앱을 켤 때마다 "오늘 출석"으로 처리되고, 연속 일수는 샘플 값(11일)에 +1로 보인다. 진짜 연속 계산은 서버나 로컬 저장을 붙여야 된다.
- 서버를 붙였을 때: DB의 연속 출석(`habit.habit_user.current_streak` · `last_checkin_date`)은 **체크인 기준**이다. 접속 기준 연속 출석을 저장하려면 DB가 바뀌어야 한다 (`identity.users.last_active_date`는 마지막 접속일만 있다). → DB 담당에게 요청 (`backend/db/README.md`).
