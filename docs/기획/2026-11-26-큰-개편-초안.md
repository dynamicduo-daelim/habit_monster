## A. (12번) 홈 ↔ 습관 탭 바꾸기 — **구현 완료 (D-99)**: 탭 `오늘 · 챗봇 · 필드 · 도감 · 통계`, 가운데는 옛 홈 그대로, 오늘 탭은 랜덤 루틴몬 1마리 말풍선 · 아이콘 없음, 필드 바텀시트 삭제. 아래 안은 처음 초안 (바뀜)

### 왜
- 처음 들어왔을 때 **습관에 더 집중**되게. 지금 첫 화면(홈)은 필드 · 몬스터 · 아이콘이 많아 "오늘 뭘 하지?"가 바로 안 보인다.

### 안
- **첫 탭(앱을 열면 보이는 곳) = 오늘**: 위에 오늘 체크 수 · 성실도 → 습관 리스트(체크 아이콘) → 체크받기 버튼. 가운데에 **필드를 작게**(몬스터들이 돌아다니는 창, 누르면 크게) [가정]
- **가운데 탭 = 내 루틴몬**: 고른 루틴몬 **1마리**를 크게 — 이름 · 레벨 · 호감도 · 쓰다듬기 · 간식 · 놀아주기 · 말 걸기가 정리된 화면 (지금 교감 창을 탭 화면으로). 다른 루틴몬으로 바꾸기 [가정]
- 상점 · 가방 · 선물함 · 출석은 어디에? → 첫 탭 위쪽 작은 아이콘 줄 [가정]

### 정할 것
- [ ] 아래 탭 순서: `오늘(습관) · 챗봇 · 루틴몬 · 도감 · 통계`?
- [ ] 필드(여러 마리가 돌아다니는 곳)는 남길지 — 첫 탭 가운데 작은 창 / 루틴몬 탭 배경 / 없앰
- [ ] 바텀시트는 첫 탭이 습관 화면이 되면 필요 없음 → 없앨지

## B. (9번) 루틴몬 이름 짓기

- 교감 창(또는 루틴몬 탭)에서 연필 버튼으로 바꾸기. 최대 8자 [가정], 금지어는 서버 검사 [가정]

## C. (10번) 맵 여러 개

### 안
