# 홈 시트 습관 리스트에서 편집하기

- 날짜: 2026-11-16
- 상태: 기획 중 (사용자 확인 전)
- 관련: 브랜치 `feature/habit-sheet-edit` (예정, `dev`에서) · API 명세 v6 4장 습관 · 기존 화면 `HabitManageScreen`(홈 "습관" 아이콘)

## 1. 왜 만드나
- **문제**: 홈 아래 시트의 "습관 리스트"는 보기만 된다. 습관을 그만두거나 추가하려면 시트를 닫고 오른쪽 "습관" 아이콘으로 가야 해서, 리스트를 보다가 바로 고칠 수 없다 (사용자 11-16).
- **목표**: 리스트에서 습관을 눌러 상세를 보고, 그 자리에서 그만두기 · (기간이 끝났으면) 연장 · 새 습관 추가를 한다.
- **하지 않는 것**: 진행 중인 습관의 **목표값 · 이름 바꾸기** — 서버 규칙(명세 v6: "진행 중인 습관의 목표값은 바꿀 수 없습니다", 목표를 낮춰 점수를 쉽게 얻는 걸 막으려고)과 API가 없어서. 사용자 11-16 "지금 되는 것만".

## 2. 누가 · 언제 쓰나
- 매일 쓰는 사람이 홈 시트를 펼쳐 습관 리스트를 보다가.
- 사용 흐름:
  1. 리스트의 습관 줄을 누른다 → **습관 상세 창**(가운데 팝업).
  2. 상세에서 진행(예: 12/30일 막대) · 목표 · 기간 · 카테고리를 본다.
  3. [그만두기] → "정말 그만둘까요? 채운 날과 받은 보상은 남지만 기간 보너스는 없어요" 확인 → 그만둠.
  4. 기간이 끝난 습관이면 [연장하기] → 기간(7 · 30 · 100일) 고르기 + 목표값 조정(이때만 바꿀 수 있음) → 연장.
  5. 리스트 맨 아래 [+ 습관 추가] → 지금의 습관 추가 화면(무엇을 → 얼마나 → 언제까지)으로 바로.

## 3. 규칙
- 습관 줄 오른쪽에 `›` 표시 — 누를 수 있다는 뜻.
- 상세 창 내용: 카테고리 아이콘 · 이름 · 측정(예: 운동 시간 · 목표 30분) · 기간과 보너스(30일 ×1.5) · **진행 막대 n/기간일** · 상태(진행 중 / 기간 끝남).
- [그만두기]: 확인 창을 거친다 (명세: 앱은 그만두기 전에 확인 창). 마지막 남은 습관이면 버튼을 막고 "습관이 하나는 있어야 해요" 안내 (서버 422 `LAST_HABIT`과 같은 규칙).
- [연장하기]: 상태가 "기간 끝남"일 때만 보인다. 목표값은 생략하면 그대로. 연장하면 진행은 0일부터 다시 (서버 `POST /habits/{id}/renew`).
- [+ 습관 추가]: 습관이 이미 5개면 흐리게 + "습관은 5개까지예요".
- 오늘 체크인을 마친 뒤 그만두거나 추가하면, 오늘 기록은 그대로이고 내일부터 반영 (서버 시작일 규칙과 같음 — 앱은 안내 문구만).

## 4. 화면
- 시안에 없는 새 화면 (상세 창). 색 · 모양은 지금 홈 시트 · 팝업과 같게 (어두운 판, 버튼 모서리 10).
- 바뀌는 곳: 시트 "습관 리스트" 쪽 (줄 누르기 + `›` + 맨 아래 [+ 습관 추가]).

## 5. 예외 · 경계
- 습관 1개: 그만두기 막힘.
- 습관 5개: 추가 막힘.
- **시연 모드(서버 없음)**: 날짜가 흐르지 않아 "기간 끝남"이 생기지 않는다 → **[가정]** 시연용 샘플 습관 하나를 "기간 끝남"으로 두어 연장을 보여 줄 수 있게 한다 (테스트 영향 확인 필요).
- 서버 오류(409 이미 그만둠 등)는 기존 `runGameAction` 오류 토스트로.
- 좁은 화면(360폭)에서 상세 창이 넘치지 않게.

## 6. 다른 곳에 미치는 영향
- 앱:
  - `Habit` 모델에 진행(`filledDays` · `periodDays`)과 상태(`진행 중 / 기간 끝남`) 추가 — 서버 `GET /habits`에 이미 있는 값.
  - `GameRepository.renewHabit(habit, period, target)` 추가 (`LocalGameRepository` · `HttpGameRepository` 둘 다). 그만두기 · 추가는 이미 있음(`removeHabit` · `addHabit`).
  - `habit_sheet.dart`(리스트), 새 `habit_detail_popup.dart`, `HabitManageScreen`을 "추가 화면부터" 열 수 있게.
- 서버 · DB: 없음 (명세 v6 그대로).
- 문서: 프로젝트-이해(홈 시트), 작업-기록, 기획-변경-이력.
