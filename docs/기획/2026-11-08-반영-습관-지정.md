# 반영 습관 지정 (동점 처리 정리)

- 날짜: 2026-11-08
- 상태: **보류** — 방향(유저가 직접 지정)만 기울었고, 아래 8장 두 가지를 정한 뒤 구현한다
- 관련: `docs/할-일.md` "반영 습관 동점", 시뮬레이션 11-02 (`docs/작업-기록.md` 11-02), D-62, 시드 `daily_counted_habits`, 명세 v6 4-1

> 11-05 ~ 11-08에 사용자와 이야기한 내용을 정리해 둔 것이다. 체크인 대사 · 알림(5단계)을 먼저 하기로 해서 보류한다 (사용자 11-08).

## 1. 왜 만드나
- **문제**: 하루에 반영되는 습관은 점수 상위 3개(`daily_counted_habits`)이고, **동점이면 등록 순서**로 뽑는다. 습관 5개를 매일 목표만큼 하면 모두 20점이라 앞에 등록한 3개만 반영된다.
  - 시뮬레이션(11-02): 러닝 · 홈트 · 물 · 야식 · 7시간 수면이면 **수면 카테고리 경험치가 400일 동안 0**.
- **3개 상한이 있는 이유**: 습관을 많이 등록해 골드를 불리는 것을 막으려고 (`economy-v1.md`, 하루 최대 75G). 상한 자체는 그대로 두는 것이 전제다.
- **반영이 걸리는 곳** (시드 설명 "골드·카테고리 EXP·기간 점수 모두 적용"):
  - 골드 · 전체 성실도 · 카테고리 경험치 → 반영된 3개만
  - 기간 **채운 날**은 이미 반영 여부와 상관없이 "했어"면 +1 (B1). 그래서 기간을 영영 못 끝내는 문제는 없다
- **하지 않는 것**: 하루 상한 3개 · 75G 자체를 바꾸는 것.

## 2. 지금까지 나온 안 (순서대로)

| 안 | 내용 | 결과 |
| --- | --- | --- |
| A. 카테고리를 고르게 | 점수 → 동점이면 아직 안 뽑힌 카테고리 먼저 → 마지막으로 반영된 날이 오래된 습관 먼저 → 등록 순서 | Claude 제안. 사용자: "자꾸 걸린다" — 서버가 대신 고르는 규칙이 계속 늘어남 |
| B. 경험치는 전부 반영 | 골드 · 성실도는 상위 3개, 카테고리 경험치는 체크인한 습관 전부 | Claude 추천. 대가: 하루 경험치 총량이 3개분 → 5개분, 습관 많은 카테고리 레벨이 빨라짐 → 경험치 곡선 다시 시뮬레이션 필요 |
| **C. 유저가 직접 지정** | 반영할 습관(최대 3개)을 유저가 고른다. 서버는 고르지 않는다 | **사용자가 기울어진 안** (11-08): "전략적으로 하려는 유저가 있으면 시스템이 임의로 골라 올리지 않는 게 좋다" |

## 3. 규칙 (C안 — Claude 추천, 확정 아님)

| 항목 | 추천 | 이유 |
| --- | --- | --- |
| 고르는 때 | 습관 화면에서 미리 지정 (설정처럼). 체크인마다 고르지 않음 | 매일 고르면 챗봇 체크인 흐름이 번거로워짐 |
| 개수 | 최대 3개 (`daily_counted_habits` 그대로) | 골드 상한 75G 유지 |
| 적용 대상 | 골드 · 성실도 · 경험치 **모두** 지정한 습관 기준 | 하나는 유저 선택, 하나는 점수 순이면 규칙이 두 개라 설명이 어려움 |
| 기간 채운 날 | 지금처럼 "했어"면 전부 (B1) | 바뀌지 않음 |
| 바꾸는 시점 | 언제든 바꿀 수 있고 **다음 날부터** 적용 | 오늘 점수를 보고 반영 습관을 바꾸는 꼼수를 막음 |
| 처음 값 | 습관이 3개 이하면 자동으로 전부. 4번째부터는 추가할 때 "반영할까요?" | 대부분 유저는 신경 안 써도 됨 |
| 반영 습관을 그만두면 | 빈자리. 홈 알림 점으로 "다시 고르기" 안내 (서버가 대신 채우지 않음) | 서버가 채우면 다시 "임의 선택" |

- 이렇게 하면 **동점 처리 코드가 없어진다** (반영 = 지정했고 오늘 체크한 습관).

## 4. 화면
- 습관 화면(카드)에 "반영" 표시 · 켜고 끄기. 3개가 차 있으면 하나를 끄고 켜야 함.
- 체크인 결과에서 반영 안 한 습관은 "반영 안 함 — 골드 · 경험치 0"이 보여야 왜 0인지 안다.
- 시안에 없는 새 UI → 프론트 담당.

## 5. 예외 · 경계
- 지정한 습관을 오늘 "못했어" → 그 자리는 0점 (다른 습관이 대신 들어오지 않음)
- 습관이 3개 이하 → 전부 자동 반영이라 지금과 같음
- 연장 · 기간 완료(ENDED) 습관 → 지정 유지 여부 미정
