# 습관 기간 연장 · 서버로 습관 추가 · 그만두기

- 날짜: 2026-10-21
- 상태: **서버 완료 (10-23), 앱은 프론트 담당에게 요청** (`frontend/서버연동-메모.md` 1장). 3장 규칙은 사용자 확인(10-23, D-47), 4장 화면 · 8장은 아직 제안
- 관련: 4단계 4-1 (`docs/handoff/04-나머지화면.md`), API 명세 v5 4장, 기존 기획 `2026-10-10-습관-추가.md` · 결정 D-14(습관 최소 1개)

## 1. 왜 만드나
- **문제**: 서버는 습관이 기간(7 · 30 · 100일)을 다 채우면 `ENDED`(기간 완료)로 바꾸고 더 묻지 않는다. 그런데 앱에는 "기간 완료"를 보여 주는 곳도, 다시 시작(연장)하는 방법도 없다. 그래서 기간을 채운 습관은 체크인에서 조용히 사라진 것처럼 보인다. 또 서버 모드의 습관 추가 · 그만두기는 아직 앱 안에서만 바뀌어 다시 켜면 사라진다.
- **목표**: 기간을 채운 습관을 "내 습관"에서 알아보고, **연장**(기간 · 목표값을 다시 골라 새로 시작)하거나 **그만두기**를 고를 수 있다. 추가 · 그만두기 · 연장이 서버에 저장된다.
- **하지 않는 것**: 진행 중인 습관의 이름 · 목표값 바꾸기(명세: 연장할 때만 바꿈), 그만둔 습관 목록 보기 · 되살리기, 통계 화면(4-4).

## 2. 누가 · 언제 쓰나
- 사용자: 습관 하나를 7 · 30 · 100일 채운 사람. 그리고 습관을 더하거나 그만두려는 모든 사람.
- 상황: 체크인에서 마지막 날을 채우면 챗봇이 "기간 보너스 +N G"를 말한다 (3-3). 그 뒤 홈의 "습관" 아이콘에 표시가 붙는다.
- 사용 흐름 (연장):
  1. 홈 "습관" 아이콘 오른쪽 위에 알림 점이 보인다 (상점 아이콘의 알림 점과 같은 것).
  2. 누르면 "내 습관". 기간을 채운 습관 카드는 금색 테두리 + "기간 완료!" 띠, 아래에 [연장하기] · [그만두기].
  3. [연장하기] → 연장 창: "얼마나 더 해 볼까요?" 기간 7일 · 30일 · 100일(배수 ×1.2 · ×1.5 · ×2.0) 중 하나, 하루 목표(이전 값이 기본, −/+로 조절, O/X 습관은 없음) → [연장하기]
  4. 창이 닫히고 카드가 보통 카드로 돌아가 "0 / 30일" 부터. 알림 "다시 시작! 오늘부터 체크해요" (오늘 체크인을 이미 냈으면 "내일부터 체크해요").

## 3. 규칙
서버 규칙은 명세 v5 4장 그대로 + 사용자가 정한 "1개 남기기".

- 습관 상태는 셋: **진행 중**(ACTIVE) · **기간 완료**(ENDED, 연장 또는 그만두기를 기다림) · **그만둠**(STOPPED, 목록에서 빠짐).
- 기간 완료 습관은 챗봇이 묻지 않는다 (다음 날부터). 연장하면 다시 묻는다.
- 습관 개수: 진행 중 + 기간 완료를 합쳐 최대 5개 (`max_active_habits`). 기간 완료도 칸을 차지한다 → 꽉 찼으면 연장하거나 그만둬야 새로 추가할 수 있다.
- **습관은 1개 이상 남긴다** (사용자 결정 10-21, D-14): 진행 중 + 기간 완료가 1개뿐이면 그만둘 수 없다 → 서버 422 `LAST_HABIT`, 앱은 "습관은 1개 이상 있어야 해요" 알림 (지금과 같은 문구). 명세에도 적는다.
- **시작일**: 추가 · 연장할 때 오늘 체크인을 아직 안 냈으면 오늘부터, 이미 냈으면 내일부터 (명세 — 제출한 체크인에 끼어들지 않게).
- 연장: 기간을 새로 고르고, 하루 목표는 바꿀 수 있다(생략하면 이전 값). 채운 날은 0부터. 이전 기간의 기록 · 보상은 그대로 남는다.
- 그만두기: 진행 중 · 기간 완료 모두. 진행 중에 그만두면 채운 날 · 받은 보상은 남고 기간 보너스는 없다. 오늘 체크인한 뒤 그만두면 오늘의 "다시 체크"에는 남고 내일부터 빠진다.
- 추가: 이름 1 ~ 30자, 하루 목표 > 0 그리고 측정 항목의 입력 상한 이하, 연 카테고리만.

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 습관 최대 | 진행 중 + 기간 완료 5개 | `max_active_habits` (명세 4장) |
| 습관 최소 | 진행 중 + 기간 완료 1개 | D-14 · 사용자 결정 10-21 |
| 기간 | 7 · 30 · 100일 (×1.2 · ×1.5 · ×2.0) | `period_days` · `period_multiplier` |

## 4. 화면
디자인 시안에 없는 추가 화면이다 (기존 "내 습관"과 같은 어두운 테마 · 칸 크기를 따른다).

- **홈 "습관" 아이콘**: 기간 완료 습관이 있으면(`GET /me/status`의 `endedHabitCount` > 0) 오른쪽 위에 알림 점. [가정] 이미 상점 아이콘에 쓰는 네모 알림 점(`AppColors.notifyDot`, 12px)을 그대로 쓴다 — 숫자는 넣지 않음.
- **내 습관 카드**
  - 진행 중: 지금 모양 + 칩 하나 추가 "4 / 30일 채움" (서버 `filledDays` / `periodDays`). 시연 모드는 채운 날을 세지 않아서 이 칩을 숨긴다.
  - 기간 완료: 금색 테두리, 카드 위에 "기간 완료!" 띠, 칩 "30 / 30일 채움", 오른쪽 아래 버튼 둘 [연장하기](노란 버튼) · [그만두기](기존 모양).
  - 목록 순서: 기간 완료를 맨 위 (먼저 눈에 띄게) → 진행 중.
- **연장 창** (`PopupCard`, 그만두기 확인 창과 같은 틀)
  - 제목 "기간 연장", 습관 이름
  - "얼마나 더 해 볼까요?" + 기간 버튼 3개 (지금 추가 폼의 "언제까지" 버튼과 같은 모양 · 문구)
  - "하루 목표" + [−] 값 [+] (측정 항목의 단위 · 간격, O/X 습관은 이 줄 없음)
  - [연장하기] · [취소]
- 위 칸 수 표시(오른쪽 위 "3 / 5")는 진행 중 + 기간 완료를 센다.

## 5. 예외 · 경계
- 처음 쓰는 사용자: 기간 완료 습관이 없으니 배지 · 띠 · 연장 버튼이 안 보인다 (지금과 같음).
- 기간 완료 습관만 1개 남았을 때: 그만두기는 막히고(1개 남기기) 연장만 된다.
- 5칸이 꽉 찼고 그중 기간 완료가 있을 때: "+ 새 습관 추가" 대신 지금 안내("습관이 꽉 찼어요")에 "기간 완료 습관을 연장하거나 그만두면 자리가 생겨요"를 붙인다.
- 오늘 체크인을 낸 뒤 연장 · 추가: 내일부터 체크인 대상. 알림 문구로 알려 준다.
- 같은 날 같은 습관을 두 번 연장: 첫 연장 뒤에는 진행 중이라 두 번째는 서버 409 `HABIT_NOT_ENDED` → 앱 버튼이 이미 사라져 있음.
- 날짜가 바뀌는 순간: 서버 업무 날짜 기준. 앱 화면이 오래 열려 있었으면 서버 응답으로 고친다.
- 좁은 화면(360폭): 기간 완료 카드의 버튼 둘이 한 줄에 들어가는지 캡처로 확인.
- 시연 모드(서버 없음): 기간 완료가 생기지 않는다 (앱 로컬 규칙엔 기간 진행이 없음 — 3-3 기록). 추가 · 그만두기는 지금처럼 앱 안에서.
