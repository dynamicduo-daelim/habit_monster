- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `bright-reading-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 도서관 창가에서 조용히 앉아 있다 → 돌봄이가 옆에 앉는다 → 말없이 한참 있다 → "…옆에 있을게."가 처음으로 나온다
- 말버릇: 둥실 말이 적고 "…옆에 있을게." 정도만
