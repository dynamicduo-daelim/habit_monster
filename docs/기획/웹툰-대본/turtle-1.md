# turtle-1 · 오물 1화 「한 입 한 입」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `yum-rice-bowl` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 풀잎을 오물오물 먹고 있다 → 돌봄이가 와도 먹는 걸 멈추지 않는다 → 돌봄이가 천천히 같이 먹는다 → "…음, 맛있다." 첫 웃음
- 말버릇: 오물 "오물오물… 음, 맛있다." 먹으며 말한다

## 1컷 · 풀잎을 꼭꼭 씹는 오물
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-berry-bush`(임시, left 54%, bottom 12%, width 40%) · `village-path` 멀리(far, left -10%, bottom 4%, width 70%)
- 몬스터: 오물 (left 18%, top 44%, width 34%)
- 포즈/연출: 입을 우물거리며 풀잎을 꼭꼭 씹는 오물
- 말풍선: 「오물오물…」 (작게)
- 내레이션: 냠냠마을 아침 풀숲. 오물이 천천히 풀잎을 씹고 있었다.
- 효과음: 냠냠

## 2컷 · 멈추지 않는 한 입
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-berry-bush`(임시, left 6%, bottom 12%, width 36%)
- 몬스터: 오물 (left 38%, top 40%, width 34%)
- 포즈/연출: 돌봄이의 따뜻한 손 그림자가 다가와도 입을 쉬지 않음
- 말풍선: 「오물… 오물오물…」 (작게)
- 내레이션: 돌봄이가 다가와 앉아도, 먹는 걸 멈추지 않았다.
- 효과음: 없음

## 3컷 · 나란히 함께 먹기
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 14%, bottom 8%, width 72%) · `yum-rice-bowl`(임시, left 44%, bottom 18%, width 18%)
- 몬스터: 오물 (left 22%, top 32%, width 30%)
- 포즈/연출: 돌봄이의 손이 작은 그릇을 함께 놓음. 따뜻한 빛
- 말풍선: 「오물오물… 천천히 씹는 거야.」 (pop)
- 내레이션: 돌봄이도 곁에 나란히 앉아, 천천히 한 입을 베어 물었다.
- 효과음: 오물오물

## 4컷 · 첫 웃음
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `yum-rice-bowl`(임시, left 38%, bottom 14%, width 24%)
- 몬스터: 오물 (left 32%, top 34%, width 36%)
- 포즈/연출: `pop`으로 활짝 웃음. 반짝 3개
- 말풍선: 「오물오물… 음, 맛있다!」 (pop tail-right)
- 내레이션: 천천히 꼭꼭 씹자, 맛있는 미소가 번졌다.
- 효과음: 없음
