- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `hot-sunset-ridge` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `peacock_2.png`가 없음 → 1컷은 기본 `peacock.png`, 2 ~ 4컷은 기본 그림을 1.15배로 키우고 `glow`를 더함
- 줄거리 순서: 깃 끝이 노을색으로 물든다 → 친구들 앞에 서기가 무서워 뒷걸음질 → 돌봄이의 손 그림자가 등을 받친다 → 천천히 깃을 펴서 마을이 환해진다
- 말버릇: 놀빛 '…봐도 돼. 조금만.', 모닥이 '~끽', 콩지 '…콩, 콩.'

- 말풍선: 「…다들 보고 있어… 못 하겠어.」 (작게)
