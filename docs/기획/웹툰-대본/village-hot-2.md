# village-hot-2 · 따끈마을 2장 「줄넘기 소리」

- 마을: 따끈마을 · 운동 / 종류: 마을 장(chapter) / 열리는 때: 따끈마을 종을 3종(절반 올림) 잡을 때
- 표지 소품: `hot-jumprope-post` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 콩지는 줄넘기가 하고 싶지만 부끄러워 구석에서 센다 → 모닥이가 "일단 해보자끽!" 하며 줄 한쪽을 잡아 준다 → 홰치도 졸린 눈으로 박자를 세어 준다 → 셋이 한 번 넘고 운동장이 따뜻해진다
- 말버릇: 모닥이 '~끽', 콩지 '…콩, 콩.', 홰치 '꼬오—' 뒤 하품

## 1컷 · 구석에서 혼자 세는 콩지
- 하늘: morning / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `hot-jumprope-post`(임시, left 40%, bottom 12%, width 50%) · `stone-yard` 멀리(far, left -12%, bottom 2%, width 60%)
- 몬스터: 콩지 (left 10%, top 46%, width 24%) — 운동장 구석에서 줄 없이 손짓만
- 포즈/연출: 콩지가 작게 `hop`. 기둥에 줄이 늘어져 걸려 있음
- 말풍선: 「…하나, 둘, 셋… 콩, 콩.」 (작게)
- 내레이션: 콩지는 줄넘기가 하고 싶었다. 하지만 부끄러워 구석에서 혼자 세었다.
- 효과음: 콩콩

## 2컷 · 일단 해보자끽!
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-jumprope-post`(임시, left 62%, bottom 12%, width 36%) · `stone-yard`(left 6%, bottom 2%, width 70%)
- 몬스터: 모닥이 (left 30%, top 34%, width 22%) — 줄 한쪽을 쥐고 들어 보임 · 콩지 (left 8%, top 46%, width 20%)
- 포즈/연출: 모닥이가 `jump`로 달려와 줄을 잡고 흔듦. 콩지는 깜짝 놀라 귀가 쫑긋
- 말풍선: 「일단 해보자끽!」 (pop, 크게, 모닥이) · 「…콩?」 (작게, 콩지)
- 내레이션: 모닥이가 줄 한쪽을 대신 잡아 주었다.
- 효과음: 휘익—

## 3컷 · 졸린 눈으로 박자를 세어 준다
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-jumprope-post`(임시, left 62%, bottom 12%, width 36%) · `stone-yard`(left 6%, bottom 2%, width 70%)
- 몬스터: 홰치 (left 70%, top 20%, width 16%) 기둥 위 · 모닥이 (left 38%, top 38%, width 18%) · 콩지 (left 14%, top 46%, width 18%)
- 포즈/연출: 홰치가 하품하며 날개로 박자를 짚음. 줄이 `hop`하며 원을 그림. 콩지는 줄을 보며 숨을 고름
- 말풍선: 「꼬오— 하나, 둘… 하아암. 셋에 넘어.」 (작게, 홰치)
- 내레이션: 홰치도 졸린 눈으로 박자를 세어 주었다.
- 효과음: 휙, 휙

## 4컷 · 셋이 한 번 넘고, 운동장이 따뜻해진다
- 하늘: warm / 땅 높이 34% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom -2%, width 88%) · `hot-jumprope-post`(임시, left 78%, bottom 18%, width 22%)
- 몬스터: 콩지 (left 36%, top 14%, width 22%) 점프 중 · 모닥이 (left 8%, top 46%, width 18%) · 홰치 (left 74%, top 44%, width 16%)
- 포즈/연출: 콩지가 `jump`로 줄을 넘음. 착지한 돌바닥에서 `flare`로 붉은 온기가 퍼짐. `twinkle` 4개
- 말풍선: 「넘었다…콩, 콩! 셋이서 넘었어!」 (pop, 콩지)
- 내레이션: 셋이 함께 한 번 넘자, 운동장 돌바닥이 따뜻해졌다.
- 효과음: 탁!
