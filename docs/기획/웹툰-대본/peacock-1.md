# peacock-1 · 놀빛 1화 「접힌 깃털」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '친해진'(4 이상)
- 표지 소품: `hot-sunset-ridge` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `peacock.png`)
- 줄거리 순서: 깃을 꼭 접고 돌아서 있다 → 돌봄이가 노을을 같이 본다 → "…조금만 봐도 돼." 하고 깃을 한 줄 펴 본다 → 노을색이 번진다
- 말버릇: 놀빛 '…봐도 돼. 조금만.'

## 1컷 · 깃을 꼭 접고 돌아서 있는 놀빛
- 하늘: dusk / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `hot-sunset-ridge`(임시, left -6%, bottom 14%, width 112%) · 픽셀 구름 2개
- 몬스터: 놀빛 (left 14%, top 38%, width 28%) — 등을 돌리고 서 있음(좌우 반전)
- 포즈/연출: 깃을 몸에 바짝 붙임. 가만히 `shiver`(아주 작게)
- 말풍선: 「…」 (작게, 점 세 개)
- 내레이션: 노을이 지는 따끈마을. / 놀빛은 깃을 꼭 접은 채 돌아서 있었다.
- 효과음: 없음

## 2컷 · 돌봄이가 옆에서 노을을 본다
- 하늘: dusk / 땅 높이 24% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-sunset-ridge`(임시, left 0%, bottom 12%, width 100%)
- 몬스터: 놀빛 (left 22%, top 40%, width 26%) — 고개만 살짝 돌려 곁눈질
- 포즈/연출: 오른쪽에서 돌봄이의 손 그림자가 길게 드리워 놀빛 옆에 나란히 놓임(`warm`, left 54%, bottom 4%, width 36%). 말은 없음
- 말풍선: 「…저기, 뭘 보는 거야?」 (작게)
- 내레이션: 돌봄이는 아무 말 없이 곁에서 같이 노을을 보았다.
- 효과음: 없음

## 3컷 · 깃을 한 줄 펴 본다
- 하늘: dusk / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `hot-sunset-ridge`(임시, left -6%, bottom 14%, width 112%)
- 몬스터: 놀빛 (left 30%, top 36%, width 34%) — 깃 한 줄만 부채처럼 펴짐
- 포즈/연출: 깃 한 줄이 `reach`로 천천히 펴짐. 그 줄 끝에서 `twinkle` 한 번
- 말풍선: 「…조금만 봐도 돼.」 (pop, 작게 속삭이는 꼬리)
- 내레이션: 놀빛이 용기를 내어 깃을 딱 한 줄만 펴 보였다.
- 효과음: 사락

## 4컷 · 노을색이 번진다
- 하늘: warm / 땅 높이 24% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-sunset-ridge`(임시, left 0%, bottom 12%, width 100%)
- 몬스터: 놀빛 (left 28%, top 36%, width 36%)
- 포즈/연출: 펴진 깃 한 줄에서 노을색이 `flare`로 몸 전체에 번짐. 얼굴이 살짝 붉어짐
- 말풍선: 「…예쁘다고 해 줘서 고마워. 조금만 더 봐도 돼.」 (pop)
- 내레이션: 노을색이 깃을 따라, 천천히 번졌다.
- 효과음: 없음
