# chicken-1 · 홰치 1화 「졸린 새벽 알람」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '친해진'(4 이상)
- 표지 소품: `hot-roost-perch` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `chicken.png`)
- 줄거리 순서: 해 뜨기 전 "꼬오—" 크게 외친다 → 마을은 조용한데 자기만 하품한다 → 돌봄이가 조용히 인사해 준다 → 그제야 첫 해가 올라와 둘이 본다
- 말버릇: 홰치 '꼬오—' 큰소리 뒤에 하품. 돌봄이는 말하지 않는다. '새벽'은 하늘 dusk로 그린다

## 1컷 · 해 뜨기 전, 크게 외침
- 하늘: dusk / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-roost-perch`(임시, left 28%, bottom 14%, width 44%) · `village-square` 멀리(far, left -8%, bottom 6%, width 80%) · 픽셀 구름 1개
- 몬스터: 홰치 (left 34%, top 24%, width 30%) — 횃대 위
- 포즈/연출: `pop`으로 가슴을 활짝 펴고 부리를 위로. 외침 선(소리 선) 3줄
- 말풍선: 「꼬오—! 아침이다—!」 (pop, 크게, 오른쪽 위)
- 내레이션: 아직 해도 뜨기 전. / 홰치는 마을에서 제일 먼저 일어났다.
- 효과음: 꼬오오—!

## 2컷 · 마을은 조용, 자기만 하품
- 하늘: dusk / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `village-square`(left -6%, bottom 6%, width 92%) · `village-path` 멀리(far, left 60%, bottom 4%, width 36%)
- 몬스터: 홰치 (left 30%, top 36%, width 32%)
- 포즈/연출: `shiver`처럼 몸이 살짝 흔들리며 눈이 반쯤 감김. 닫힌 집 창문들은 어두움
- 말풍선: 「하아암… 아무도 안 일어났네…」 (작게)
- 내레이션: 마을은 쿨쿨 조용한데, / 깨운 홰치만 하품이 나왔다.
- 효과음: 하아암

## 3컷 · 돌봄이가 조용히 인사
- 하늘: dusk / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-roost-perch`(임시, left 4%, bottom 14%, width 36%) · `stone-yard`(left 20%, bottom -6%, width 84%)
- 몬스터: 홰치 (left 18%, top 38%, width 30%)
- 포즈/연출: 오른쪽 아래에서 돌봄이의 손 그림자가 `reach`로 올라와 살며시 손을 흔듦 (left 56%, bottom -2%, width 30%). 손 뒤로 따뜻한 빛 `warm`
- 말풍선: 「…꼬? 오…」 (작게)
- 내레이션: 돌봄이가 작은 손짓으로 조용히 인사해 주었다.
- 효과음: 없음

## 4컷 · 첫 해가 올라와 둘이 본다
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-sunrise-hill`(임시, left 0%, bottom 24%, width 100%) — 없으면 `stone-yard`로 대체하고 구석에 '임시' 표시
- 몬스터: 홰치 (left 26%, top 40%, width 28%)
- 포즈/연출: 지평선 위로 따뜻한 빛 덩어리가 `flare`로 올라옴. 오른쪽에 돌봄이의 빛 한 덩이(`warm`)가 홰치 곁에 나란히. 별 `twinkle` 3개
- 말풍선: 「꼬오… 같이 보니까 더 예쁘다.」 (pop)
- 내레이션: 그제야 첫 해가 올라왔다. 둘은 가만히 같이 보았다.
- 효과음: 없음
