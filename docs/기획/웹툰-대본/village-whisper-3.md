# village-whisper-3 · 소곤마을 3장 「꿈 사이로」

- 마을: 소곤마을 · 수면 / 종류: 마을 장(chapter) / 열리는 때: 소곤마을 종 4종 모두

- 진화 그림(_2): 쓰지 않음
