# turtle-3 · 오물 3화 「등딱지에 새싹」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 1차 진화 (Lv.10)
- 표지 소품: `yum-berry-bush` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `_2` 없음 → 3 · 4컷 `evolved=True` (1.15배 + 빛)
- 줄거리 순서: 등딱지에서 초록 새싹이 돋는다 → 오물이 놀라 오래 가만히 있는다 → 친구들이 물을 조금씩 준다 → 새싹이 한 뼘 자라 모두 신기해한다
- 말버릇: 오물 "오물오물…", 쪼르 "쪼르르~", 푸릇이 "푸릇…"

## 1컷 · 등딱지 위의 싹
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `tree-big`(left 58%, bottom 10%, width 40%)
- 몬스터: 오물 (left 28%, top 40%, width 38%)
- 포즈/연출: 등딱지 위에 연둣빛 새싹이 쏙 돋아남. 잎에 작은 빛
- 말풍선: 「오물…? 등에 뭐가 간질간질해.」 (작게)
- 내레이션: 매일 꼭꼭 씹어 먹던 어느 날 아침, 오물의 등딱지에서 파란 새싹이 돋았다.
- 효과음: 쏙

## 2컷 · 가만히 멈춘 오물
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `tree-big`(left 58%, bottom 10%, width 40%)
- 몬스터: 오물 (left 30%, top 40%, width 38%)
- 포즈/연출: 깜짝 놀라 다리를 쏙 넣고 가만히 얼어붙음. 식은땀
- 말풍선: 「오물… 움직이면 꺾일까 봐…」 (작게)
- 내레이션: 오물은 새싹이 다칠까 봐 한참을 꼼짝 않고 서 있었다.
- 효과음: 두근두근

## 3컷 · 친구들의 작은 물방울
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-berry-bush`(임시, left 74%, bottom 12%, width 24%) · `yum-water-pitcher`(임시, left 8%, bottom 14%, width 18%)
- 몬스터: 쪼르 (left 10%, top 36%, width 22%) · 푸릇이 (left 30%, top 42%, width 20%) · 오물 진화 (left 52%, top 28%, width 42%, evolved=True)
- 포즈/연출: 쪼르가 물을 살살 뿌려 주고 푸릇이가 잎을 토닥여 줌. 오물의 등딱지에 부드러운 빛
- 말풍선: 「쪼르르~ 물 한 방울!」 (pop tail-right) · 「푸릇… 안 다쳐, 괜찮아!」 (작게)
- 내레이션: 친구들이 다가와 새싹 위에 시원한 물방울을 톡톡 얹어 주었다.
- 효과음: 쪼르르

## 4컷 · 한 뼘 자란 새싹
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `haru-tree`(left 28%, bottom 10%, width 46%)

- 포즈/연출: 새싹이 쑥 자라며 반짝 4개. 오물이 활짝 웃음
- 말풍선: 「오물오물… 음, 새싹도 맛있는 물을 먹었나 봐!」 (pop tail-right)
- 내레이션: 쑥 자라난 등딱지 새싹을 보며, 모두가 함께 손뼉을 쳤다.
- 효과음: 반짝
