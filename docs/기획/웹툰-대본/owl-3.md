# owl-3 · 밤톨 3화 「넓어진 날개 밥상」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 1차 진화 (Lv.10)
- 표지 소품: `yum-rice-bowl` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `_2` 없음 → 3 · 4컷 `evolved=True` (1.15배 + 빛)
- 줄거리 순서: 날개가 넓어져 더 많은 그릇을 올린다 → 균형을 못 잡고 흔들린다 → 오물과 쪼르가 함께 받쳐 준다 → 큰 밥상이 완성되어 모두 환호한다
- 말버릇: 밤톨 "부엉. 밥은 먹었니?", 오물 "오물오물…", 쪼르 "쪼르르~"

## 1컷 · 넓어진 날개 위의 그릇들
- 하늘: warm / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `tree-big`(left 58%, bottom 8%, width 40%)
- 몬스터: 밤톨 (left 26%, top 32%, width 40%)
- 포즈/연출: 날개가 넓어지며 맛있는 국과 밥그릇 서너 개를 너끈히 올림. 날개에 작은 빛
- 말풍선: 「부엉! 이제 한 번에 다 나를 수 있겠어!」 (pop)
- 내레이션: 규칙적으로 식사를 챙겨 온 밤톨의 날개가 밥상만큼이나 널찍하게 자라났다.
- 효과음: 척척

## 2컷 · 뒤뚱뒤뚱 흔들리는 균형
- 하늘: warm / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%)
- 몬스터: 밤톨 (left 28%, top 30%, width 40%, `shiver`)
- 포즈/연출: 너무 욕심을 내어 그릇이 덜컹거리며 휘청거림. 식은땀
- 말풍선: 「부엉?! 어어, 그릇이 쏟아지겠다!」 (pop tail-right)
- 내레이션: 너무 많은 그릇을 올린 탓에 밤톨은 균형을 잃고 휘청거렸다.
- 효과음: 달그락!

## 3컷 · 친구들의 든든한 받침
- 하늘: dusk / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 14%, bottom 8%, width 72%)
- 몬스터: 밤톨 진화 (left 34%, top 26%, width 42%, evolved=True) · 오물 (left 10%, top 38%, width 22%) · 쪼르 (left 76%, top 38%, width 20%)
- 포즈/연출: 오물과 쪼르가 양옆에서 날개 끝을 함께 받쳐 줌. 밤톨의 날개에 은은한 빛
- 말풍선: 「오물오물… 천천히, 우리가 잡았어.」 (작게) · 「쪼르르~ 안 쏟아져!」 (작게)
- 내레이션: 오물과 쪼르가 얼른 달려와 넓은 날개 밑을 단단히 받쳐 주었다.
- 효과음: 턱

## 4컷 · 모두를 위한 큰 밥상
- 하늘: dusk / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `haru-tree`(left 28%, bottom 10%, width 46%) · `yum-rice-bowl`(임시, left 44%, bottom 20%, width 16%)
- 몬스터: 밤톨 진화 (left 36%, top 28%, width 44%, evolved=True) · 오물 (left 8%, top 46%, width 20%) · 쪼르 (left 80%, top 46%, width 18%)
- 포즈/연출: 식탁 위에 모든 그릇이 완벽하게 차려지고 다 함께 환호 (`jump`). 반짝 4개
- 말풍선: 「부엉! 밥은 먹었니? 이제 다 같이 먹자!」 (pop tail-right)
- 내레이션: 커다란 밥상이 차려지자 마을 친구들의 신나는 환호가 밤하늘을 채웠다.
- 효과음: 와아!
