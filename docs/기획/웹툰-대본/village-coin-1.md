# village-coin-1 · 알뜰마을 1장 「동전이 굴러간 자리」

- 마을: 알뜰마을 · 절약 / 종류: 마을 장(chapter) / 열리는 때: 알뜰마을 종 1종
- 표지 소품: `coin-tower` (임시)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 동전이 여기저기 흩어져 마을 장터가 휑하다 → 돌봄이가 동전 하나를 주워 건넨다 → 주민들이 하나씩 줍는다 → 작은 탑이 쌓인다

## 1컷 · 휑한 장터
- 하늘: high / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `coin-market-stall`(임시, 왼쪽) · `coin-market-stall`(임시, 오른쪽)
- 몬스터: 없음
- 포즈/연출: 반짝 5개(바닥에 흩어진 동전)
- 말풍선: 없음
- 내레이션: 동전이 여기저기 흩어져 장터가 휑했다.
- 효과음: 휑 (18)

## 2컷 · 한 닢 건네기
- 하늘: high / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `coin-market-stall`(임시, 멀리)
- 몬스터: 없음
- 포즈/연출: 돌봄이의 손 + 따뜻한 빛, 반짝 2개
- 말풍선: 없음
- 내레이션: 돌봄이가 동전 하나를 주워 건넸다.
- 효과음: 없음

## 3컷 · 하나씩 줍기
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `coin-market-stall`(임시, 멀리)
- 몬스터: 짤랑 · 든든 · 꼼꼼 · 차곡 (각 너비 16%) — `hop`
- 포즈/연출: 반짝 3개
- 말풍선: 「여기 하나!」 (작게)
- 내레이션: 주민들이 하나둘 동전을 주웠다.
- 효과음: 없음

## 4컷 · 작은 탑
- 하늘: warm / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `coin-tower`(임시, 가운데)
- 몬스터: 짤랑 (left 8%, top 46%, width 16%) · 차곡 (left 74%, top 44%, width 16%) — `warm`
- 포즈/연출: 따뜻한 빛, 반짝 3개
- 말풍선: 없음
- 내레이션: 작은 동전 탑이 쌓였다.
- 효과음: 없음
