# village-hot-3 · 따끈마을 3장 「함께 데운 아침」

- 마을: 따끈마을 · 운동 / 종류: 마을 장(chapter) / 열리는 때: 따끈마을 종 5종 전부 잡을 때
- 표지 소품: `hot-sunrise-hill` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (다섯 마리 모두 기본 그림)
- 줄거리 순서: 길쭉이 온 마을 스트레칭을 이끌고, 놀빛은 떨며 맨 앞에 선다 → 서툰 몸짓에도 모두 박수를 친다 → 하루나무 잎끝이 붉어지고 → 다섯이 나란히 첫 해를 본다
- 말버릇: 길쭉 '쭈우우욱… 천천히 해도 돼', 놀빛 '…봐도 돼. 조금만.', 모닥이 '~끽', 콩지 '…콩, 콩.', 홰치 '꼬오—' 뒤 하품

## 1컷 · 길쭉이 이끄는 마을 스트레칭
- 하늘: morning / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom 2%, width 88%) · `hot-stretch-mat`(임시, left 40%, bottom 8%, width 50%)
- 몬스터: 길쭉 (left 30%, top 14%, width 44%) 앞쪽 가운데 · 모닥이 (left 6%, top 48%, width 16%) · 콩지 (left 24%, top 52%, width 15%) · 홰치 (left 76%, top 48%, width 15%)
- 포즈/연출: 길쭉이 `reach`로 위로 쭈욱. 나머지가 따라 팔을 올림. 홰치는 하품하며 꾸벅
- 말풍선: 「쭈우우욱… 천천히 해도 돼. 다 같이.」 (pop, 길쭉)
- 내레이션: 길쭉이 온 마을 스트레칭을 이끌었다.
- 효과음: 쭈우욱

## 2컷 · 떨면서 맨 앞에 선 놀빛
- 하늘: morning / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom 2%, width 92%)
- 몬스터: 놀빛 (left 32%, top 34%, width 34%) 맨 앞 · 길쭉 · 모닥이 · 콩지 · 홰치는 뒤에 작게 줄 서 있음(left 6% · 24% · 66% · 82%, top 18%, width 12%)
- 포즈/연출: 놀빛이 `shiver`하며 깃을 어색하게 흔듦. 몸짓이 서투름
- 말풍선: 「…봐도 돼. 조금만…」 (작게)
- 내레이션: 놀빛은 떨면서도 맨 앞에 서서 몸을 움직였다.
- 효과음: 파르르

## 3컷 · 서툰 몸짓에도 박수
- 하늘: high / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom 2%, width 88%)
- 몬스터: 놀빛 (left 38%, top 36%, width 24%) 가운데 · 모닥이 (left 6%, top 42%, width 16%) · 콩지 (left 22%, top 46%, width 14%) · 홰치 (left 66%, top 44%, width 14%) · 길쭉 (left 78%, top 50%, width 20%)
- 포즈/연출: 모두가 `hop`하며 박수. 놀빛은 놀라 눈이 동그래짐. 박수 위로 `twinkle`
- 말풍선: 「최고다끽!」 (작게, 모닥이) · 「…콩, 콩!」 (작게, 콩지)
- 내레이션: 서툰 몸짓에도, 모두가 박수를 쳤다.
- 효과음: 짝짝짝

## 4컷 · 다섯이 나란히 첫 해를
- 하늘: warm / 땅 높이 36% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-sunrise-hill`(임시, left 0%, bottom 22%, width 100%) · `haru-tree`(left 62%, bottom 10%, width 34%, 잎끝이 붉음)
- 몬스터: 모닥이 (left 8%, top 46%, width 15%) · 콩지 (left 24%, top 48%, width 14%) · 홰치 (left 40%, top 46%, width 14%) · 길쭉 (left 54%, top 52%, width 20%) · 놀빛 (left 76%, top 44%, width 15%) — 다섯이 한 줄로 나란히, 모두 해 쪽을 바라봄
- 포즈/연출: 하루나무 잎끝이 `flare`로 붉어짐. 지평선 위 첫 해가 떠오름. 손 그림자는 화면 아래 가장자리에서 가만히 함께 있음
- 말풍선: 「따뜻하다끽…」 (작게, 모닥이) · 「…콩.」 (작게, 콩지) · 「꼬오— 하아암.」 (작게, 홰치) · 「쭈우욱… 좋다.」 (작게, 길쭉) · 「…봐도 돼. 같이.」 (작게, 놀빛)
- 내레이션: 다섯이 나란히 서서, 함께 데운 아침의 첫 해를 보았다.
- 효과음: 없음
