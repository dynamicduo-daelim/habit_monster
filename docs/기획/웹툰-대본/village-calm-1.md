# village-calm-1 · 잔잔마을 1장 「시끄러운 개울」

- 마을: 잔잔마을 · 명상 / 종류: 장(chapter) / 열리는 때: 잔잔마을 종 1종
- 표지 소품: `calm-stream` (임시)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 개울이 졸졸이 아니라 출렁출렁 시끄럽다 → 돌봄이가 눈을 감고 숨을 크게 쉰다 → 물결이 천천히 가라앉는다 → 주민들이 따라서 숨을 쉰다
- 말버릇: 퐁글 "후우… 퐁글퐁글."

- 배경 소품: `calm-stream`(임시, left 0%, bottom 8%, width 100%)
- 몬스터: 퐁글 · 물멍 · 보슬 · 나울 실루엣 (각 width 14%, top 44%)
- 말풍선: 「왜 이렇게 시끄럽지…」 (작게)
- 내레이션: 잔잔마을 개울이 졸졸이 아니라 출렁출렁 시끄러웠다.
- 효과음: 출렁 (20)
