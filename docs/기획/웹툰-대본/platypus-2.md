# platypus-2 · 쪼르 2화 「물 2L 도전」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `yum-water-pitcher` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 쪼르가 하루 물 마시기 표를 만든다 → 돌봄이와 번갈아 체크한다 → 중간에 쪼르가 배불러 잠든다 → 돌봄이가 이어서 표를 채워 준다
- 말버릇: 쪼르 "쪼르르~ 한 잔 더!"

- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-water-pitcher`(임시, left 74%, bottom 20%, width 16%)
- 몬스터: 쪼르 (left 20%, top 34%, width 34%)
- 포즈/연출: 큰 종이에 물방울 여덟 개를 그려 둔 표를 당당하게 펼침
- 말풍선: 「쪼르르~ 오늘 목표는 물 여덟 잔, 딱 2L야!」 (pop)
- 내레이션: 쪼르가 커다란 종이에 정성껏 물 마시기 체크표를 그렸다.
- 효과음: 쓱쓱

- 말풍선: 「쪼르르~ 벌써 네 잔째! 아주 좋아!」 (pop tail-right)
