# rabbit-2 · 콩지 2화 「셋까지 세는 용기」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '단짝'(7 이상)
- 표지 소품: `hot-jumprope-post` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `rabbit.png`)
- 줄거리 순서: 모닥이가 같이 넘자고 한다 → 콩지가 귀를 접고 망설인다 → 돌봄이가 "셋까지만" 한다 → 셋을 넘고 발끝이 따끈해진다
- 말버릇: 콩지 '…콩, 콩.', 모닥이 '~끽'. 돌봄이는 말하지 않으므로 "셋까지만"은 손가락 셋을 펴 보이는 그림 + 내레이션으로 처리한다

## 1컷 · 모닥이가 같이 넘자고 한다
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-jumprope-post`(임시, left 2%, bottom 18%, width 32%) · `village-square` 멀리(far, left 36%, bottom 8%, width 72%)
- 몬스터: 모닥이 (left 58%, top 36%, width 26%) · 콩지 (left 14%, top 46%, width 24%)
- 포즈/연출: 모닥이 `jump`로 들어와 줄 한쪽 끝을 번쩍 듦. 콩지는 한 발 뒤로 물러섬
- 말풍선: 「같이 넘자끽! 일단 해보자끽!」 (pop, 모닥이)
- 내레이션: 줄넘기 소리가 나자, 모닥이가 달려왔다.
- 효과음: 타다닥

## 2컷 · 귀를 접고 망설인다
- 하늘: high / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-jumprope-post`(임시, left 2%, bottom 18%, width 32%)
- 몬스터: 콩지 (left 30%, top 38%, width 34%)
- 포즈/연출: 콩지 가까이 클로즈업. `shiver`, 귀를 접고 발끝을 꼼지락. 식은땀 한 방울(`drop`)
- 말풍선: 「…콩, 콩. 틀리면… 어떡해.」 (작게)
- 내레이션: 콩지의 귀가 슬금슬금 접혔다.
- 효과음: 꼼지락

## 3컷 · 돌봄이가 손가락 셋을 펴 보인다
- 하늘: warm / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 6%, bottom 0%, width 88%) · `hot-jumprope-post`(임시, left -4%, bottom 20%, width 26%)
- 몬스터: 콩지 (left 20%, top 40%, width 28%) · 모닥이 (left 66%, top 46%, width 20%, 줄 끝을 든 채)
- 포즈/연출: 아래에서 돌봄이의 손이 `reach`로 올라와 손가락 셋을 폄 (left 34%, bottom -2%, width 34%). 손 뒤로 따뜻한 빛 `warm`
- 말풍선: 「…셋, 까지만?」 (작게, 콩지)
- 내레이션: 돌봄이가 손가락 세 개를 가만히 펴 보였다. 셋까지만, 이라고.
- 효과음: 없음

## 4컷 · 셋을 넘고 발끝이 따끈
- 하늘: warm / 땅 높이 40% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 10%, bottom -20%, width 80%)
- 몬스터: 콩지 (left 34%, top 26%, width 32%) 가운데 · 모닥이 (left 4%, top 44%, width 20%) 줄 한쪽
- 포즈/연출: 콩지 `hop`(줄을 넘는 한 번). 발끝에 따끈한 빛 `flare`, 별 `twinkle` 3개
- 말풍선: 「…콩, 콩, 셋!」(pop, 콩지) · 「넘었다끽!」(작게, 모닥이)
- 내레이션: 하나, 둘, 셋. 콩지의 발끝이 따끈해졌다.
- 효과음: 탁, 탁, 탁!
