# hedgehog-1 · 푸릇이 1화 「야식 냄새」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `yum-water-pitcher` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 밤에 뒤척이며 배고픈 소리가 난다 → 가시가 쭈뼛 선다 → 돌봄이가 따뜻한 물을 건넨다 → 한 모금 마시고 "푸릇… 참을 수 있어." 한다
- 말버릇: 푸릇이 "푸릇… 참아야 해!" 혼잣말

## 1컷 · 밤의 꼬르륵
- 하늘: dusk / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `village-square` 멀리(far, left -10%, bottom 4%, width 70%)
- 몬스터: 푸릇이 (left 28%, top 44%, width 34%)
- 포즈/연출: 이불 속에서 뒤척이며 배를 감싸 쥠. 식은땀
- 말풍선: 「푸릇… 배고파… 맛있는 냄새가 나는 것 같아…」 (작게)
- 내레이션: 달빛이 내린 밤. 어디선가 맛있는 냄새가 솔솔 풍겨 왔다.
- 효과음: 꼬르륵

## 2컷 · 바짝 선 가시
- 하늘: dusk / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `tree-big`(left 58%, bottom 8%, width 40%)
- 몬스터: 푸릇이 (left 26%, top 38%, width 38%)
- 포즈/연출: `shiver`하며 온몸의 가시를 뾰족하게 바짝 세움
- 말풍선: 「푸릇… 안 돼, 참아야 해!」 (pop tail-right)
- 내레이션: 야식의 유혹에 마음이 흔들리자, 가시가 바짝 곤두섰다.
- 효과음: 찌릿

## 3컷 · 따뜻한 물 한 잔
- 하늘: dusk / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-water-pitcher`(임시, left 6%, bottom 12%, width 20%)
- 몬스터: 푸릇이 (left 38%, top 38%, width 34%)
- 포즈/연출: 돌봄이의 손이 따뜻한 찻잔을 건넴. 은은하고 따뜻한 빛
- 말풍선: 「푸릇… 물이네? 따뜻하다…」 (작게)
- 내레이션: 그때 돌봄이가 김이 모락모락 나는 따뜻한 물 한 잔을 건넸다.
- 효과음: 모락모락

## 4컷 · 참을 수 있어
- 하늘: dusk / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-water-pitcher`(임시, left 14%, bottom 12%, width 20%)
- 몬스터: 푸릇이 (left 32%, top 34%, width 36%)
- 포즈/연출: 가시가 보들보들 가라앉고 편안하게 미소 지음. 반짝 2개
- 말풍선: 「푸릇… 꿀꺽. 참을 수 있어!」 (pop tail-right)
- 내레이션: 따뜻한 물 한 모금에 배 속이 편안해지며, 가시도 부드럽게 누웠다.
- 효과음: 후우
