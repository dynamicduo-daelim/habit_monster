# platypus-1 · 쪼르 1화 「쪼르르 한 잔」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `yum-water-pitcher` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 물병을 들고 돌아다니며 모두에게 권한다 → 돌봄이에게도 한 잔 따라 준다 → 마시자 "잘했어!" 하며 박수 → 쪼르의 부리가 반짝인다
- 말버릇: 쪼르 "쪼르르~ 한 잔 더!"

## 1컷 · 물 마시기 감독관
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `village-path`(left 0%, bottom 4%, width 100%)
- 몬스터: 쪼르 (left 28%, top 36%, width 34%, `hop`)
- 포즈/연출: 시원한 물병을 들고 마을을 씩씩하게 누비는 쪼르
- 말풍선: 「쪼르르~ 다들 물 한 잔씩 마실 시간!」 (pop)
- 내레이션: 냠냠마을의 아침. 쪼르가 물병을 들고 신나게 돌아다녔다.
- 효과음: 찰랑찰랑

## 2컷 · 시원한 물 한 잔
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-water-pitcher`(임시, left 6%, bottom 12%, width 22%)
- 몬스터: 쪼르 (left 38%, top 34%, width 34%)
- 포즈/연출: 돌봄이의 컵에 맑은 물을 쪼르르 가득 따라 줌
- 말풍선: 「쪼르르~ 아침엔 시원한 물 한 잔이 보약이야!」 (pop tail-right)
- 내레이션: 돌봄이를 발견한 쪼르가 얼른 다가와 컵에 맑은 물을 따랐다.
- 효과음: 쪼르르

- 포즈/연출: 돌봄이의 손이 컵을 비우자 쪼르가 신나서 손뼉을 침

- 내레이션: 돌봄이가 물을 한 컵 시원하게 들이켜자, 쪼르가 환호하며 박수를 쳤다.
