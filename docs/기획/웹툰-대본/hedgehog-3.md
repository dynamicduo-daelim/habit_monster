# hedgehog-3 · 푸릇이 3화 「가시가 잎사귀처럼」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 1차 진화 (Lv.10)
- 표지 소품: `yum-berry-bush` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `_2` 없음 → 3 · 4컷 `evolved=True` (1.15배 + 빛)
- 줄거리 순서: 가시 끝이 연두색으로 변한다 → 다칠까 봐 걱정하다 친구를 살짝 안아 본다 → 하나도 안 따갑다 → 푸릇이가 눈물이 글썽해 웃는다
- 말버릇: 푸릇이 "푸릇… 참아야 해!", 다래 "찾았다!"

## 1컷 · 연둣빛으로 물든 가시
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `tree-big`(left 56%, bottom 8%, width 42%)
- 몬스터: 푸릇이 (left 28%, top 38%, width 36%)
- 포즈/연출: 가시 끝이 부드러운 연둣빛으로 물들며 빛남 (`twinkle`)
- 말풍선: 「푸릇…? 가시 끝이 부드러운 초록색이야.」 (작게)
- 내레이션: 매일 신선한 채소를 맛있게 챙겨 먹자, 가시 끝이 연둣빛으로 물들었다.
- 효과음: 반짝

## 2컷 · 다칠까 봐 조심조심
- 하늘: morning / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `village-path`(left 0%, bottom 4%, width 100%)
- 몬스터: 푸릇이 (left 24%, top 38%, width 32%, `shiver`) · 다래 (left 64%, top 36%, width 26%)
- 포즈/연출: 다래가 다가오자 푸릇이가 가시로 다칠까 봐 웅크리며 뒷걸음질
- 말풍선: 「푸릇… 오지 마, 내 가시가 찌를지도 몰라!」 (pop) · 「괜찮아!」 (작게)
- 내레이션: 푸릇이는 친구가 다칠까 봐 조심스레 몸을 움츠렸다.
- 효과음: 주춤

## 3컷 · 살포시 안아 본 순간
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-berry-bush`(임시, left 74%, bottom 12%, width 24%)
- 몬스터: 푸릇이 진화 (left 32%, top 28%, width 40%, evolved=True) · 다래 (left 52%, top 32%, width 26%)
- 포즈/연출: 푸릇이가 용기 내어 다래를 살포시 안음. 가시가 부드러운 잎사귀처럼 감싸 안음. 따뜻한 빛
- 말풍선: 「푸릇… 어라? 하나도 안 따가워?」 (pop tail-right) · 「폭신폭신해!」 (작게)
- 내레이션: 가시는 더 이상 날카롭지 않았다. 부드러운 나뭇잎처럼 포근했다.
- 효과음: 포근

## 4컷 · 글썽이며 번진 미소
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `haru-tree`(left 28%, bottom 10%, width 46%)
- 몬스터: 푸릇이 진화 (left 36%, top 28%, width 42%, evolved=True) · 다래 (left 12%, top 44%, width 22%, `hop`) · 오물 (left 78%, top 46%, width 20%)
- 포즈/연출: 푸릇이 눈가에 감동의 눈물이 글썽이며 활짝 미소. 반짝 4개
- 말풍선: 「푸릇… 이제 모두를 꼭 안아 줄 수 있어!」 (pop tail-right)
- 내레이션: 마침내 친구를 마음껏 안아 줄 수 있게 된 푸릇이는 눈물겹게 활짝 웃었다.
- 효과음: 와아
