# monkey-2 · 모닥이 2화 「일단 해보자끽」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '단짝'(7 이상)
- 표지 소품: `stone-yard`
- 진화 그림(_2): 쓰지 않음 (기본 `monkey.png`)
- 줄거리 순서: 스트레칭 첫날 너무 빨리 해서 혼자 넘어진다 → 돌봄이와 같은 속도로 천천히 따라 한다 → 같이 끝내고 둘이 엉덩방아를 찧으며 웃는다
- 말버릇: 모닥이 '~끽'. 돌봄이는 말하지 않고 손 · 빛으로만 나온다

## 1컷 · 스트레칭 첫날, 너무 빠르게
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom 2%, width 92%) · 픽셀 구름 1개
- 몬스터: 모닥이 (left 38%, top 34%, width 28%)
- 포즈/연출: `jump`로 휙 들어와 팔을 마구 휘두름. 몸 옆에 속도선 3줄
- 말풍선: 「하나 둘 셋 넷! 다 했다끽!」 (pop, 오른쪽 위)
- 내레이션: 스트레칭 첫날. / 모닥이는 일단 몸부터 움직였다.
- 효과음: 휙휙휙

## 2컷 · 혼자 넘어짐
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom 2%, width 92%)
- 몬스터: 모닥이 (left 30%, top 44%, width 30%, 18도 기울임)
- 포즈/연출: 발이 꼬여 `shiver`로 비틀. 머리 위에 작은 별 `twinkle` 2개
- 말풍선: 「끽…?」 (작게)
- 내레이션: 너무 빨리 하다가, 혼자 데구루루 넘어졌다.
- 효과음: 털썩

## 3컷 · 같은 속도로 천천히
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom 2%, width 92%) · `village-square` 멀리(far, left 56%, bottom 20%, width 50%)
- 몬스터: 모닥이 (left 22%, top 34%, width 28%)
- 포즈/연출: 오른쪽 아래에서 돌봄이의 손 그림자가 `reach`로 올라와 천천히 팔을 올림 (left 58%, bottom -2%, width 30%). 모닥이는 그 속도에 맞춰 `warm`처럼 천천히 팔을 올림. 손 뒤로 따뜻한 빛
- 말풍선: 「…천천히, 이 속도끽?」 (작게)
- 내레이션: 돌봄이는 같은 속도로 천천히 팔을 올렸다.
- 효과음: 없음

## 4컷 · 엉덩방아, 웃음
- 하늘: warm / 땅 높이 40% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 10%, bottom -20%, width 80%)
- 몬스터: 모닥이 (left 30%, top 36%, width 36%)
- 포즈/연출: `hop` 한 번 뒤 풀썩 주저앉음. 옆에 돌봄이의 빛 한 덩이(`warm`, right 6%, bottom 10%). 반짝 `twinkle` 3개
- 말풍선: 「끽끽끽! 또 하자끽!」 (pop)
- 내레이션: 같이 끝내고, 둘이 엉덩방아를 찧으며 웃었다.
- 효과음: 쿵
