# bat-1 · 보슬 1화 「눈 감고 들어 봐」

- 마을: 잔잔마을 · 명상 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `calm-mist-bank` (임시)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 안개 속에서 날개만 보인다 → 돌봄이에게 귓속말한다 → 작은 이야기를 속삭인다 → 이야기가 끝나자 안개가 걷힌다
- 말버릇: 보슬 "보슬보슬… 눈 감고 들어 봐." 속삭임

## 2컷 · 귓속말
