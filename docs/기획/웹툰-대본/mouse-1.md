# mouse-1 · 토독 1화 「작은 노트의 첫 장」

- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `bright-bookshelf` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 책 더미 사이에서 발가락만 보인다 → 돌봄이가 책을 꺼내 주자 눈이 반짝 → "토독, 이건 뭘까?" 첫 질문을 적는다 → 돌봄이가 같이 찾아 준다
- 말버릇: 토독 "토독, 이건 뭘까?" 질문으로 시작

## 1컷 · 책 더미 사이의 발가락
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-bookshelf`(임시, left 52%, bottom 14%, width 44%) · `village-square` 멀리(far, left -10%, bottom 6%, width 70%)
- 몬스터: 토독 (left 14%, top 62%, width 22%) — 책 더미에 거의 가려짐
- 포즈/연출: 발가락만 꼼지락
- 말풍선: 「토독… 이 책은 너무 높아…」 (작게)
- 내레이션: 반짝마을 도서관. 책 더미 사이로 발가락만 쏙 보였다.
- 효과음: 바스락

## 2컷 · 돌봄이가 책을 꺼내 주다
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-bookshelf`(임시, left 4%, bottom 14%, width 40%)
- 몬스터: 토독 (left 44%, top 38%, width 32%)
- 포즈/연출: `pop`으로 눈이 반짝. 돌봄이의 손 + 따뜻한 빛. 반짝 2개
- 말풍선: 「토독…!」 (작게)
- 내레이션: 돌봄이가 가만히 책 한 권을 꺼내 주었다.
- 효과음: 없음

## 3컷 · 첫 질문
- 하늘: high / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `bright-reading-table`(임시, left 12%, bottom 6%, width 76%) · `bright-lantern`(임시, left 78%, bottom 22%, width 14%)
- 몬스터: 토독 (left 34%, top 26%, width 32%)
- 포즈/연출: `hop`하며 노트에 적음
- 말풍선: 「토독, 이건 뭘까?」 (pop)
- 내레이션: 작은 노트의 첫 줄에, 첫 질문이 적혔다.
- 효과음: 사각사각

## 4컷 · 같이 찾아 주다
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `bright-open-book`(임시, left 14%, bottom 10%, width 72%)
- 몬스터: 토독 (left 34%, top 30%, width 30%)
- 포즈/연출: `hop`. 돌봄이의 손이 책장을 같이 넘김. 따뜻한 빛 + 반짝 3개
- 말풍선: 「토독, 아하! 그렇구나!」 (pop)
- 내레이션: 돌봄이가 옆에서 같이 책장을 넘겨 주었다.
- 효과음: 없음
