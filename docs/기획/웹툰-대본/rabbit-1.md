# rabbit-1 · 콩지 1화 「구석의 줄넘기」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '친해진'(4 이상)
- 표지 소품: `hot-jumprope-post` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `rabbit.png`)
- 줄거리 순서: 아무도 없을 때만 줄넘기를 한다 → 돌봄이가 오자 줄을 등 뒤로 숨긴다 → 돌봄이가 옆에 앉아 세어만 준다 → "…콩, 하나." 처음으로 소리 내어 센다
- 말버릇: 콩지 '…콩, 콩.' 말끝을 톡톡 끊는다. 돌봄이는 말하지 않는다

## 1컷 · 구석에서 혼자 줄넘기
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-jumprope-post`(임시, left 4%, bottom 18%, width 34%) · `village-square` 멀리(far, left 40%, bottom 8%, width 70%) · 픽셀 구름 1개
- 몬스터: 콩지 (left 14%, top 44%, width 26%) — 왼쪽 구석
- 포즈/연출: `hop`을 반복하듯 작게 폴짝. 발밑에서 따끈한 김 같은 빛이 조금
- 말풍선: 「…콩, 콩. 열둘.」 (작게, 속삭이듯)
- 내레이션: 따끈마을 운동장 구석. / 아무도 없을 때만 콩지의 줄넘기가 시작된다.
- 효과음: 탁, 탁

## 2컷 · 돌봄이가 오자 줄을 등 뒤로
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-jumprope-post`(임시, left 4%, bottom 18%, width 34%) · `village-path`(left 52%, bottom 4%, width 52%)
- 몬스터: 콩지 (left 18%, top 42%, width 28%)
- 포즈/연출: 콩지 `shiver`(귀가 쫑긋 서고 몸이 굳음). 오른쪽 아래에서 돌봄이의 손 그림자가 살짝 보임 (right 4%, bottom -8%, width 26%)
- 말풍선: 「…콩?!」 (pop, 작게)
- 내레이션: 누가 오는 소리에, 콩지는 줄을 얼른 등 뒤로 숨겼다.
- 효과음: 휙

## 3컷 · 옆에 앉아 세어만 준다
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `hot-jumprope-post`(임시, left 2%, bottom 18%, width 30%) · `stone-yard`(left 20%, bottom -4%, width 84%)
- 몬스터: 콩지 (left 22%, top 40%, width 28%)
- 포즈/연출: 콩지 옆 오른쪽에 돌봄이의 손 그림자와 따뜻한 빛(`warm`, left 54%, bottom 2%, width 42%). 콩지는 줄을 앞으로 슬며시 내려놓음
- 말풍선: 없음
- 내레이션: 돌봄이는 아무 말 없이 옆에 앉아, 손가락으로 셈만 해 주었다.
- 효과음: 없음

## 4컷 · 처음으로 소리 내어 센다
- 하늘: warm / 땅 높이 40% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 10%, bottom -20%, width 80%) · `hot-jumprope-post`(임시, left -4%, bottom 30%, width 26%)
- 몬스터: 콩지 (left 32%, top 30%, width 34%)
- 포즈/연출: `hop`으로 한 번 폴짝, 귀가 쫑긋. 발끝에 따끈한 빛 `flare`, 별 `twinkle` 3개
- 말풍선: 「…콩, 하나.」 (pop)
- 내레이션: 콩지의 목소리가, 처음으로 운동장에 퍼졌다.
- 효과음: 탁!
