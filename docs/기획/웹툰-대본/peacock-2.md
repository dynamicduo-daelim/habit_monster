# peacock-2 · 놀빛 2화 「칭찬 한마디」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '단짝'(7 이상)
- 표지 소품: `hot-sunset-ridge` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `peacock.png`)
- 줄거리 순서: 연습하다 깃이 꼬여 속상해한다 → 돌봄이가 "예쁘다"고 말해 준다 → 얼굴이 빨개져 깃을 확 펴 버린다 → 놀라서 둘 다 깔깔 웃는다
- 돌봄이는 말하지 않는다: "예쁘다"는 손으로 엄지를 드는 그림자와 말풍선 속 하트 모양 빛(글자 없음)으로, 내레이션이 말해 준다
- 말버릇: 놀빛 '…봐도 돼. 조금만.'

## 2컷 · 깃이 꼬였다

- 포즈/연출: 오른쪽 아래에서 돌봄이의 손 그림자가 엄지를 세움(`reach`, left 62%, bottom 2%, width 30%). 손 위로 따뜻한 하트 빛(`warm`) 하나

- 내레이션: 돌봄이가 엄지를 들며 말해 주었다. "정말 예쁘다."
- 효과음: 없음

## 4컷 · 얼굴이 빨개져 확 펴 버렸다
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-sunset-ridge`(임시, left 0%, bottom 12%, width 100%)

- 효과음: 와락!
