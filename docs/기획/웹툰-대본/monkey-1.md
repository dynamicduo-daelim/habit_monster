# monkey-1 · 모닥이 1화 「이마의 작은 불씨」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '친해진'(4 이상)
- 표지 소품: `haru-tree`
- 진화 그림(_2): 쓰지 않음 (기본 `monkey.png`)
- 출처: 지금 시안 `docs/design/웹툰-시안-모닥이-1화.html`을 대본으로 옮김 (컷 · 위치 · 문구 그대로)
- 말버릇: 모닥이 '~끽'

## 1컷 · 신이 나서 큰 나무 위로
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본(4:5)
- 배경 소품: `village-square`(left -6%, bottom 6%, width 92%) · `tree-big`(right -12%, bottom 3%, width 70%) · 픽셀 구름 2개
- 몬스터: 모닥이 (left 54%, top 23%, width 25%) — 오른쪽 나무 쪽
- 포즈/연출: `jump` (왼쪽 아래에서 튀어 올라 착지). 뛰는 길을 가리키는 속도선 3줄
- 말풍선: 「끽끽! 손님이다끽!」 (pop, 오른쪽 위, 꼬리 오른쪽)
- 내레이션: 따끈마을의 아침. / 처음 보는 손님에 모닥이는 신이 났다.
- 효과음: 휘익— (왼쪽 아래, 기울임)

## 2컷 · 나무 꼭대기, 아래가 까마득
- 하늘: high / 칸 모양: 기본
- 배경 소품: `tree-crown`(left -34%, bottom -36%, width 100%) · `village-path` 멀리(far, left 64%, bottom 3%, width 32%) · 픽셀 구름 2개
- 몬스터: 모닥이 (left 8%, top 33%, width 30%)
- 포즈/연출: `shiver` (덜덜 떪). 식은땀 한 방울이 `drop`으로 떨어짐
- 말풍선: 「끽…」 (작게, 모닥이 오른쪽 위)
- 내레이션: 올라가는 건 쉬웠는데, / 내려가는 길은 보이지 않았다.
- 효과음: 없음

## 3컷 · 나무 아래에서 돌봄이의 손
- 하늘: warm / 칸 모양: 기본
- 배경 소품: `tree-big`(left -38%, top -14%, width 176%, 크게 올려다본 나무)
- 몬스터: 모닥이 (left 35%, top 30%, width 28%, 6도 기울임)
- 포즈/연출: 아래에서 돌봄이의 손이 `reach`로 올라옴 (left 31%, bottom -2%, width 38%). 손 뒤로 따뜻한 빛(`warm`, left 15%, bottom -26%, width 72%)
- 말풍선: 「…잡아도 돼끽?」 (작게, 모닥이 오른쪽)
- 내레이션: 돌봄이가 가만히 손을 내밀었다.
- 효과음: 없음

## 4컷 · 따끈한 돌바닥 위, 불씨가 반짝
- 하늘: morning / 땅 높이 40% / 칸 모양: 넓게(wide, 1:1)
- 배경 소품: `stone-yard`(left 10%, bottom -22%, width 80%)
- 몬스터: 모닥이 (left 30%, top 34%, width 40%)
- 포즈/연출: `hop` (착지). 이마에서 불씨 빛이 `flare`로 켜지고 네 군데에서 `twinkle` 반짝
- 말풍선: 「고마워끽! 이제 친구다끽!」 (pop, 오른쪽 위)
- 내레이션: 이마의 작은 불씨가, 반짝 켜졌다. (아래쪽)
- 효과음: 없음
