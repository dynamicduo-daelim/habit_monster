# village-yum-3 · 냠냠마을 3장 「오늘은 다 같이 한 상」

- 마을: 냠냠마을 · 식습관 / 종류: 마을 장(chapter) / 열리는 때: 냠냠마을 종 5종 전부 잡을 때
- 표지 소품: `yum-rice-bowl` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (다섯 마리 모두 기본 그림)
- 줄거리 순서: 쪼르가 물을 한 잔씩 따르며 건배를 외친다 → 밤톨이 "밥은 먹었니?" 하며 상을 차린다 → 서툰 요리지만 서로 맛을 보며 웃는다 → 하루나무 잎이 탱글탱글해진다
- 말버릇: 쪼르 "쪼르르~ 한 잔 더!", 밤톨 "부엉. 밥은 먹었니?", 오물 "오물오물…", 푸릇이 "푸릇… 참아야 해!", 다래 "찾았다!"

- 몬스터: 쪼르 (left 42%, top 24%, width 26%, `jump`) · 오물 (left 8%, top 40%, width 16%) · 푸릇이 (left 24%, top 42%, width 15%) · 다래 (left 68%, top 40%, width 15%) · 밤톨 (left 82%, top 36%, width 16%)
- 포즈/연출: 쪼르가 물병을 높이 들고 모두의 잔에 맑은 물을 채우며 건배를 외침
- 말풍선: 「쪼르르~ 건강하게 맛있게, 건배!」 (pop tail-right)
- 내레이션: 쪼르가 컵마다 시원한 물을 채우며 힘차게 건배를 외쳤다.
- 효과음: 쪼르르

## 3컷 · 서툴러도 함께 나눈 맛
