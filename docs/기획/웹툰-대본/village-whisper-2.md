# village-whisper-2 · 소곤마을 2장 「잎사귀 침대」

- 마을: 소곤마을 · 수면 / 종류: 마을 장(chapter) / 열리는 때: 소곤마을 종 2종
- 표지 소품: `whisper-leaf-bed` (임시)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 포근이가 침대를 만드는데 초롱이 "불 꺼도 돼?" 하며 망설인다 → 새근이가 먼저 누워 "새근… 쿨" 잠든다 → 초롱이 등불을 살짝 줄이고 → 둘이 나란히 누워 별을 센다

- 내레이션: 초롱은 불을 끄는 게 망설여졌다.
- 효과음: 없음
