# deer-3 · 번득이 3화 「번개가 환해지던 날」

- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `bright-lantern` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `deer_2.png`가 없다 → 1·2·4컷(번득이가 나오는 모든 컷)에서 1.15배 + 빛으로 그림
- 줄거리 순서: 뿔이 한 가닥 더 자란다 → 너무 번뜩여서 책이 날아간다 → 토독과 끈기가 받아 준다 → 번득이가 "미안, 미안!" 하며 쑥스러워한다
- 말버릇: 번득이 "아! 잠깐, 잠깐만!", 토독 "토독, …", 끈기 "으르렁— 아니, …뜻이야!"

## 1컷 · 뿔이 한 가닥 더
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-bookshelf`(임시, left 56%, bottom 14%, width 40%) · `bright-lantern`(임시, left 6%, bottom 30%, width 12%)
- 몬스터: 번득이 (left 22%, top 32%, width 34%) 진화, `pop`
- 포즈/연출: 뿔 뒤 flare 빛, 반짝 2개
- 말풍선: 「아! 뿔이 늘었다!」 (pop)
- 내레이션: 아침에 눈을 뜨니, 뿔이 한 가닥 더 자라 있었다.
- 효과음: 없음

## 2컷 · 책이 날아간다
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-bookshelf`(임시, left 56%, bottom 14%, width 40%)
- 몬스터: 번득이 (left 20%, top 40%, width 34%) 진화, `jump`
- 포즈/연출: 속도선. 책이 휙 날아감
- 말풍선: 「아! 잠깐, 잠깐만!」 (pop, 작게)
- 내레이션: 아이디어가 너무 번뜩인 나머지, 들고 있던 책이 휙 날아갔다.
- 효과음: 휙—

## 3컷 · 받아 준다
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom 2%, width 88%)
- 몬스터: 번득이 (left 6%, top 36%, width 24%) 진화 · 토독 (left 40%, top 38%, width 20%) `hop` · 끈기 (left 66%, top 32%, width 26%)
- 말풍선: 「토독, 잡았다!」 · 「으르렁— 아니, 괜찮다는 뜻이야!」 (작게)
- 내레이션: 토독과 끈기가 책을 척 받아 주었다.
- 효과음: 착!

## 4컷 · 쑥스러운 번득이
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `bright-open-book`(임시, left 14%, bottom 6%, width 72%)
- 몬스터: 번득이 (left 26%, top 28%, width 40%) 진화, `hop`
- 포즈/연출: 뿔 flare + 반짝 3개
- 말풍선: 「미안, 미안! 고마워!」 (pop)
- 내레이션: 번득이는 얼굴이 빨개졌다. 그래도 뿔은 환하게 반짝였다.
- 효과음: 없음
