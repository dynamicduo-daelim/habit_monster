# hedgehog-2 · 푸릇이 2화 「아침 이슬 샐러드」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `yum-berry-bush` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 아침에 푸릇이가 샐러드를 쳐다만 본다 → 다래가 열매를 몰래 얹어 준다 → 한 입 먹고 눈이 동그래진다 → 가시가 보들보들해진다
- 말버릇: 푸릇이 "푸릇… 참아야 해!", 다래 "찾았다!"

## 1컷 · 초록빛 샐러드 앞 망설임
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 48%, bottom 20%, width 18%)
- 몬스터: 푸릇이 (left 18%, top 38%, width 34%)
- 포즈/연출: 샐러드 볼을 내려다보며 숟가락을 들까 말까 망설임. 뾰족한 가시
- 말풍선: 「푸릇… 채소만 가득해… 맛이 있을까?」 (작게)
- 내레이션: 아침 식탁. 초록빛 샐러드 앞에서 푸릇이는 머뭇거렸다.
- 효과음: 쭈뼛

## 2컷 · 다래의 깜짝 선물
- 하늘: morning / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 12%, bottom 8%, width 76%) · `yum-berry-bush`(임시, left 74%, bottom 12%, width 24%)
- 몬스터: 다래 (left 14%, top 28%, width 26%, `pop`) · 푸릇이 (left 52%, top 36%, width 28%)
- 포즈/연출: 다래가 덤불에서 쏙 나와 달콤한 빨간 열매를 샐러드 위에 얹어 줌
- 말풍선: 「찾았다! 달콤한 열매도 같이 먹어 봐!」 (pop)
- 내레이션: 그 순간, 다래가 덤불에서 불쑥 나타나 잘 익은 열매를 올려놓았다.
- 효과음: 쏙

## 3컷 · 눈이 동그래진 한 입
- 하늘: high / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%)
- 몬스터: 푸릇이 (left 30%, top 32%, width 38%)
- 포즈/연출: 샐러드를 한 숟가락 입에 넣고 눈이 휘둥그레짐 (`pop`). 반짝 2개
- 말풍선: 「푸릇…! 달콤하고 아삭해!」 (pop tail-right)
- 내레이션: 싱그러운 채소와 달콤한 열매가 어우러져 깜짝 놀랄 만큼 맛있었다.
- 효과음: 아삭

## 4컷 · 보들보들해진 가시
- 하늘: warm / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 14%, bottom 8%, width 72%)
- 몬스터: 푸릇이 (left 26%, top 34%, width 32%) · 다래 (left 60%, top 34%, width 28%, `hop`)
- 포즈/연출: 푸릇이의 가시가 부드러운 잎사귀처럼 포근히 누움. 둘이 마주 보며 웃음
- 말풍선: 「푸릇… 샐러드가 좋아졌어!」 (pop) · 「다 먹었다!」 (작게)
- 내레이션: 접시를 비우자, 뾰족했던 가시가 부드러운 솜털처럼 보들보들해졌다.
- 효과음: 방긋
