- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '단짝'(7 이상)
- 표지 소품: `hot-roost-perch` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `chicken.png`)
- 줄거리 순서: 반대로 홰치가 늦잠을 잔다 → 돌봄이가 살그머니 깨운다 → "내가 깨워야 하는데…" 하며 얼굴을 붉힌다 → 이번엔 둘이 같이 "꼬오—" 한다
- 말버릇: 홰치 '꼬오—' 뒤 하품. 돌봄이는 말하지 않는다

## 2컷 · 돌봄이가 살그머니 깨운다
- 하늘: high / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-roost-perch`(임시, left 8%, bottom 14%, width 40%) · `stone-yard`(left 24%, bottom -6%, width 80%)
- 몬스터: 홰치 (left 18%, top 42%, width 28%, 눕힌 채 -40도로 일어나는 중)
- 포즈/연출: 오른쪽 아래에서 돌봄이의 손 그림자가 `reach`로 올라와 홰치의 깃털을 살살 쓰다듬음 (left 52%, bottom -2%, width 32%). 따뜻한 빛 `warm`
- 말풍선: 「꼬…? 하아암…」 (작게)
- 내레이션: 돌봄이가 살그머니, 깃털을 톡톡 두드려 깨웠다.
- 효과음: 톡톡

## 3컷 · 얼굴을 붉힌다
- 하늘: warm / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-roost-perch`(임시, left 30%, bottom 14%, width 42%)
- 몬스터: 홰치 (left 32%, top 30%, width 34%)
- 포즈/연출: 홰치 `pop`으로 벌떡 일어나 날개로 얼굴을 가림. 볼이 붉어지는 느낌으로 몸 뒤에 `glow warm`. `shiver`
- 말풍선: 「내가 깨워야 하는데… 꼬, 꼬오… 하아암.」 (pop)
- 내레이션: 깨워 주는 쪽이 깨워졌다. 홰치는 얼굴이 빨개졌다.
- 효과음: 파닥

## 4컷 · 둘이 같이 꼬오—
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-sunrise-hill`(임시, left 0%, bottom 24%, width 100%) — 없으면 `stone-yard`로 대체하고 구석에 '임시' 표시
- 몬스터: 홰치 (left 32%, top 34%, width 32%)
- 포즈/연출: 홰치 `hop`, 부리를 활짝. 옆에 돌봄이의 빛 한 덩이가 함께 퍼져 나가는 소리 선. 별 `twinkle` 3개
- 말풍선: 「꼬오—! 같이 하니까 졸리지 않다!」 (pop)
- 내레이션: 이번에는 둘이 함께, 아침을 불렀다.
- 효과음: 꼬오오—!
