# deer-1 · 번득이 1화 「뿔이 간질간질」

- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `bright-lantern` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 뿔 끝에 작은 불꽃이 튄다 → 뭔가 떠올랐는데 말이 엉킨다 → 돌봄이가 천천히 들어 준다 → 정리된 생각을 노트에 적고 기뻐한다
- 말버릇: 번득이 "아! 잠깐, 잠깐만!" 말이 앞서간다

## 1컷 · 뿔 끝의 불꽃
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-bookshelf`(임시, left 54%, bottom 14%, width 42%) · `bright-lantern`(임시, left 6%, bottom 30%, width 12%)
- 몬스터: 번득이 (left 22%, top 34%, width 32%)
- 포즈/연출: `shiver`, 뿔 끝에 반짝 2개
- 말풍선: 「아! 뿔이 간질간질해!」 (pop)
- 내레이션: 번득이의 뿔 끝이 간질간질, 작은 불꽃이 톡 튀었다.
- 효과음: 파직

## 2컷 · 말이 엉킨다
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-bookshelf`(임시, left 54%, bottom 14%, width 42%)
- 몬스터: 번득이 (left 22%, top 36%, width 32%) `hop`, 식은땀
- 말풍선: 「아! 잠깐, 잠깐만! 그게, 그러니까…」 (pop, 작게)
- 내레이션: 뭔가 떠올랐는데, 말이 먼저 엉켜 버렸다.
- 효과음: 버벅

## 3컷 · 천천히 들어 준다
- 하늘: warm / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 0%, bottom 8%, width 70%)
- 몬스터: 번득이 (left 16%, top 40%, width 30%)
- 포즈/연출: 돌봄이의 손 + 따뜻한 빛. 돌봄이는 말하지 않고 고개만 끄덕임
- 말풍선: 「…천천히 말해 볼게.」 (작게)
- 내레이션: 돌봄이는 서두르지 않고 끝까지 들어 주었다.
- 효과음: 없음

## 4컷 · 노트에 적고 기뻐한다
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `bright-reading-table`(임시, left 14%, bottom 6%, width 72%) · `bright-lantern`(임시, left 80%, bottom 22%, width 14%)
- 몬스터: 번득이 (left 34%, top 20%, width 30%) `jump`
- 말풍선: 「아! 이거였어! 적어 둬야지!」 (pop)
- 내레이션: 정리된 생각을 노트에 또박또박 적었다.
- 효과음: 사각사각
