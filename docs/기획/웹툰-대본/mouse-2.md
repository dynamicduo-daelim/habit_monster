# mouse-2 · 토독 2화 「모르는 걸 모아 둔 노트」

- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `bright-reading-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 모르는 게 너무 많아 한숨을 쉰다 → 돌봄이가 "하나씩 알면 돼"라고 한다 → 하루 하나씩 답을 적는다 → 노트에 작은 별이 세 개 생긴다
- 말버릇: 토독 "토독, …" 로 시작. 돌봄이의 "하나씩 알면 돼"는 말하지 않고 손가락 하나 + 내레이션으로 바꿨다

## 1컷 · 질문이 가득한 노트
- 하늘: high / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 6%, bottom 8%, width 88%)
- 몬스터: 토독 (left 30%, top 36%, width 34%)
- 포즈/연출: `shiver`, 식은땀 1개
- 말풍선: 「토독… 모르는 게 너무 많아…」 (작게)
- 내레이션: 노트에는 모르는 것이 가득했다. 토독은 한숨이 나왔다.
- 효과음: 후우

## 2컷 · 손가락 하나
- 하늘: high / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 0%, bottom 8%, width 72%) · `bright-lantern`(임시, left 80%, bottom 22%, width 14%)
- 몬스터: 토독 (left 16%, top 40%, width 30%)
- 포즈/연출: 돌봄이의 손이 손가락 하나를 폄. 따뜻한 빛
- 말풍선: 「…하나씩?」 (작게)
- 내레이션: 돌봄이가 손가락 하나를 가만히 펴 보였다. 하나씩 알면 된다고.
- 효과음: 없음

## 3컷 · 하루에 하나씩
- 하늘: morning / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `bright-reading-table`(임시, left 10%, bottom 6%, width 80%)
- 몬스터: 토독 셋 (left 14% · 40% · 66%, top 26%, width 24%) — 사흘을 한 컷에 나란히
- 포즈/연출: 각각 `hop`
- 말풍선: 「하나 알았다!」 · 「또 하나!」 · 「토독, 또 하나!」 (작게)
- 내레이션: 첫날, 이튿날, 사흗날. 하루에 하나씩 답을 적었다.
- 효과음: 사각

## 4컷 · 별이 세 개
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `bright-open-book`(임시, left 14%, bottom 10%, width 72%)
- 몬스터: 토독 (left 34%, top 34%, width 30%)
- 포즈/연출: `pop`. 노트 위에 별 같은 반짝 3개
- 말풍선: 「토독, 별이 세 개나 생겼어!」 (pop)
- 내레이션: 노트에 작은 별이 세 개 반짝였다.
- 효과음: 없음
