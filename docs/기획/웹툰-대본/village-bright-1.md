# village-bright-1 · 반짝마을 1장 「불이 꺼진 도서관」

- 마을: 반짝마을 · 공부 / 종류: 마을 장(chapter) / 열리는 때: 반짝마을 종을 1종 잡을 때
- 표지 소품: `bright-bookshelf` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 책장이 닫혀 있고 아무도 안 읽는다 → 돌봄이가 책 한 쪽을 펴 읽는다 → 글자 위에 작은 불빛이 켜진다 → 주민들이 하나둘 책을 집는다
- 말버릇: 토독 "토독, 이건 뭘까?", 번득이 "아! …"
- 1장은 어떤 종을 먼저 잡았어도 읽히도록 마을 주민 넷(토독 · 번득이 · 둥실 · 끈기)이 모두 나온다

- 배경 소품: `bright-bookshelf`(임시, left 4%, bottom 14%, width 26%) · `bright-bookshelf`(임시, left 70%, bottom 14%, width 26%)

- 효과음: 없음

## 3컷 · 작은 불빛
