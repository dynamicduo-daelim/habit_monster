# axolotl-1 · 초롱 1화 「이제 불 꺼도 돼?」

- 마을: 소곤마을 · 수면 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `whisper-star-lamp` (임시)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 마을 길에 등을 켜고 다닌다 → 돌봄이의 화면 불빛에 눈을 찡그린다 → 돌봄이가 화면을 끈다 → 초롱이 안심하며 반짝인다
- 말버릇: 초롱 "초롱초롱… 이제 불 꺼도 돼?"
