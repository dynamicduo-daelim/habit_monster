# badger-3 · 다래 3화 「덤불 속의 큰 열매」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 1차 진화 (Lv.10)
- 표지 소품: `yum-berry-bush` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `_2` 없음 → 3 · 4컷 `evolved=True` (1.15배 + 빛)
- 줄거리 순서: 다래의 코가 더 예민해진다 → 숲 가득 열매 냄새가 느껴진다 → 친구들을 이끌고 가장 큰 열매를 찾는다 → 모두 나눠 먹고 배가 빵빵해진다
- 말버릇: 다래 "찾았다!", 오물 "오물오물…", 푸릇이 "푸릇…"

## 1컷 · 킁킁, 예민해진 코
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `tree-big`(left 56%, bottom 8%, width 42%)
- 몬스터: 다래 (left 28%, top 36%, width 36%)
- 포즈/연출: 코를 킁킁거리며 냄새를 맡음. 코 끝에 작은 반짝임
- 말풍선: 「킁킁… 바람 타고 달콤한 향기가 나!」 (pop)
- 내레이션: 매일 규칙적으로 세 끼를 챙겨 먹던 다래의 코가 한층 더 예민해졌다.
- 효과음: 킁킁

## 2컷 · 숲속 열매 탐정단
- 하늘: morning / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `village-path`(left 0%, bottom 4%, width 100%)
- 몬스터: 다래 (left 18%, top 32%, width 28%, `hop`) · 오물 (left 52%, top 40%, width 22%) · 푸릇이 (left 74%, top 40%, width 20%)
- 포즈/연출: 다래가 앞장서서 친구들을 숲 깊은 곳으로 이끎
- 말풍선: 「찾았다! 다들 나만 따라와!」 (pop tail-right)
- 내레이션: 숲 가득 퍼지는 열매 향기를 따라, 다래가 앞장서서 걸어갔다.
- 효과음: 사각사각

## 3컷 · 덤불 속의 대왕 열매
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-berry-bush`(임시, left 20%, bottom 8%, width 60%)
- 몬스터: 다래 진화 (left 34%, top 26%, width 40%, evolved=True) · 오물 (left 10%, top 42%, width 20%) · 푸릇이 (left 76%, top 42%, width 18%)
- 포즈/연출: 덤불 사이에서 커다란 황금빛 열매를 발견하고 환호 (`jump`). 다래 몸에 은은한 빛
- 말풍선: 「찾았다! 숲에서 가장 커다란 열매야!」 (pop tail-right)
- 내레이션: 마침내 덤불 한가운데에서 커다란 대왕 열매를 찾아냈다.
- 효과음: 번쩍

## 4컷 · 빵빵해진 배
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 14%, bottom 8%, width 72%)
- 몬스터: 다래 진화 (left 36%, top 30%, width 40%, evolved=True) · 오물 (left 12%, top 44%, width 20%) · 푸릇이 (left 76%, top 44%, width 18%)
- 포즈/연출: 큰 열매를 조각내어 배불리 나눠 먹고 배를 두드림. 반짝 3개
- 말풍선: 「찾았다! 다 같이 먹으니까 배가 빵빵해!」 (pop) · 「오물오물… 최고야.」 (작게)
- 내레이션: 친구들과 달콤한 열매를 배불리 나누어 먹으며, 다래의 하루가 든든하게 채워졌다.
- 효과음: 통통
