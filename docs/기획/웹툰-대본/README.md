## 파일 형식

```
# <id>-<화> · <제목>
- 마을 / 종류(species | chapter) / 열리는 때
- 표지 소품: 있는 소품 이름 또는 Ludo 파일 이름(임시)
- 진화 그림(_2): 쓰는지 여부와 어느 컷부터
- 줄거리 순서 (설정서의 '→')
- 말버릇

## N컷 · 한 줄 제목          (3 ~ 4컷)
- 하늘: morning | high | warm | dusk / 땅 높이 % / 칸 모양: 기본(4:5) 또는 넓게(wide, 1:1)
- 배경 소품: 이름(left·bottom·width %) …  — 위치는 컷 틀 기준 %
- 몬스터: 이름 (left·top·width %)
- 포즈/연출: 애니메이션 이름(jump · pop · shiver · hop · flare · twinkle · reach · warm · drop) + 설명
- 말풍선: 「문구」 (스타일)
- 내레이션: 문구
- 효과음: 문구 또는 없음

## 끝 카드
- 끝 카드 한 줄
```

## 규칙

- 배경 소품은 지금 있는 6장(`haru-tree` · `tree-big` · `tree-crown` · `village-square` · `village-path` · `stone-yard`, `docs/design/webtoon-bg/`) 또는 Ludo 시트 파일 이름(아래)을 쓴다. Ludo 소품은 이미지가 생기기 전까지 `(임시)`로 적고, 없으면 있는 소품이나 단색으로 그리며 컷 구석에 작은 '임시' 표시를 붙인다.
- 말버릇은 설정서 1부 그대로: 모닥이 '~끽', 콩지 '…콩, 콩.', 홰치 '꼬오—' 뒤에 하품, 길쭉 '쭈우우욱… 천천히 해도 돼', 놀빛 '…봐도 돼. 조금만.'
- 돌봄이(사용자)는 말하지 않는다. 손 그림자나 따뜻한 빛으로만 나오고, "셋까지만" 같은 말은 손짓 + 내레이션으로 바꾼다.
- 힐링물: 악당 · 싸움 · 슬픈 결말 없음. 가장 큰 감정은 놀람 · 쑥스러움 · 걱정.
- 모닥이 1화는 지금 시안 HTML(`docs/design/웹툰-시안-모닥이-1화.html`)의 컷 · 위치 · 문구를 그대로 옮겼다.
