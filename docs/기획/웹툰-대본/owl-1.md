# owl-1 · 밤톨 1화 「밥은 먹었니?」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 친해진 (호감도 4)
- 표지 소품: `yum-rice-bowl` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 밤마다 식탁 위에 앉아 있다 → 돌봄이에게 먼저 안부를 묻는다 → 돌봄이가 "아직"이라 하자 허둥지둥 밥을 차린다 → 같이 먹고 졸음이 쏟아진다
- 말버릇: 밤톨 "부엉. 밥은 먹었니?" 안부부터 묻는다

## 1컷 · 밤 식탁의 지킴이
- 하늘: dusk / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `village-square` 멀리(far, left -10%, bottom 4%, width 70%)
- 몬스터: 밤톨 (left 32%, top 34%, width 36%)
- 포즈/연출: 어둑해진 저녁 식탁 위에 단정하게 앉아 있는 밤톨
- 말풍선: 「부엉… 오늘 하루도 다들 잘 챙겨 먹었으려나.」 (작게)
- 내레이션: 별빛이 내릴 무렵이면, 밤톨은 마을 식탁 위를 든든하게 지켰다.
- 효과음: 부엉

## 2컷 · 따뜻한 첫 안부
- 하늘: dusk / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%)
- 몬스터: 밤톨 (left 34%, top 32%, width 34%, `pop`)
- 포즈/연출: 늦게 찾아온 돌봄이를 발견하고 고개를 갸웃하며 눈을 맞춤
- 말풍선: 「부엉. 밥은 먹었니?」 (pop tail-right)
- 내레이션: 밤톨은 찾아온 돌봄이에게 가장 먼저 따뜻한 안부를 물었다.
- 효과음: 없음

## 3컷 · 허둥지둥 차린 밥상
- 하늘: dusk / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 12%, bottom 8%, width 76%) · `yum-rice-bowl`(임시, left 44%, bottom 18%, width 18%)
- 몬스터: 밤톨 (left 18%, top 28%, width 32%, `hop`)
- 포즈/연출: 돌봄이가 아직 못 먹었다는 듯 머뭇거리자, 밤톨이 날개를 퍼덕이며 따뜻한 국과 밥을 뚝딱 내옴
- 말풍선: 「부엉! 끼니를 거르면 안 되지! 어서 앉아, 따뜻할 때 먹어!」 (pop)
- 내레이션: 아직 밥을 못 먹었다는 손짓에, 밤톨은 허둥지둥 김 나는 밥상을 차려 냈다.
- 효과음: 달그락달그락

## 4컷 · 배부른 졸음
- 하늘: dusk / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 48%, bottom 20%, width 18%)
- 몬스터: 밤톨 (left 32%, top 38%, width 36%)
- 포즈/연출: 따뜻한 밥을 깨끗이 비우고 눈이 스르르 감김 (`warm`). 반짝 2개
- 말풍선: 「부엉… 역시 따뜻한 밥을 먹어야 잠도 잘 오지… 하아암…」 (작게)
- 내레이션: 든든하게 한 그릇을 비우자, 둘 사이에 기분 좋은 졸음이 사르르 내려앉았다.
- 효과음: 쿨쿨
