# platypus-3 · 쪼르 3화 「부리 끝의 새순」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 1차 진화 (Lv.10)
- 표지 소품: `yum-water-pitcher` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `_2` 없음 → 3 · 4컷 `evolved=True` (1.15배 + 빛)
- 줄거리 순서: 부리 끝에 새순이 돋는다 → 쪼르가 신기해서 눈이 모인다 → 오물과 푸릇이가 새순에 물을 주며 응원한다 → 부리가 더 길고 반짝이게 자란다
- 말버릇: 쪼르 "쪼르르~ 한 잔 더!", 오물 "오물오물…", 푸릇이 "푸릇…"
