# village-yum-2 · 냠냠마을 2장 「편식 탐정 다래」

- 마을: 냠냠마을 · 식습관 / 종류: 마을 장(chapter) / 열리는 때: 냠냠마을 종 3종 잡을 때
- 표지 소품: `yum-berry-bush` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 푸릇이는 아침 이슬 샐러드가 싫은 척하며 야식 냄새를 쫓는다 → 다래가 열매를 숨겨 두고 보물찾기를 한다 → 오물이 천천히 씹으며 맛을 알려 준다 → 푸릇이가 한 입 먹고 눈이 동그래진다
- 말버릇: 푸릇이 "푸릇… 참아야 해!", 다래 "찾았다!", 오물 "오물오물… 음, 맛있다."

## 1컷 · 야식 냄새를 쫓는 푸릇이
- 하늘: morning / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 48%, bottom 20%, width 18%)
- 몬스터: 푸릇이 (left 24%, top 38%, width 34%, `shiver`)
- 포즈/연출: 신선한 샐러드를 뒤로한 채 어젯밤 남은 기름진 야식 냄새를 쫓아 킁킁거림. 식은땀
- 말풍선: 「푸릇… 샐러드는 심심해… 고소한 냄새가 좋은데…」 (작게)
- 내레이션: 푸릇이는 아침 샐러드가 내키지 않는 척하며 기름진 냄새를 쫓았다.
- 효과음: 킁킁

## 2컷 · 다래의 비밀 보물찾기
- 하늘: high / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-berry-bush`(임시, left 20%, bottom 8%, width 60%)
- 몬스터: 다래 (left 18%, top 28%, width 28%, `pop`) · 푸릇이 (left 66%, top 36%, width 24%)
- 포즈/연출: 다래가 덤불 속에 달콤한 산딸기와 열매들을 숨기며 푸릇이를 부름
- 말풍선: 「찾았다! 덤불 속에 진짜 맛있는 보물이 숨어 있어!」 (pop tail-right)
- 내레이션: 편식 탐정 다래가 덤불 속에 알록달록한 제철 열매들을 숨겨 놓았다.
- 효과음: 쏙쏙

## 3컷 · 오물의 천천히 씹는 시범
- 하늘: high / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-berry-bush`(임시, left 6%, bottom 12%, width 32%)
- 몬스터: 오물 (left 18%, top 36%, width 32%) · 푸릇이 (left 56%, top 38%, width 28%)
- 포즈/연출: 오물이 열매와 풀잎을 입에 넣고 꼭꼭 씹는 행복한 표정을 지음
- 말풍선: 「오물오물… 음, 꼭꼭 씹으면 열매 단물이 팡 터져.」 (pop)
- 내레이션: 오물이 곁에서 천천히 꼭꼭 씹으며 진짜 맛을 느끼는 법을 보여 주었다.
- 효과음: 냠냠

## 4컷 · 눈이 둥그레진 푸릇이
- 하늘: warm / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 14%, bottom 8%, width 72%)
- 몬스터: 푸릇이 (left 40%, top 30%, width 34%, `pop`) · 다래 (left 12%, top 34%, width 24%, `hop`) · 오물 (left 74%, top 36%, width 22%)
- 포즈/연출: 푸릇이가 조심스레 한 입 먹고 눈이 반짝 커짐. 반짝 3개
- 말풍선: 「푸릇…! 달콤하고 아삭해! 샐러드가 이렇게 맛있었어?!」 (pop tail-right)
- 내레이션: 한 입 베어 물자마자 푸릇이의 눈이 동그랗게 커지며 환한 미소가 번졌다.
- 효과음: 아삭!
