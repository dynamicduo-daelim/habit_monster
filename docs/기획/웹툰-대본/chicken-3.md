# chicken-3 · 홰치 3화 「깃털이 따뜻해진 날」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `hot-sunrise-hill` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 사용함. `chicken_2.png`가 있다. 1컷은 기본 `chicken.png`, 2 ~ 4컷은 `chicken_2.png`(깃털이 달아오른 뒤)
- 줄거리 순서: 외치다 목이 간지럽다 → 깃털 끝이 붉게 달아오른다 → 친구들이 하나둘 문을 열고 나온다 → 더 크고 맑은 "꼬오—"가 마을에 퍼진다
- 말버릇: 홰치 '꼬오—' 뒤 하품, 모닥이 '~끽', 콩지 '…콩, 콩.'

## 1컷 · 외치다 목이 간지럽다
- 하늘: dusk / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-roost-perch`(임시, left 26%, bottom 14%, width 46%) · `village-square` 멀리(far, left -8%, bottom 6%, width 80%)
- 몬스터: 홰치 (left 34%, top 26%, width 30%)
- 포즈/연출: 부리를 위로 들다가 `shiver`, 날개로 목을 만짐
- 말풍선: 「꼬오— 꼬, 콜록… 목이 간질간질…」 (pop)
- 내레이션: 오늘도 제일 먼저 외치는데, / 목이 간질간질했다.
- 효과음: 간질간질

## 2컷 · 깃털 끝이 붉게 달아오른다
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `hot-roost-perch`(임시, left 26%, bottom 14%, width 46%)
- 몬스터: 홰치 `_2` (left 30%, top 28%, width 36%)
- 포즈/연출: 깃털 끝에서 붉은 빛이 `flare`로 퍼짐. 몸 뒤 `glow warm`. 별 `twinkle` 3개
- 말풍선: 「꼬…? 깃털이 따뜻해… 하아암.」 (작게)
- 내레이션: 깃털 끝이 노을처럼 붉게 달아올랐다.
- 효과음: 후끈

## 3컷 · 친구들이 하나둘 문을 연다
- 하늘: morning / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `village-square`(left -6%, bottom 14%, width 92%) · `village-path`(left 60%, bottom 6%, width 40%)
- 몬스터: 홰치 `_2` (left 36%, top 40%, width 26%) 가운데 · 모닥이 (left 4%, top 48%, width 20%) · 콩지 (left 74%, top 48%, width 20%)
- 포즈/연출: 양옆에서 집 문이 열리고 모닥이 · 콩지가 눈을 비비며 나옴. 홰치는 `hop`. 따뜻한 빛이 마을로 번짐
- 말풍선: 「일어났다끽!」 (작게, 모닥이) · 「…콩, 콩. 포근한 소리.」 (작게, 콩지)
- 내레이션: 따뜻한 빛에 하나둘, 마을의 문이 열렸다.
- 효과음: 끼익

## 4컷 · 더 크고 맑은 꼬오—
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `hot-sunrise-hill`(임시, left 0%, bottom 24%, width 100%) — 없으면 `stone-yard`로 대체하고 구석에 '임시' 표시
- 몬스터: 홰치 `_2` (left 28%, top 30%, width 40%)
- 포즈/연출: 부리를 활짝 `pop`. 소리 선이 마을 쪽으로 멀리 퍼짐. 지평선 위 해가 `flare`
- 말풍선: 「꼬오오—! 오늘도 좋은 아침이다—! 하아암.」 (pop, 크게)
- 내레이션: 더 크고 맑은 꼬오—가, 마을 끝까지 퍼졌다.
- 효과음: 꼬오오오—!
