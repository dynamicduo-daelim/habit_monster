# rabbit-3 · 콩지 3화 「발이 가벼워진 날」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `hot-jumprope-post` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `rabbit_2.png` 없음 → 기본 `rabbit.png`를 1.15배로 키우고 몸 뒤에 `glow`를 더한다 (모든 컷의 콩지 폭 = 아래 적은 값, 이미 1.15배 반영)
- 줄거리 순서: 몸이 가벼워져 줄 없이도 폴짝 뛴다 → 놀라 귀가 쫑긋 선다 → 친구들이 박수를 친다 → 귀가 한 뼘 길어진 콩지가 수줍게 인사한다
- 말버릇: 콩지 '…콩, 콩.', 모닥이 '~끽', 홰치 '꼬오—' 뒤 하품

## 1컷 · 줄 없이 폴짝
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom -2%, width 92%) · `hot-jumprope-post`(임시, left -4%, bottom 22%, width 26%) · 픽셀 구름 1개
- 몬스터: 콩지 (left 32%, top 24%, width 33%) — 공중
- 포즈/연출: `hop`. 손에는 줄이 없음(줄은 기둥에 걸려 있음). 발밑에 따끈한 빛
- 말풍선: 「…콩? 줄이 없는데… 콩, 콩!」 (작게)
- 내레이션: 오늘은 발이 이상하게 가벼웠다. / 줄이 없어도 폴짝 뛸 수 있을 만큼.
- 효과음: 폴짝

## 2컷 · 놀라 귀가 쫑긋
- 하늘: high / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom -2%, width 92%)
- 몬스터: 콩지 (left 30%, top 36%, width 36%)
- 포즈/연출: 콩지 `pop`처럼 놀람, 귀가 쫑긋 곧게 섬. 머리 위에 `twinkle` 별 2개, 몸 뒤 `glow warm`
- 말풍선: 「…콩?! 나, 나 뛰었어?」 (pop)
- 내레이션: 놀란 귀가 쫑긋, 하늘을 향해 섰다.
- 효과음: 쫑긋

## 3컷 · 친구들의 박수
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `village-square`(left -6%, bottom 14%, width 92%)
- 몬스터: 콩지 (left 36%, top 34%, width 28%) 가운데 · 모닥이 (left 6%, top 46%, width 22%) · 홰치 (left 72%, top 46%, width 22%)
- 포즈/연출: 모닥이 `hop`으로 박수, 홰치는 날개를 짝짝. 콩지는 얼굴이 빨개져 `shiver`. 오른쪽 아래에 돌봄이의 따뜻한 빛
- 말풍선: 「대단하다끽!」 (pop, 모닥이) · 「꼬오— 멋지다… 하아암.」 (작게, 홰치)
- 내레이션: 지켜보던 친구들이 짝짝짝, 박수를 쳤다.
- 효과음: 짝짝짝

## 4컷 · 귀가 한 뼘 길어진 콩지의 인사
- 하늘: warm / 땅 높이 40% / 칸 모양: 기본
- 배경 소품: `hot-sunrise-hill`(임시, left 0%, bottom 24%, width 100%) — 없으면 `stone-yard`로 대체하고 구석에 '임시' 표시
- 몬스터: 콩지 (left 30%, top 30%, width 40%) — 귀가 길어 보이게 약간 위로
- 포즈/연출: `hop` 한 번 뒤 고개를 꾸벅. 귀 끝에 따끈한 빛 `flare`. 별 `twinkle` 3개
- 말풍선: 「…콩, 콩. 안녕… 이제, 같이 넘자.」 (pop)
- 내레이션: 귀가 한 뼘 길어진 콩지가, 수줍게 인사했다.
- 효과음: 없음
