# lion-2 · 끈기 2화 「끝까지 푼 문제」

- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `bright-reading-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 어려운 문제 앞에서 끈기가 포기하고 싶어 한다 → 돌봄이가 옆에서 한 줄만 더 가자고 한다 → 끝까지 풀고 처음으로 활짝 웃는다
- 말버릇: 끈기 "으르렁— 아니, …뜻이야!". 돌봄이의 "한 줄만 더"는 손가락 하나 + 내레이션으로 바꿨다. 줄거리가 세 흐름이라 3컷(한 줄씩 푸는 모습)을 덧붙여 4컷으로 했다

## 1컷 · 포기하고 싶다
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 0%, bottom 10%, width 74%)
- 몬스터: 끈기 (left 22%, top 36%, width 38%) `shiver`, 식은땀
- 말풍선: 「으르렁… 못 하겠어…」 (작게)
- 내레이션: 문제가 너무 어려워서, 끈기는 그만하고 싶어졌다.
- 효과음: 끙

## 2컷 · 한 줄만 더
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 0%, bottom 10%, width 74%)

- 포즈/연출: 돌봄이의 손이 손가락 하나를 폄. 따뜻한 빛

- 내레이션: 돌봄이가 손가락 하나를 폈다. 딱 한 줄만 더 가 보자고.
- 효과음: 없음
