# village-bright-3 · 반짝마을 3장 「끝까지 읽은 날」

- 마을: 반짝마을 · 공부 / 종류: 마을 장(chapter) / 열리는 때: 반짝마을 종을 4종 모두 잡을 때
- 표지 소품: `bright-open-book` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 끈기가 두꺼운 책을 끝까지 읽겠다고 선언하고 벌벌 떤다 → 셋이 번갈아 한 쪽씩 읽어 준다 → 마지막 장을 덮자 모두 환호한다 → 하루나무 잎에 금빛 줄이 생긴다
- 말버릇: 끈기 "으르렁—", 토독 "토독, …", 번득이 "아! 잠깐!"

## 1컷 · 끝까지 읽겠다는 선언
- 하늘: high / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `bright-open-book`(임시, left 14%, bottom 10%, width 72%)
- 몬스터: 끈기 (left 28%, top 32%, width 40%) `shiver`, 식은땀
- 말풍선: 「으르렁— 끝까지 읽을 거야!」 (pop)
- 내레이션: 끈기가 두꺼운 책을 끝까지 읽겠다고 선언했다. 다리는 벌벌 떨렸다.
- 효과음: 없음

- 몬스터: 끈기 (left 4%, top 34%, width 24%) · 토독 (left 34%, top 28%, width 18%) `hop` · 번득이 (left 54%, top 28%, width 18%) · 둥실 (left 74%, top 28%, width 20%)
- 말풍선: 「토독, 한 쪽 읽을게!」 · 「다음은 나! 아! 잠깐!」 (작게)
- 내레이션: 셋이 번갈아, 한 쪽씩 읽어 주었다.
- 효과음: 없음

## 3컷 · 환호
