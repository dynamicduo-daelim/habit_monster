# anaconda-1 · 길쭉 1화 「쭈우우욱」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: 호감도 '친해진'(4 이상)
- 표지 소품: `hot-warm-rock` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음 (기본 `anaconda.png`)
- 줄거리 순서: 바위 위에서 길게 늘어져 있다 → 돌봄이가 그 옆에서 몸을 쭉 편다 → 길쭉이 천천히 따라 한다 → "…천천히 해도 돼." 하고 눈을 가늘게 뜬다
- 말버릇: 길쭉 '쭈우우욱… 천천히 해도 돼'

## 1컷 · 바위 위에 길게 늘어진 길쭉
- 하늘: morning / 땅 높이 24% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-warm-rock`(임시, left 12%, bottom 10%, width 76%) · `village-path` 멀리(far, left -8%, bottom 4%, width 50%) · 픽셀 구름 2개
- 몬스터: 길쭉 (left 20%, top 24%, width 56%) — 바위 위에 축 늘어짐
- 포즈/연출: `warm` 김이 바위에서 천천히 올라옴. 길쭉은 거의 안 움직이고 꼬리 끝만 느리게 흔들림
- 말풍선: 「쭈우우욱… 아직 아침이네…」 (작게)
- 내레이션: 따끈마을의 따뜻한 바위 위. / 길쭉은 오늘도 길게 늘어져 있었다.
- 효과음: 모락모락

## 2컷 · 돌봄이가 옆에서 몸을 쭉 편다
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `hot-warm-rock`(임시, left -4%, bottom 12%, width 80%)
- 몬스터: 길쭉 (left 24%, top 36%, width 52%) — 고개만 살짝 돌림
- 포즈/연출: 화면 오른쪽 아래에서 돌봄이의 손 그림자가 위로 쭉 뻗음(`reach`, left 62%, bottom 4%, width 30%). 손 뒤로 `warm` 빛
- 말풍선: 「…뭐 하는 거야?」 (작게)
- 내레이션: 돌봄이가 바위 옆에서 두 팔을 위로 쭉 폈다.
- 효과음: 쭈욱

## 3컷 · 길쭉이 천천히 따라 한다
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `hot-warm-rock`(임시, left -4%, bottom 12%, width 80%)
- 몬스터: 길쭉 (left 24%, top 14%, width 52%) — 몸 앞쪽이 천천히 위로 솟음
- 포즈/연출: 느린 `reach`(위로 길게 늘어남). 손 그림자는 옆에서 같이 올라가 나란히 선다. 몸 곳곳 `twinkle` 3개
- 말풍선: 「쭈우우욱… 이렇게…?」 (pop, 작게)
- 내레이션: 길쭉은 아주 천천히, 같은 모양으로 몸을 폈다.
- 효과음: 쭈우우욱…

## 4컷 · 천천히 해도 돼
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `hot-warm-rock`(임시, left 8%, bottom 10%, width 84%)
- 몬스터: 길쭉 (left 26%, top 36%, width 48%) — 눈을 가늘게 뜸
- 포즈/연출: `warm` 빛이 길쭉 몸을 감쌈. 손 그림자가 옆에서 가만히 쉬고 있음
- 말풍선: 「…천천히 해도 돼. 같이 쭈우우욱.」 (pop)
- 내레이션: 길쭉이 눈을 가늘게 뜨고 웃었다. 서두를 일이 없는 아침이었다.
- 효과음: 없음
