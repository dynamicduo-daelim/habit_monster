# badger-2 · 다래 2화 「편식 친구 달래기」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `yum-berry-bush` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 푸릇이가 채소를 안 먹는다 → 다래가 보물찾기처럼 숨겨 둔다 → 돌봄이가 찾고 푸릇이도 따라 찾는다 → 셋이 열매를 나눠 먹는다
- 말버릇: 다래 "찾았다!", 푸릇이 "푸릇… 참아야 해!"

## 1컷 · 입을 꾹 다문 푸릇이
- 하늘: high / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 48%, bottom 20%, width 18%)
- 몬스터: 푸릇이 (left 20%, top 38%, width 32%, `shiver`) · 다래 (left 64%, top 34%, width 28%)
- 포즈/연출: 푸릇이가 채소 그릇 앞에서 고개를 홱 돌리고 입을 꾹 다묾
- 말풍선: 「푸릇… 초록 잎은 안 먹어!」 (작게) · 「음, 그래?」 (작게)
- 내레이션: 식탁 앞, 푸릇이가 채소를 먹기 싫다며 입을 꾹 닫았다.
- 효과음: 홱

## 2컷 · 보물찾기 덤불
- 하늘: high / 땅 높이 26% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-berry-bush`(임시, left 18%, bottom 10%, width 64%)
- 몬스터: 다래 (left 40%, top 28%, width 30%, `pop`)
- 포즈/연출: 다래가 덤불 사이사이에 맛있는 채소와 열매를 쏙쏙 숨겨 둠
- 말풍선: 「찾았다! …가 아니라 보물찾기 시작!」 (pop tail-right)
- 내레이션: 다래는 채소와 열매를 덤불 곳곳에 숨기며 보물찾기 판을 벌였다.
- 효과음: 쏙쏙

## 3컷 · 보물 발견
- 하늘: warm / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-berry-bush`(임시, left 14%, bottom 8%, width 72%)
- 몬스터: 푸릇이 (left 22%, top 36%, width 28%, `hop`) · 다래 (left 66%, top 32%, width 28%)
- 포즈/연출: 돌봄이의 손이 잎사귀를 들추자 푸릇이가 신나서 열매를 찾아냄. 반짝 2개
- 말풍선: 「푸릇! 여기 방울토마토 찾았다!」 (pop) · 「오, 잘 찾네!」 (작게)
- 내레이션: 돌봄이와 함께 찾던 푸릇이도 어느새 신이 나서 잎사귀를 들췄다.
- 효과음: 찾았다!

## 4컷 · 셋이 나눈 삼시 세끼
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 12%, bottom 8%, width 76%)
- 몬스터: 푸릇이 (left 16%, top 36%, width 28%) · 다래 (left 44%, top 32%, width 28%, `jump`)
- 포즈/연출: 찾은 채소와 열매를 한 접시에 모아 돌봄이와 셋이 나눠 먹음. 따뜻한 빛
- 말풍선: 「찾았다! 골고루 먹으니까 힘이 불끈 나!」 (pop)
- 내레이션: 보물처럼 찾아낸 채소들을 나눠 먹자, 식탁 위에 웃음꽃이 피었다.
- 효과음: 아삭아삭
