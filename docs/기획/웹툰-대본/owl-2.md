# owl-2 · 밤톨 2화 「잔걱정 한 보따리」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `yum-long-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 밤톨이 친구들의 식사를 하나하나 챙기다 지친다 → 돌봄이가 "밤톨도 먹어야지" 한다 → 못 이기는 척 앉아 먹는다 → 포근한 얼굴이 된다
- 말버릇: 밤톨 "부엉. 밥은 먹었니?" 안부부터 묻는다

## 1컷 · 잔걱정 부엉이의 날갯짓
- 하늘: warm / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 48%, bottom 20%, width 18%)
- 몬스터: 밤톨 (left 26%, top 30%, width 36%, `shiver`)
- 포즈/연출: 그릇들을 이리저리 옮기며 날개를 쉬지 못하고 퍼덕임. 식은땀
- 말풍선: 「부엉… 오물이는 꼭꼭 씹었나, 푸릇이는 야식을 참았나…」 (작게)
- 내레이션: 밤톨은 온 마을 친구들의 식사를 챙기느라 날개가 쉴 틈이 없었다.
- 효과음: 파닥파닥

## 2컷 · 주저앉은 날개
- 하늘: warm / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%)
- 몬스터: 밤톨 (left 32%, top 42%, width 36%)
- 포즈/연출: 날개를 축 늘어뜨리고 테이블 구석에 지쳐 털썩 주저앉음
- 말풍선: 「부엉… 다들 챙기느라 정작 나는 한 숟가락도 못 떴네…」 (작게)
- 내레이션: 모두를 챙기느라 정작 자기 밥상은 돌아보지 못한 채, 밤톨은 지쳐 버렸다.
- 효과음: 후유

## 3컷 · 밤톨을 위한 한 그릇
- 하늘: warm / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 40%, bottom 18%, width 20%)
- 몬스터: 밤톨 (left 34%, top 34%, width 34%)
- 포즈/연출: 돌봄이의 손이 따뜻한 밥그릇과 나무 숟가락을 밤톨 앞에 살며시 놓아 줌. 따뜻한 빛
- 말풍선: 「부엉…? 이건 날 위한 밥상인 게야?」 (pop tail-right)
- 내레이션: 그때 돌봄이가 다가와 밤톨의 앞에도 따뜻한 밥 한 그릇을 놓아 주었다.
- 효과음: 달칵

## 4컷 · 포근해진 깃털
- 하늘: dusk / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `yum-rice-bowl`(임시, left 38%, bottom 14%, width 24%)
- 몬스터: 밤톨 (left 30%, top 32%, width 38%)
- 포즈/연출: 밥을 든든하게 먹고 포근한 미소를 지으며 날개를 둥글게 모음. 반짝 2개
- 말풍선: 「부엉… 남이 차려 준 밥이 이렇게 따뜻할 줄이야.」 (pop tail-right)
- 내레이션: 못 이기는 척 한 숟가락을 비우자, 밤톨의 깃털이 솜이불처럼 포근해졌다.
- 효과음: 모락모락
