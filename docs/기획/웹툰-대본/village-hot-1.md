# village-hot-1 · 따끈마을 1장 「식어 가는 운동장」

- 마을: 따끈마을 · 운동 / 종류: 마을 장(chapter) / 열리는 때: 따끈마을 종을 1종 잡을 때
- 표지 소품: `stone-yard`
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 운동장 돌바닥이 따뜻하지 않아 주민들이 이불 속에서 안 나온다 → 돌봄이가 첫 스트레칭을 한다 → 발밑 돌이 조금 데워진다 → 한 마리씩 얼굴을 내민다
- 주민은 이 장에서 아직 한 마리도 만나지 않은 상태라 1컷은 실루엣(검은 윤곽)으로, 4컷에서 모습이 드러난다
- 말버릇: 모닥이 '~끽', 콩지 '…콩, 콩.', 홰치 '꼬오—' 뒤 하품, 길쭉 '쭈우우욱…', 놀빛 '…봐도 돼.'

## 1컷 · 식어 가는 운동장
- 하늘: morning / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom 4%, width 88%) · `village-square` 멀리(far, left -8%, bottom 22%, width 60%)
- 몬스터: 없음. 집 창문마다 이불 속 실루엣 다섯 개(left 8% · 24% · 40% · 58% · 76%, top 14%, width 14%)
- 포즈/연출: 돌바닥 위로 차가운 푸른 기운이 감돌고 김이 없음. 실루엣은 꿈틀 `shiver`(아주 작게)
- 말풍선: 「으… 추워… 조금만 더…」 (작게, 이불 속에서)
- 내레이션: 따끈마을의 돌바닥이 오늘은 따뜻하지 않았다. / 모두 이불에서 나오지 못했다.
- 효과음: 으슬으슬

## 2컷 · 돌봄이가 첫 스트레칭을
- 하늘: morning / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 4%, bottom 4%, width 92%)
- 몬스터: 없음
- 포즈/연출: 화면 아래에서 돌봄이의 손 그림자가 두 팔을 위로 쭉 폄(`reach`, left 32%, bottom 0%, width 38%). 팔 끝에서 `warm` 빛
- 말풍선: 없음
- 내레이션: 돌봄이가 운동장 한가운데에서, 첫 스트레칭을 했다.
- 효과음: 쭈욱

## 3컷 · 발밑 돌이 조금 따뜻해진다
- 하늘: warm / 땅 높이 36% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 0%, bottom -10%, width 100%, 가까이 크게)
- 몬스터: 없음
- 포즈/연출: 돌바닥 한 칸이 `flare`로 붉게 달아오르고 김이 모락모락. 그 주위로 `twinkle` 4개. 손 그림자는 가장자리에서 쉬고 있음
- 말풍선: 없음
- 내레이션: 발밑의 돌이 조금씩 데워지기 시작했다.
- 효과음: 모락모락

## 4컷 · 한 마리씩 얼굴을 내민다
- 하늘: morning / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `village-square`(left -6%, bottom 8%, width 92%) · `stone-yard`(left 20%, bottom 0%, width 60%)
- 몬스터: 모닥이 (left 8%, top 38%, width 16%) · 콩지 (left 30%, top 42%, width 14%, 귀만 빼꼼) · 홰치 (left 52%, top 40%, width 14%) · 길쭉 (left 70%, top 50%, width 24%, 고개만) — 집 문틈으로 얼굴만
- 포즈/연출: 문이 하나씩 열리며 `pop`. 놀빛은 맨 오른쪽 창문 뒤 그림자로만 보임(아직 수줍음)
- 말풍선: 「따뜻하다끽…?」 (작게, 모닥이) · 「…콩, 콩. 누구세요.」 (작게, 콩지)
- 내레이션: 따뜻한 기운에, 한 마리씩 얼굴을 내밀었다.
- 효과음: 끼익
