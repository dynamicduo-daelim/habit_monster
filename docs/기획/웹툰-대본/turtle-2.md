# turtle-2 · 오물 2화 「천천히 먹는 비밀」

- 마을: 냠냠마을 · 식습관 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `yum-long-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 오물이 돌봄이에게 꼭꼭 씹는 법을 알려 준다 → 서두르다 목이 막혀 기침한다 → 오물이 등을 톡톡 두드린다 → 천천히 먹으니 맛이 더 난다는 걸 알게 된다
- 말버릇: 오물 "오물오물… 음, 맛있다." 먹으며 말한다

## 1컷 · 꼭꼭 씹는 비법
- 하늘: high / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 48%, bottom 20%, width 18%)
- 몬스터: 오물 (left 16%, top 34%, width 34%)
- 포즈/연출: 입을 크게 오물거리며 시범을 보이는 오물
- 말풍선: 「오물오물… 삼키기 전에 열 번 세는 거야.」 (pop)
- 내레이션: 오물이 돌봄이에게 꼭꼭 씹는 비법을 알려 주었다.
- 효과음: 냠냠

## 2컷 · 켁켁! 서두르다 목이 막히다
- 하늘: high / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-water-pitcher`(임시, left 74%, bottom 20%, width 16%)
- 몬스터: 오물 (left 18%, top 36%, width 32%)
- 포즈/연출: 돌봄이의 손이 가슴을 짚으며 기침(식은땀 연출). 오물이 깜짝 놀라 눈을 크게 뜸
- 말풍선: 「오물?! 서두르면 안 돼!」 (pop tail-right)
- 내레이션: 서둘러 삼키려다 목이 턱 막혀 버렸다.
- 효과음: 켁켁

## 3컷 · 등을 톡톡
- 하늘: warm / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-water-pitcher`(임시, left 74%, bottom 20%, width 16%)
- 몬스터: 오물 (left 34%, top 34%, width 32%)
- 포즈/연출: 오물이 `hop`하며 돌봄이의 등을 앞발로 톡톡 두드려 줌. 돌봄이의 손이 물잔을 받음
- 말풍선: 「오물오물… 천천히, 숨 쉬고.」 (작게)
- 내레이션: 오물이 작은 발로 등을 톡톡 두드려 주었다.
- 효과음: 토닥토닥

## 4컷 · 천천히 느끼는 맛
- 하늘: warm / 땅 높이 30% / 칸 모양: 기본
- 배경 소품: `yum-rice-bowl`(임시, left 38%, bottom 14%, width 24%)
- 몬스터: 오물 (left 32%, top 32%, width 36%)
- 포즈/연출: `warm`으로 편안한 미소. 반짝 2개
- 말풍선: 「오물오물… 음, 이제 맛이 나지?」 (pop tail-right)
- 내레이션: 천천히 꼭꼭 씹으니, 단맛이 입안 가득 번져 왔다.
- 효과음: 꿀꺽
