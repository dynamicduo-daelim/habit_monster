# village-yum-1 · 냠냠마을 1장 「텅 빈 식탁」

- 마을: 냠냠마을 · 식습관 / 종류: 마을 장(chapter) / 열리는 때: 냠냠마을 종 1종 잡을 때
- 표지 소품: `yum-long-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 마을 식탁이 비고 모두 간식으로 때우고 있다 → 돌봄이가 따뜻한 밥 한 그릇을 내놓는다 → 김이 솔솔 올라온다 → 하나둘 식탁으로 모인다
- 말버릇: 오물 "오물오물…", 밤톨 "부엉."

## 1컷 · 텅 빈 식탁과 부스러기
- 하늘: warm / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `village-square` 멀리(far, left -10%, bottom 4%, width 70%)
- 몬스터: 오물 (left 12%, top 44%, width 24%) · 푸릇이 (left 68%, top 42%, width 22%)
- 포즈/연출: 마을 식탁은 휑하고, 몬스터들이 구석에서 마른 과자 부스러기만 깨작거림
- 말풍선: 「오물오물… 배는 안 부른데…」 (작게)
- 내레이션: 냠냠마을의 넓은 식탁은 텅 비어 있었고, 모두 주전부리로 끼니를 때우고 있었다.
- 효과음: 바삭

## 2컷 · 따뜻한 밥 한 그릇
- 하늘: warm / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `yum-long-table`(임시, left 8%, bottom 10%, width 84%) · `yum-rice-bowl`(임시, left 42%, bottom 18%, width 22%)
- 몬스터: 밤톨 (left 18%, top 32%, width 26%)
- 포즈/연출: 돌봄이의 따뜻한 손이 식탁 한가운데에 김이 모락모락 나는 밥 한 그릇을 정성껏 내놓음
- 말풍선: 「부엉…?! 저건 따뜻한 밥?」 (작게)
- 내레이션: 그때 돌봄이가 다가와 식탁 가운데에 갓 지은 밥 한 그릇을 정성스레 내려놓았다.
- 효과음: 달칵

## 3컷 · 피어오르는 김
- 하늘: warm / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `yum-rice-bowl`(임시, left 34%, bottom 14%, width 32%)
- 포즈/연출: 하얀 쌀밥 위로 따뜻한 김이 피어오르며 식탁 전체를 감싸 안음. 은은한 빛
- 내레이션: 구수한 밥 냄새와 함께, 포근한 김이 솔솔 피어올랐다.
- 효과음: 모락모락

## 4컷 · 하나둘 모여드는 친구들
- 하늘: warm / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `yum-long-table`(임시, left 12%, bottom 8%, width 76%) · `yum-rice-bowl`(임시, left 44%, bottom 18%, width 18%)
- 몬스터: 오물 (left 8%, top 40%, width 18%) · 푸릇이 (left 26%, top 42%, width 16%) · 밤톨 (left 44%, top 28%, width 20%, `hop`) · 다래 (left 66%, top 38%, width 16%) · 쪼르 (left 82%, top 40%, width 16%)
- 포즈/연출: 맛있는 냄새를 맡고 마을 친구들이 하나둘 식탁 의자에 모여 앉음. 반짝 2개
- 말풍선: 「부엉, 다 같이 앉자!」 (pop) · 「오물오물… 밥이다!」 (작게)
- 내레이션: 구수한 냄새를 따라, 냠냠마을 친구들이 하나둘 식탁 둘레로 모여들었다.
- 효과음: 총총
