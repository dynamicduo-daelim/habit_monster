# anaconda-3 · 길쭉 3화 「더 길고 따뜻하게」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `hot-warm-rock` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): `anaconda_2.png`가 없음 → 2 ~ 4컷은 기본 `anaconda.png`를 1.15배로 키우고 `glow`를 더함
- 줄거리 순서: 몸이 근질근질하며 늘어난다 → 놀라 똬리를 튼다 → 마을 친구들이 몸 위에 올라 앉아 본다 → 넓은 몸으로 모두를 태우고 한 바퀴 돈다
- 말버릇: 길쭉 '쭈우우욱… 천천히 해도 돼', 모닥이 '~끽', 콩지 '…콩, 콩.'

## 1컷 · 몸이 근질근질
- 하늘: morning / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `hot-warm-rock`(임시, left 8%, bottom 10%, width 84%)
- 몬스터: 길쭉 (left 22%, top 30%, width 52%)
- 포즈/연출: `shiver`(작게)로 몸이 부르르. 몸 마디마다 붉은 불빛이 `twinkle`
- 말풍선: 「쭈…? 몸이 근질근질해…」 (작게)
- 내레이션: 어느 날 아침, 몸속이 근질근질했다.
- 효과음: 근질근질

## 2컷 · 쭈우욱 늘어나다 놀라서 똬리
- 하늘: high / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-warm-rock`(임시, left 10%, bottom 8%, width 80%)
- 몬스터: 길쭉 (기본 그림 1.15배 + `glow`, left 16%, top 22%, width 62%)
- 포즈/연출: 몸이 한 뼘 더 길어지며 `flare`. 놀라 몸을 둥글게 말아 똬리를 틂(`pop`)
- 말풍선: 「쭈우욱…?! 더 길어졌어…!」 (pop)
- 내레이션: 몸이 한 뼘 더 길어져서, 길쭉도 깜짝 놀랐다.
- 효과음: 쭈우욱!

## 3컷 · 친구들이 올라 앉아 본다
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom 4%, width 88%)
- 몬스터: 길쭉 (1.15배 + `glow`, left 14%, top 36%, width 62%) 똬리 · 모닥이 (left 30%, top 18%, width 16%) 몸 위 · 콩지 (left 52%, top 22%, width 16%) 몸 위
- 포즈/연출: 모닥이는 `hop`으로 폴짝 올라가고, 콩지는 귀를 쫑긋하며 조심조심 오름
- 말풍선: 「넓다끽! 포근하다끽!」 (작게, 모닥이) · 「…콩, 콩. 따뜻해.」 (작게, 콩지)
- 내레이션: 마을 친구들이 하나둘, 길쭉의 넓은 몸에 올라 앉았다.
- 효과음: 폴짝

## 4컷 · 모두를 태우고 한 바퀴
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `stone-yard`(left 6%, bottom 4%, width 88%) · `village-square` 멀리(far, left 52%, bottom 10%, width 46%)
- 몬스터: 길쭉 (1.15배 + `glow`, left 12%, top 38%, width 64%) · 모닥이 (left 28%, top 22%, width 14%) · 콩지 (left 48%, top 26%, width 14%)
- 포즈/연출: 길쭉이 천천히 큰 원을 그리며 앞으로 미끄러짐. 바닥에 `warm` 빛 자국이 따라옴
- 말풍선: 「쭈우우욱… 천천히 한 바퀴. 같이 가자.」 (pop)
- 내레이션: 길쭉은 넓은 몸으로 모두를 태우고, 천천히 한 바퀴 돌았다.
- 효과음: 스르르
