# squirrel-2 · 새근이 2화 「꿈 모으기」

- 마을: 소곤마을 · 수면 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `whisper-crescent-moon` (임시)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 꿈을 모아 병에 담는다 → 돌봄이에게도 한 조각 나눠 준다 → 그날 밤 돌봄이가 좋은 꿈을 꾼다 → 아침에 둘이 꿈 이야기를 나눈다
- 말버릇: 새근이 "새근… 쿨…"

## 1컷 · 꿈 병
- 하늘: dusk / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `whisper-crescent-moon`(임시, 멀리)
- 몬스터: 새근이 (left 14%, top 40%, width 32%) — `pop`
- 포즈/연출: 반짝 3개
- 말풍선: 「새근… 꿈이 포옥 들어가.」 (작게)
- 내레이션: 새근이는 꿈을 하나둘 병에 담았다.
- 효과음: 없음

## 2컷 · 한 조각 나눔
- 하늘: dusk / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `whisper-leaf-bed`(임시)
- 몬스터: 새근이 (left 14%, top 40%, width 32%)
- 포즈/연출: 돌봄이의 손 + 따뜻한 빛
- 말풍선: 「이건 너 거야… 쿨.」 (작게)
- 내레이션: 새근이가 돌봄이에게도 한 조각을 나눠 주었다.
- 효과음: 없음

## 3컷 · 좋은 꿈
- 하늘: dusk / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `whisper-crescent-moon`(임시, 멀리) · `whisper-leaf-bed`(임시)
- 몬스터: 없음
- 포즈/연출: 반짝 4개, 따뜻한 빛
- 말풍선: 없음
- 내레이션: 그날 밤, 돌봄이는 좋은 꿈을 꾸었다.
- 효과음: 쿨 (18)

## 4컷 · 꿈 이야기
- 하늘: morning / 땅 높이 28% / 칸 모양: 기본
- 배경 소품: `whisper-leaf-bed`(임시)
- 몬스터: 새근이 (left 22%, top 38%, width 32%) — `warm`
- 포즈/연출: 돌봄이의 손 + 따뜻한 빛
- 말풍선: 「어땠어? 새근… 좋았지?」 (작게)
- 내레이션: 아침에 둘이 꿈 이야기를 나누었다.
- 효과음: 없음
