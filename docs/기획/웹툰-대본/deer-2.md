# deer-2 · 번득이 2화 「아! 잠깐 잠깐」

- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: 단짝 (호감도 7)
- 표지 소품: `bright-reading-table` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 쓰지 않음
- 줄거리 순서: 문제를 풀다 말고 딴 생각이 난다 → 돌봄이가 "하나만 끝내 보자"고 한다 → 끝까지 푼 문제에 동그라미가 쳐진다 → 뿔에 작은 번개가 한 번 지나간다
- 말버릇: 번득이 "아! 잠깐, 잠깐만!". 돌봄이의 "하나만 끝내 보자"는 손가락 하나 + 내레이션으로 바꿨다

## 1컷 · 딴 생각
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 0%, bottom 8%, width 76%) · 구름 2개
- 몬스터: 번득이 (left 24%, top 36%, width 32%) `hop`
- 말풍선: 「아! 잠깐, 저 구름 좀 봐!」 (pop)
- 내레이션: 문제를 풀다 말고, 번득이는 창밖 구름이 눈에 들어왔다.
- 효과음: 두리번

## 2컷 · 손가락 하나
- 하늘: high / 땅 높이 24% / 칸 모양: 기본
- 배경 소품: `bright-reading-table`(임시, left 0%, bottom 8%, width 76%)
- 몬스터: 번득이 (left 14%, top 40%, width 30%)
- 포즈/연출: 돌봄이의 손이 손가락 하나를 폄. 따뜻한 빛
- 말풍선: 「하나만…? 아! 알았어!」 (작게)
- 내레이션: 돌봄이가 손가락 하나를 폈다. 하나만 끝내 보자고.
- 효과음: 없음

## 3컷 · 동그라미
- 하늘: warm / 땅 높이 28% / 칸 모양: 넓게(wide)
- 배경 소품: `bright-reading-table`(임시, left 14%, bottom 6%, width 72%)
- 몬스터: 번득이 (left 34%, top 20%, width 30%) `hop`
- 말풍선: 「다 풀었다! 동그라미!」 (pop)
- 내레이션: 끝까지 푼 문제에 큼직한 동그라미가 쳐졌다.
- 효과음: 쓱

## 4컷 · 작은 번개
- 하늘: dusk / 땅 높이 26% / 칸 모양: 기본
- 배경 소품: `bright-lantern`(임시, left 8%, bottom 30%, width 12%) · `bright-bookshelf`(임시, left 60%, bottom 14%, width 36%)
- 몬스터: 번득이 (left 24%, top 32%, width 36%) `pop`
- 포즈/연출: 뿔 위로 번개 빛(flare)이 한 번 지나감
- 말풍선: 「아! 잠깐, 뿔이 반짝했어!」 (pop)
- 내레이션: 뿔 위로 작은 번개가 한 번 지나갔다.
- 효과음: 파직
