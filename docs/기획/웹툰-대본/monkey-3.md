# monkey-3 · 모닥이 3화 「불씨가 모닥불이 되던 날」

- 마을: 따끈마을 · 운동 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `hot-warm-rock` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 사용함. `monkey_2.png`가 있다. 1 · 2컷은 기본 `monkey.png`(불씨가 막 커지는 때), 3 · 4컷은 `monkey_2.png`(자란 모습)
- 줄거리 순서: 이마 불씨가 간질간질 커진다 → 놀라서 콩지 뒤에 숨는다 → 따뜻해진 걸 아는 친구들이 둘러앉는다 → 몸이 한 뼘 자라 신나게 "끽!" 한다
- 말버릇: 모닥이 '~끽', 콩지 '…콩, 콩.'

## 1컷 · 이마가 간질간질
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `village-square`(left -4%, bottom 6%, width 90%) · `haru-tree` 멀리(far, right -6%, bottom 18%, width 36%)
- 몬스터: 모닥이 (left 32%, top 34%, width 32%)
- 포즈/연출: 이마에서 불씨 빛이 `flare`로 점점 커지고 모닥이는 `shiver`
- 말풍선: 「이마가 간질간질하다끽…?」 (작게)
- 내레이션: 이마의 불씨가 간질간질 커지기 시작했다.
- 효과음: 따끈따끈

## 2컷 · 놀라서 콩지 뒤에 숨는다
- 하늘: morning / 땅 높이 22% / 칸 모양: 기본
- 배경 소품: `village-square`(left -4%, bottom 6%, width 90%)
- 몬스터: 콩지 (left 42%, top 36%, width 30%) 앞 · 모닥이 (left 24%, top 40%, width 24%) 뒤쪽 반쯤 가려짐
- 포즈/연출: 모닥이 `hop`으로 콩지 뒤로 뛰어듦, 이마 빛이 콩지 어깨 너머로 보임. 콩지는 귀가 쫑긋
- 말풍선: 「끽! 불, 불이 커졌다끽!」(pop, 모닥이) · 「…콩, 콩. 따뜻해.」(작게, 콩지)
- 내레이션: 놀란 모닥이가 콩지 뒤로 쏙 숨었다.
- 효과음: 쏙

## 3컷 · 둘러앉은 친구들
- 하늘: warm / 땅 높이 30% / 칸 모양: 넓게(wide)
- 배경 소품: `hot-warm-rock`(임시, left 30%, bottom 22%, width 44%) — 없으면 `stone-yard`로 대체하고 구석에 '임시' 표시
- 몬스터: 모닥이 `_2` (left 38%, top 34%, width 28%) 가운데 · 콩지 (left 8%, top 46%, width 22%) · 홰치 (left 70%, top 46%, width 22%)
- 포즈/연출: 모닥이 이마의 모닥불 빛이 `warm`으로 일렁이고, 친구들이 둥글게 앉아 불빛을 쬠. 따뜻한 빛 `glow` 모닥이 뒤
- 말풍선: 「…콩, 콩. 포근해.」(작게, 콩지) · 「꼬오— 따뜻하다… 하아암.」(작게, 홰치)
- 내레이션: 따뜻해진 걸 안 친구들이 하나둘 둘러앉았다.
- 효과음: 없음

## 4컷 · 한 뼘 자란 모닥이
- 하늘: high / 땅 높이 40% / 칸 모양: 기본
- 배경 소품: `stone-yard`(left 10%, bottom -18%, width 80%)
- 몬스터: 모닥이 `_2` (left 28%, top 26%, width 42%)
- 포즈/연출: `hop`으로 힘차게 한 번 뜀. 이마 모닥불이 `flare`, 별 `twinkle` 4개
- 말풍선: 「끽! 나 조금 컸다끽!」 (pop, 오른쪽 위)
- 내레이션: 몸이 한 뼘 자란 모닥이가 신나게 "끽!" 했다.
- 효과음: 와아—
