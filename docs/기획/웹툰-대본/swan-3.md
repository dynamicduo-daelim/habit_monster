- 마을: 반짝마을 · 공부 / 종류: 종 화(species) / 열리는 때: Lv.10 (1차 진화)
- 표지 소품: `bright-bookshelf` (임시 — Ludo 시트 파일 이름)
- 진화 그림(_2): 사용함. `swan_2.png`가 있다 → 1 ~ 4컷 모두 `swan_2`
