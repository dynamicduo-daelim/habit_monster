## 1부. 28종 이름 · 성격 표

### 이름 규칙 (D-63 후보)
1. 2 ~ 4글자, 28종끼리 겹치지 않는다. 같은 글자로 끝나는 이름도 되도록 피한다 (부르기 헷갈림 방지).
2. 그 종의 **습관 · 도감 설명**에서 소리/모양 말(의성어 · 의태어)을 따온다. 원래 이름의 속성 말(불씨 · 번개 · 이끼 …)은 이름에서 빼고 성격으로 옮긴다.
3. 받침 있는 이름은 조사를 맞춘다 (`josaIGa` 등). 아래 표의 "받침" 열이 O이면 이/을/은, X이면 가/를/는.

## 2부. 세계관 · 마을 6개 · 메인 3장

### 세계관 (한 단락)
모아땅은 작은 몬스터들이 사는 포근한 땅이다. 한가운데에 **하루나무**가 한 그루 서 있는데, 이 나무는 누군가 하루치 작은 일(몸 풀기, 한 쪽 읽기, 물 한 잔, 숨 고르기, 일찍 눕기, 동전 한 닢)을 해낼 때마다 잎이 한 장 돋는다. 나무 둘레로 여섯 마을이 둥글게 모여 있고, 마을마다 하는 일이 다르지만 몬스터들은 모두 **서툴러도 괜찮다**고 믿는다. 어느 날 돌봄이(= 사용자)가 이 땅에 오면서 잎이 다시 돋기 시작하고, 몬스터들은 돌봄이와 함께 지내며 조금씩 자란다. 나쁜 일을 꾸미는 이도, 무서운 싸움도 없다. 이 땅의 가장 큰 사건은 "오늘 잎이 몇 장 났나"다.

- 돌봄이: 이야기 속 사용자. 말은 하지 않고 컷에서는 손 모양(그림자)이나 따뜻한 빛으로만 나온다 [가정].
- 이야기의 힘은 큰 사건이 아니라 **작은 첫걸음**에서 나온다. 모든 장은 "서툴렀지만 같이 해서 해냈다"로 끝난다.

### 장 · 컷 규칙 (11-02 기획서를 따름)
- 여는 조건: 그 마을 종을 **1종 · 절반 · 전부** 잡으면 1 · 2 · 3장 (절반 = 종 수를 반으로 올림: 5종→3, 4종→2, 6종→3). 운동 5종은 11-02 기획서의 1 · 3 · 5종과 같다.
- 형식: 한 장 = 웹툰 컷 3 ~ 4컷. 한 컷 = 기존 배경 + 스프라이트 + 감정 아이콘 + 말풍선/내레이션. 큰 사건 · 악당 · 싸움 · 슬픈 결말 없음.
- 장 줄거리 안의 "→"는 컷 순서다. 1장은 어떤 종을 먼저 잡았어도 읽히도록 **마을 주민 전체**가 나온다. 2장부터 구체 종 이름이 나온다.

### 따끈마을 (운동 5종: 모닥이 · 콩지 · 홰치 · 길쭉 · 놀빛)
- 1장 「식어 가는 운동장」(1종): 운동장 돌바닥이 따뜻하지 않아 주민들이 이불 속에서 안 나온다 → 돌봄이가 첫 스트레칭을 한다 → 발밑 돌이 조금 데워진다 → 한 마리씩 얼굴을 내민다.
- 2장 「줄넘기 소리」(3종): 콩지는 줄넘기가 하고 싶지만 부끄러워 구석에서 센다 → 모닥이가 "일단 해보자끽!" 하며 줄 한쪽을 잡아 준다 → 홰치도 졸린 눈으로 박자를 세어 준다 → 셋이 한 번 넘고 운동장이 따뜻해진다.
- 3장 「함께 데운 아침」(5종 전부): 길쭉이 온 마을 스트레칭을 이끌고, 놀빛은 떨며 맨 앞에 선다 → 서툰 몸짓에도 모두 박수를 친다 → 하루나무 잎끝이 붉어지고 → 다섯이 나란히 첫 해를 본다.

### 반짝마을 (공부 4종: 토독 · 번득이 · 둥실 · 끈기)
- 1장 「불이 꺼진 도서관」(1종): 책장이 닫혀 있고 아무도 안 읽는다 → 돌봄이가 책 한 쪽을 펴 읽는다 → 글자 위에 작은 불빛이 켜진다 → 주민들이 하나둘 책을 집는다.
- 2장 「모르는 건 부끄럽지 않아」(2종): 토독이 풀리지 않는 문제를 적어 두고 한숨을 쉰다 → 번득이가 아이디어를 쏟아 내지만 서로 엇갈린다 → 둥실이 말없이 곁에 앉아 준다 → 조용해진 틈에 답이 떠오른다.
- 3장 「끝까지 읽은 날」(4종 전부): 끈기가 두꺼운 책을 끝까지 읽겠다고 선언하고 벌벌 떤다 → 셋이 번갈아 한 쪽씩 읽어 준다 → 마지막 장을 덮자 모두 환호한다 → 하루나무 잎에 금빛 줄이 생긴다.

### 냠냠마을 (식습관 5종: 오물 · 푸릇이 · 다래 · 쪼르 · 밤톨)
- 1장 「텅 빈 식탁」(1종): 마을 식탁이 비고 모두 간식으로 때우고 있다 → 돌봄이가 따뜻한 밥 한 그릇을 내놓는다 → 김이 솔솔 올라온다 → 하나둘 식탁으로 모인다.
- 2장 「편식 탐정 다래」(3종): 푸릇이는 아침 이슬 샐러드가 싫은 척하며 야식 냄새를 쫓는다 → 다래가 열매를 숨겨 두고 보물찾기를 한다 → 오물이 천천히 씹으며 맛을 알려 준다 → 푸릇이가 한 입 먹고 눈이 동그래진다.
- 3장 「오늘은 다 같이 한 상」(5종 전부): 쪼르가 물을 한 잔씩 따르며 건배를 외친다 → 밤톨이 "밥은 먹었니?" 하며 상을 차린다 → 서툰 요리지만 서로 맛을 보며 웃는다 → 하루나무 잎이 탱글탱글해진다.

### 잔잔마을 (명상 4종: 퐁글 · 물멍 · 보슬 · 나울)
- 1장 「시끄러운 개울」(1종): 개울이 졸졸이 아니라 출렁출렁 시끄럽다 → 돌봄이가 눈을 감고 숨을 크게 쉰다 → 물결이 천천히 가라앉는다 → 주민들이 따라서 숨을 쉰다.
- 2장 「멍 때리는 오후」(2종): 퐁글이 숨 쉬는 법을 알려 주고 물멍은 온종일 멍하니 있다 → 처음엔 둘 다 서로 이해 못 하다가 → 같이 개울만 보자 마음이 가벼워진다 → "아, 왔어?" 하고 물멍이 처음으로 먼저 인사한다.
- 3장 「흔들려도 돌아오는 길」(4종 전부): 나울이 파도처럼 마음이 흔들린다고 털어놓는다 → 보슬이 작은 이야기를 속삭인다 → 넷이 나란히 앉아 물소리를 듣는다 → 하루나무 잎에 이슬이 맺힌다.

### 소곤마을 (수면 4종: 새근이 · 초롱 · 포근이 · 아라)
- 1장 「불 켜진 밤」(1종): 밤인데 모두 눈이 말똥말똥하다 → 돌봄이가 작은 불을 하나 끈다 → 마을 등불이 차례로 어두워진다 → 하품이 번져 간다.
- 2장 「잎사귀 침대」(2종): 포근이가 잎사귀로 침대를 만드는데 초롱이 "불 꺼도 돼?" 하며 망설인다 → 새근이가 먼저 누워 "새근… 쿨" 잠든다 → 초롱이 등불을 살짝 줄이고 → 둘이 나란히 누워 별을 센다.
- 3장 「꿈 사이로」(4종 전부): 아라가 꿈 사이를 헤엄쳐 마을 위를 지난다 → 잠든 친구들의 꿈이 한 줄로 이어진다 → 모두 같은 꿈에서 하루나무 아래 모인다 → 아침에 잎이 은색으로 빛난다.

### 알뜰마을 (절약 6종: 짤랑 · 든든 · 미루 · 꼼꼼 · 싹둑 · 차곡)
- 1장 「동전이 굴러간 자리」(1종): 동전이 여기저기 흩어져 마을 장터가 휑하다 → 돌봄이가 동전 하나를 주워 건넨다 → 주민들이 하나씩 줍는다 → 작은 탑이 쌓인다.
- 2장 「사고 싶은 마음」(3종): 짤랑이 반짝이는 장난감에 눈을 못 뗀다 → 미루가 "내일 생각해 보자" 하고 하루만 미룬다 → 든든이 말없이 지갑을 열어 모은 걸 보여 준다 → 다음 날 짤랑은 사지 않고도 웃는다.
- 3장 「가계부 잔치」(6종 전부): 꼼꼼이 모두의 장부를 합산한다 → 싹둑이 새는 곳을 찾아 "싹둑!" 하고 막는다 → 차곡이 쌓인 탑 위에 마지막 동전을 얹는다 → 모자란 줄 알았는데 딱 맞아 모두 박수를 친다.

### 6마을을 잇는 한 줄
여섯 마을 3장을 모두 보면 하루나무에 잎이 가득 차고, 모두가 한자리에 모여 사진을 찍는 짧은 맺음 컷이 열린다 [가정]. 이번 카드 범위 밖이라 3부에서 정하자.

### 검사 결과 (2부)
- 세계관 1단락, 마을 6개 (카테고리와 종 수 일치: 5 · 4 · 5 · 4 · 4 · 6), 메인 3장 × 6 = 18장 작성. 장마다 3 ~ 4컷 흐름.
- 여는 조건 1 · 절반 · 전부가 11-02 기획서와 맞음 (운동 1 · 3 · 5).
- 기존 작품의 이름 · 설정을 쓰지 않음. 마을 이름 6개는 28종 이름과 겹치지 않음.
- 장 줄거리에서 몬스터의 새 이름만 썼다 (원래 이름 없음).

## 3부. 종별 3화 · 친구 관계

### 화 규칙 (11-02 기획서를 따름)
- 1화 = **친해진** 때, 2화 = **단짝**일 때, 3화 = **1차 진화**(Lv.10) 때 열린다. 형식은 웹툰 컷 3 ~ 4컷, "→"가 컷 순서.
- 모든 화는 "작은 서툰 일 → 누군가 곁에서 응원 → 조금 해냄"으로 끝난다. 악당 · 싸움 · 슬픈 결말 없음.
- 돌봄이(사용자)는 말없이 손 그림자나 따뜻한 빛으로만 나온다.

### 따끈마을 (운동)

**모닥이** (monkey)
- 1화 「이마의 작은 불씨」: 돌봄이를 보고 신나서 나무 위로 뛰어오른다 → 내려오지 못하고 "끽…" 하고 작게 운다 → 돌봄이가 손을 내밀어 안아 내린다 → 이마 불씨가 반짝 켜진다.
- 2화 「일단 해보자끽」: 스트레칭 첫날, 모닥이가 너무 빨리 해서 혼자 넘어진다 → 돌봄이와 같은 속도로 천천히 따라 한다 → 같이 끝내고 둘이 엉덩방아를 찧으며 웃는다.
- 3화 「불씨가 모닥불이 되던 날」: 이마 불씨가 간질간질 커진다 → 놀라서 콩지 뒤에 숨는다 → 따뜻해진 걸 아는 친구들이 둘러앉는다 → 몸이 한 뼘 자라 신나게 "끽!" 한다.

**콩지** (rabbit)
- 1화 「구석의 줄넘기」: 아무도 없을 때만 줄넘기를 한다 → 돌봄이가 오자 줄을 등 뒤로 숨긴다 → 돌봄이가 옆에 앉아 세어만 준다 → "…콩, 하나." 처음으로 소리 내어 센다.
- 2화 「셋까지 세는 용기」: 모닥이가 같이 넘자고 한다 → 콩지가 귀를 접고 망설인다 → 돌봄이가 "셋까지만" 한다 → 셋을 넘고 발끝이 따끈해진다.
- 3화 「발이 가벼워진 날」: 몸이 가벼워져 줄 없이도 폴짝 뛴다 → 놀라 귀가 쫑긋 선다 → 친구들이 박수를 친다 → 귀가 한 뼘 길어진 콩지가 수줍게 인사한다.

**홰치** (chicken)
- 1화 「졸린 새벽 알람」: 해 뜨기 전 "꼬오—" 크게 외친다 → 마을은 조용한데 자기만 하품한다 → 돌봄이가 조용히 인사해 준다 → 그제야 첫 해가 올라와 둘이 본다.
- 2화 「깨워 주는 쪽」: 반대로 홰치가 늦잠을 잔다 → 돌봄이가 살그머니 깨운다 → "내가 깨워야 하는데…" 하며 얼굴을 붉힌다 → 이번엔 둘이 같이 "꼬오—" 한다.
- 3화 「깃털이 따뜻해진 날」: 외치다 목이 간지럽다 → 깃털 끝이 붉게 달아오른다 → 친구들이 하나둘 문을 열고 나온다 → 더 크고 맑은 "꼬오—"가 마을에 퍼진다.

**길쭉** (anaconda)
- 1화 「쭈우우욱」: 바위 위에서 길게 늘어져 있다 → 돌봄이가 그 옆에서 몸을 쭉 편다 → 길쭉이 천천히 따라 한다 → "…천천히 해도 돼." 하고 눈을 가늘게 뜬다.
- 2화 「매듭 풀기」: 스트레칭하다 몸이 꼬여 버린다 → 부끄러워 눈을 질끈 감는다 → 돌봄이가 한쪽씩 살살 풀어 준다 → 둘이 웃으며 "쭈우욱" 한다.
- 3화 「더 길고 따뜻하게」: 몸이 근질근질하며 늘어난다 → 놀라 똬리를 튼다 → 마을 친구들이 몸 위에 올라 앉아 본다 → 넓은 몸으로 모두를 태우고 한 바퀴 돈다.

**놀빛** (peacock)
- 1화 「접힌 깃털」: 깃을 꼭 접고 돌아서 있다 → 돌봄이가 노을을 같이 본다 → "…조금만 봐도 돼." 하고 깃을 한 줄 펴 본다 → 노을색이 번진다.
- 2화 「칭찬 한마디」: 연습하다 깃이 꼬여 속상해한다 → 돌봄이가 "예쁘다"고 말해 준다 → 얼굴이 빨개져 깃을 확 펴 버린다 → 놀라서 둘 다 깔깔 웃는다.
- 3화 「노을 깃」: 깃 끝이 노을색으로 물든다 → 친구들 앞에 서기가 무서워 뒷걸음질 → 돌봄이의 손 그림자가 등을 받친다 → 천천히 깃을 펴서 마을이 환해진다.

### 반짝마을 (공부)

**토독** (mouse)
- 1화 「작은 노트의 첫 장」: 책 더미 사이에서 발가락만 보인다 → 돌봄이가 책을 꺼내 주자 눈이 반짝 → "토독, 이건 뭘까?" 첫 질문을 적는다 → 돌봄이가 같이 찾아 준다.
- 2화 「모르는 걸 모아 둔 노트」: 모르는 게 너무 많아 한숨을 쉰다 → 돌봄이가 "하나씩 알면 돼"라고 한다 → 하루 하나씩 답을 적는다 → 노트에 작은 별이 세 개 생긴다.
- 3화 「책장 위의 더 큰 세상」: 몸이 커져 높은 책장에 손이 닿는다 → 처음 보는 책을 꺼내다 쏟아진다 → 둥실이 조용히 같이 줍는다 → 가장 높은 칸의 책을 펴고 눈이 동그래진다.

**번득이** (deer)
- 1화 「뿔이 간질간질」: 뿔 끝에 작은 불꽃이 튄다 → 뭔가 떠올랐는데 말이 엉킨다 → 돌봄이가 천천히 들어 준다 → 정리된 생각을 노트에 적고 기뻐한다.
- 2화 「아! 잠깐 잠깐」: 번득이가 문제를 풀다 말고 딴 생각이 난다 → 돌봄이가 "하나만 끝내 보자"고 한다 → 끝까지 푼 문제에 동그라미가 쳐진다 → 뿔에 작은 번개가 한 번 지나간다.
- 3화 「번개가 환해지던 날」: 뿔이 한 가닥 더 자란다 → 너무 번뜩여서 책이 날아간다 → 토독과 끈기가 받아 준다 → 번득이가 "미안, 미안!" 하며 쑥스러워한다.

**둥실** (swan)
- 1화 「옆에 있을게」: 도서관 창가에서 조용히 앉아 있다 → 돌봄이가 옆에 앉는다 → 말없이 한참 있다 → "…옆에 있을게."가 처음으로 나온다.
- 2화 「따뜻한 차 한 잔」: 돌봄이가 졸려 한다 → 둥실이 차를 한 잔 건넨다 → 같이 후후 불며 마신다 → 졸음이 풀려 한 쪽을 더 읽는다.
- 3화 「구름 같은 날개」: 날개가 구름처럼 부풀어 오른다 → 몸이 둥실 떠올라 당황한다 → 돌봄이가 손을 잡아 준다 → 도서관 천장 위에서 마을을 내려다본다.

**끈기** (lion)
- 1화 「으르렁이 아니라 응원」: 갈기를 세우고 큰 소리를 낸다 → 돌봄이가 놀라 움찔한다 → "아니, 힘내라는 뜻이야!" 얼굴이 빨개진다 → 갈기를 같이 빗겨 준다.
- 2화 「끝까지 푼 문제」: 어려운 문제 앞에서 끈기가 포기하고 싶어 한다 → 돌봄이가 옆에서 한 줄만 더 가자고 한다 → 끝까지 풀고 처음으로 활짝 웃는다.
- 3화 「갈기에 금빛이 돌던 날」: 갈기 끝이 금빛으로 변한다 → 놀라 거울을 몇 번이나 본다 → 친구들이 "멋있다" 하자 쑥스러워 숨는다 → 숨은 채로 작게 "으르렁… 고마워."라고 한다.

### 냠냠마을 (식습관)

**오물** (turtle)
- 1화 「한 입 한 입」: 풀잎을 오물오물 먹고 있다 → 돌봄이가 와도 먹는 걸 멈추지 않는다 → 돌봄이가 천천히 같이 먹는다 → "…음, 맛있다." 첫 웃음.
- 2화 「천천히 먹는 비밀」: 오물이 돌봄이에게 꼭꼭 씹는 법을 알려 준다 → 서두르다 목이 막혀 기침한다 → 오물이 등을 톡톡 두드린다 → 천천히 먹으니 맛이 더 난다는 걸 알게 된다.
- 3화 「등딱지에 새싹」: 등딱지에서 초록 새싹이 돋는다 → 오물이 놀라 오래 가만히 있는다 → 친구들이 물을 조금씩 준다 → 새싹이 한 뼘 자라 모두 신기해한다.

**푸릇이** (hedgehog)
- 1화 「야식 냄새」: 밤에 뒤척이며 배고픈 소리가 난다 → 가시가 쭈뼛 선다 → 돌봄이가 따뜻한 물을 건넨다 → 한 모금 마시고 "푸릇… 참을 수 있어." 한다.
- 2화 「아침 이슬 샐러드」: 아침에 푸릇이가 샐러드를 쳐다만 본다 → 다래가 열매를 몰래 얹어 준다 → 한 입 먹고 눈이 동그래진다 → 가시가 보들보들해진다.
- 3화 「가시가 잎사귀처럼」: 가시 끝이 연두색으로 변한다 → 다칠까 봐 걱정하다 친구를 살짝 안아 본다 → 하나도 안 따갑다 → 푸릇이가 눈물이 글썽해 웃는다.

**다래** (badger)
- 1화 「찾았다!」: 덤불 속에서 불쑥 튀어나온다 → 돌봄이가 깜짝 놀라 웃는다 → 다래가 열매를 건넨다 → 같이 나눠 먹으며 숨바꼭질을 시작한다.
- 2화 「편식 친구 달래기」: 푸릇이가 채소를 안 먹는다 → 다래가 보물찾기처럼 숨겨 둔다 → 돌봄이가 찾고 푸릇이도 따라 찾는다 → 셋이 열매를 나눠 먹는다.
- 3화 「덤불 속의 큰 열매」: 다래의 코가 더 예민해진다 → 숲 가득 열매 냄새가 느껴진다 → 친구들을 이끌고 가장 큰 열매를 찾는다 → 모두 나눠 먹고 배가 빵빵해진다.

**쪼르** (platypus)
- 1화 「쪼르르 한 잔」: 물병을 들고 돌아다니며 모두에게 권한다 → 돌봄이에게도 한 잔 따라 준다 → 마시자 "잘했어!" 하며 박수 → 쪼르의 부리가 반짝인다.
- 2화 「물 2L 도전」: 쪼르가 하루 물 마시기 표를 만든다 → 돌봄이와 번갈아 체크한다 → 중간에 쪼르가 배불러 잠든다 → 돌봄이가 이어서 표를 채워 준다.
- 3화 「부리 끝의 새순」: 부리 끝에 새순이 돋는다 → 쪼르가 신기해서 눈이 모인다 → 오물과 푸릇이가 새순에 물을 주며 응원한다 → 부리가 더 길고 반짝이게 자란다.

**밤톨** (owl)
- 1화 「밥은 먹었니?」: 밤마다 식탁 위에 앉아 있다 → 돌봄이에게 먼저 안부를 묻는다 → 돌봄이가 "아직"이라 하자 허둥지둥 밥을 차린다 → 같이 먹고 졸음이 쏟아진다.
- 2화 「잔걱정 한 보따리」: 밤톨이 친구들의 식사를 하나하나 챙기다 지친다 → 돌봄이가 "밤톨도 먹어야지" 한다 → 못 이기는 척 앉아 먹는다 → 포근한 얼굴이 된다.
- 3화 「넓어진 날개 밥상」: 날개가 넓어져 더 많은 그릇을 올린다 → 균형을 못 잡고 흔들린다 → 오물과 쪼르가 함께 받쳐 준다 → 큰 밥상이 완성되어 모두 환호한다.

### 잔잔마을 (명상)

**퐁글** (koala)
- 1화 「후우, 퐁글」: 물방울 떨어지는 소리를 듣고 있다 → 돌봄이에게 숨 쉬는 법을 가르친다 → 서투르게 따라 하니 "잘하고 있어" 한다 → 물방울이 동그라미를 그린다.
- 2화 「마을의 맏이」: 퐁글이 모두를 챙기다 피곤해진다 → 돌봄이가 숨 고르기를 같이 해 준다 → 처음으로 맏이가 쉬어 본다 → "고마워" 작게 중얼거린다.
- 3화 「잔물결 코알라」: 털이 물방울처럼 맑아진다 → 몸이 반짝이며 가벼워진다 → 물멍이 "…예쁘네." 한다 → 퐁글이 얼굴을 가린다.

**물멍** (crocodile)
- 1화 「…아, 왔어?」: 개울 옆에서 한참 멍하니 있다 → 돌봄이가 옆에 앉아 같이 본다 → 해가 기울 때 "아, 왔어?"라고 한다 → 돌봄이가 웃는다.
- 2화 「감사 일기」: 물멍이 일기를 쓰는데 한 줄도 못 쓴다 → 돌봄이가 "오늘 개울 좋았지" 한다 → 물멍이 "개울 좋았다."를 쓴다 → 한 줄이 오늘의 전부가 되어 만족한다.
- 3화 「비늘이 은빛으로」: 비늘이 물빛으로 반짝인다 → 입가가 처음으로 올라간다 → 퐁글과 개울을 바라보다 같이 졸린다 → 개울 위로 작은 물방울이 튄다.

**보슬** (bat)
- 1화 「눈 감고 들어 봐」: 안개 속에서 날개만 보인다 → 돌봄이에게 귓속말한다 → 작은 이야기를 속삭인다 → 이야기가 끝나자 안개가 걷힌다.
- 2화 「자기 전 한 장」: 잠 못 드는 돌봄이에게 책을 읽어 준다 → 한 장 읽고 졸아 버린다 → 돌봄이가 조용히 덮어 준다 → 둘 다 스르르 잠든다.
- 3화 「안개 날개」: 날개가 부드러운 안개처럼 퍼진다 → 소리 없이 날아오른다 → 마을 위에 보슬비 같은 이야기를 뿌린다 → 작은 무지개가 뜬다.

**나울** (wolf)
- 1화 「나울나울」: 해변에서 파도 소리를 듣고 있다 → 돌봄이가 오자 꼬리를 흔든다 → 등에 태워 주겠다고 한다 → 파도를 따라 천천히 걷는다.
- 2화 「흔들려도 괜찮아」: 나울이 마음이 흔들린다고 말한다 → 돌봄이가 "괜찮아" 한다 → 등을 기대고 파도를 본다 → 마음이 잔잔해진다.
- 3화 「파도 갈기」: 갈기가 파도처럼 물결친다 → 어색해서 자꾸 만진다 → 보슬이 "멋져" 속삭인다 → 나울이 크게 웃으며 파도 위를 달린다.

### 소곤마을 (수면)

**새근이** (squirrel)
- 1화 「새근… 쿨…」: 인사하다 말고 졸기 시작한다 → 돌봄이가 놀라 꼬리를 덮어 준다 → 새근이가 꿈속에서 "고마워" 한다 → 꿈 조각 하나가 반짝인다.
- 2화 「꿈 모으기」: 새근이가 꿈을 모아 병에 담는다 → 돌봄이에게도 한 조각 나눠 준다 → 그날 밤 돌봄이가 좋은 꿈을 꾼다 → 아침에 둘이 꿈 이야기를 나눈다.
- 3화 「꼬리가 더 푹신하게」: 꼬리가 커다란 이불만큼 부푼다 → 새근이가 꼬리에 파묻힌다 → 초롱이 찾아 와 구해 낸다 → 모두 꼬리에 누워 별을 센다.

**초롱** (axolotl)
- 1화 「이제 불 꺼도 돼?」: 마을 길에 등을 켜고 다닌다 → 돌봄이의 화면 불빛에 눈을 찡그린다 → 돌봄이가 화면을 끈다 → 초롱이 안심하며 반짝인다.
- 2화 「등불 친구」: 초롱이 돌봄이를 마을 길로 안내한다 → 길마다 작은 별빛이 켜진다 → 돌봄이가 집에 닿아 인사한다 → 초롱이 "안녕, 좋은 밤" 한다.
- 3화 「별빛 아가미」: 아가미가 별빛으로 물든다 → 눈이 부실까 걱정하다 눈을 가린다 → 새근이가 "예뻐" 한다 → 밝기가 조절되어 부드럽게 빛난다.

**포근이** (orangutan)
- 1화 「잎사귀 침대」: 잎사귀를 겹겹이 쌓고 있다 → 돌봄이가 누워 본다 → "베개 높이는 괜찮니?" 정성껏 묻는다 → 돌봄이가 엄지를 든다.
- 2화 「같은 시간에」: 포근이가 매일 같은 시간에 눕는다 → 돌봄이가 따라 눕는다 → 포근이가 이불을 덮어 준다 → 둘이 같은 시간에 잠든다.
- 3화 「구름 이불」: 잎사귀가 구름처럼 부풀어 오른다 → 포근이가 몸이 커져 당황한다 → 마을 친구들이 한꺼번에 눕는다 → 커다란 침대가 완성되어 모두 웃는다.

**아라** (manta)
- 1화 「…꿈속에서 만나」: 깊이 잠든 돌봄이의 꿈에서 지나간다 → 한마디만 남긴다 → 아침에 돌봄이가 기억 못 하지만 기분이 좋다 → 베개 옆에 작은 별가루가 있다.
- 2화 「꿈 사이를 헤엄쳐」: 아라가 새근이의 꿈과 초롱의 꿈을 잇는다 → 돌봄이가 구경한다 → 아라가 처음으로 웃는다 → 꿈 사이에 작은 다리가 놓인다.
- 3화 「은하를 두른 날개」: 날개에 은하가 비친다 → 아라가 수줍어 꿈속으로 숨는다 → 친구들이 꿈에서 찾아 인사한다 → 아라가 "…또 만나."라고 한다.

### 알뜰마을 (절약)

**짤랑** (redpanda)
- 1화 「꼬리에 동전 한 닢」: 꼬리에서 동전 소리가 난다 → 돌봄이에게 보여 준다 → 하나 주워 건넨다 → 짤랑 소리가 마을에 퍼진다.
- 2화 「오늘은 하나 모았다」: 짤랑이 저금통을 만든다 → 돌봄이와 하루 하나씩 모은다 → 장난감이 사고 싶어 흔들린다 → 미루가 "내일 생각해 보자" 하고 둘이 참는다.
- 3화 「꼬리가 두둑해진 날」: 꼬리가 풍성해진다 → 동전이 한꺼번에 쏟아질까 걱정한다 → 든든이 말없이 받아 준다 → 짤랑이 "고마워"라고 한다.

**든든** (hippo)
- 1화 「…든든하지?」: 지갑을 꼭 안고 있다 → 돌봄이가 지갑을 보자 슬쩍 열어 준다 → 두둑한 걸 보고 "…든든하지?" 한다 → 돌봄이가 고개를 끄덕인다.
- 2화 「지갑 지키기」: 든든이가 낮잠을 자다 지갑을 잃을 뻔한다 → 돌봄이가 지갑을 지켜 준다 → 든든이가 깨어 "고마워" 한다 → 둘이 지갑을 같이 지킨다.
- 3화 「두둑한 배」: 배도 지갑도 둥글어진다 → 든든이가 쑥스러워 뒤돌아선다 → 친구들이 "더 든든하다" 한다 → 든든이가 처음으로 큰 소리로 웃는다.

**미루** (chameleon)
- 1화 「지금은 안 보여~」: 광고판 앞에서 몸 색을 바꿔 숨는다 → 돌봄이가 어디 있는지 찾는다 → 찾고 나서 "내일 생각해 보자" 한다 → 둘이 풍경을 보며 웃는다.
- 2화 「하루만 미루기」: 짤랑이 사고 싶은 걸 미루가 도와 하루 미룬다 → 다음 날 마음이 변한 걸 확인한다 → 짤랑이 사지 않고 웃는다 → 미루가 뿌듯해한다.
- 3화 「무지개 비늘」: 비늘이 무지개 색으로 반짝인다 → 미루가 처음으로 숨지 않고 서 있다 → 친구들이 박수를 친다 → 쑥스러워 색이 분홍으로 변한다.

**꼼꼼** (octopus)
- 1화 「하나, 둘…」: 다리 여덟 개로 장부를 쓰고 있다 → 돌봄이가 오자 한 줄 더 추가한다 → 계산이 맞아 기뻐한다 → 돌봄이가 박수를 친다.
- 2화 「합계가 안 맞아」: 계산이 안 맞아 꼼꼼이 속상하다 → 돌봄이가 같이 다시 센다 → 1원 차이를 찾아낸다 → 둘이 하이파이브를 한다.
- 3화 「여덟 다리의 장부」: 다리가 더 길어져 장부 두 권을 동시에 쓴다 → 혼자 놀라 먹물이 살짝 튄다 → 친구들이 같이 닦아 준다 → 장부가 깨끗이 마무리된다.

**싹둑** (shark)
- 1화 「싹둑! 안 사도 돼」: 전단지를 가위로 싹둑 자른다 → 돌봄이가 놀란다 → "이건 안 사도 돼" 부드럽게 말한다 → 둘이 남은 종이로 종이배를 접는다.
- 2화 「새는 돈 막기」: 싹둑이 돌봄이의 지출을 같이 본다 → 새는 곳을 찾는다 → 돌봄이가 놀란다 → 싹둑이 "괜찮아, 고치면 돼" 한다.
- 3화 「지느러미 가위」: 지느러미가 더 반짝인다 → 싹둑이 실수로 영수증을 자른다 → 차곡이 풀로 붙여 준다 → 싹둑이 미안해하며 웃는다.

**차곡** (jaguar)
- 1화 「차곡차곡」: 동전 탑을 쌓고 있다 → 돌봄이가 하나 올려 준다 → "쌓이는 게 보이니?" 묻는다 → 돌봄이가 끄덕인다.
- 2화 「은빛 달 아래」: 차곡이 달밤에 탑을 점검한다 → 돌봄이가 옆에서 지켜본다 → 한 닢씩 모은 이야기를 들려준다 → 달빛에 탑이 반짝인다.
- 3화 「은빛 점박이」: 무늬가 은빛으로 빛난다 → 차곡이 어색해 숨는다 → 짤랑과 든든이 찾아 와 같이 탑을 쌓는다 → 탑이 두 배가 되어 환해진다.

### 친구 관계도 (8쌍)

| 쌍 | 관계 | 계기 · 장면 |
| --- | --- | --- |
| 모닥이 ↔ 콩지 | 앞서가는 막내 + 뒤따르는 겁쟁이 | 줄넘기를 같이 넘다 서로 속도를 맞추게 된다 (콩지 2화 · 따끈마을 2장) |
| 토독 ↔ 둥실 | 질문쟁이 + 조용한 곁 | 둥실이 말없이 곁에 앉아 주면 토독의 답이 떠오른다 (반짝마을 2장) |
| 푸릇이 ↔ 다래 | 편식 걱정쟁이 + 열매 탐정 | 다래가 열매를 숨겨 푸릇이의 입맛을 열어 준다 (푸릇이 2화) |
| 퐁글 ↔ 물멍 | 숨 알려 주는 맏이 + 멍 때리는 순둥이 | 같이 개울을 보며 서로의 느림을 이해한다 (잔잔마을 2장) |
| 새근이 ↔ 초롱 | 먼저 잠드는 친구 + 불을 줄이는 친구 | 새근이가 먼저 누우면 초롱이 따라 등불을 줄인다 (소곤마을 2장) |
| 짤랑 ↔ 미루 | 사고 싶은 친구 + 하루 미루는 친구 | 미루의 "내일 생각해 보자"로 짤랑이 사지 않고 웃는다 (미루 2화) |
| 홰치 ↔ 밤톨 | 아침 알람 + 밤 파수꾼 | 아침과 밤을 번갈아 지키며 서로 안부를 묻는다 |
| 보슬 ↔ 새근이 | 잠들기 전 이야기꾼 + 잠꾸러기 | 보슬이 속삭이면 새근이가 가장 먼저 잠든다 |

마을 사이 친구는 홰치↔밤톨(따끈↔냠냠), 보슬↔새근이(잔잔↔소곤) 두 쌍이다. 이 쌍은 6마을 맺음 컷에서 나란히 선다.

### 검사 결과 (3부)
- 28종 × 3화 = 84화 모두 작성. 화마다 3 ~ 4컷 흐름("→"로 3 ~ 4칸)을 적었다.
- 친구 관계 8쌍 (기준 5쌍 이상). 악당 · 싸움 · 슬픈 결말 없음 (놀람 · 쑥스러움 · 걱정 정도의 작은 감정만).
- 이름은 1부의 새 이름만 썼고 원래 이름은 쓰지 않았다. 기존 작품의 이름 · 설정은 쓰지 않았다.
- 컷 수 점검: "- N화" 줄 84개 모두 "→"가 2 ~ 3개(= 3 ~ 4컷)임을 검색으로 확인했다.
