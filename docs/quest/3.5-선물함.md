# 3.5단계 — 선물함

## 목표
퀘스트 계열 보상을 **선물함에 넣고, 사용자가 "받기"로 받게** 바꾼다. 기획서 [`기획/2026-11-26-선물함.md`](../기획/2026-11-26-선물함.md) · 결정 D-89.
4단계(월간 배지 성실볼)보다 먼저 한다. 4단계 이후는 선물 한 줄을 넣기만 하면 된다.

- 즉시 지급 유지: 체크인 · 레벨업 · 기간 보너스 · 목표 완료 · 탐색 중복 · 운영 보정
- 선물함으로: 일일 · 주간 퀘스트(2 · 3단계 자동 지급을 바꿈), 월간 배지(4), 업적 · 깜짝(5 ~ 8)
