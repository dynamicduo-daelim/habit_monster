# 4단계 — 월간 배지

## 목표
그달 퀘스트 **20개 이상 완료** → 그달 배지 + 성실볼 1개 `[가정]`. 기획서 4-3장.
완료 개수 = 일일 · 주간 · 깜짝 · 조건 깜짝 모두 1개씩 (점수 합이 아니라 개수).

## 명세 · DB 변경 제안
- [ ] `GET /quests`에 월간 진행(이번 달 완료 수 / 20)
- [ ] `GET /quests/badges` — **획득한 배지만** (놓친 달은 보여 주지 않음)
- [ ] 테이블 `quest.user_monthly_badge`(사용자, 월, 획득 시각, 유니크 (사용자, 월))
- [ ] 성실볼 지급 경로 확인 (상점 · 인벤토리 모듈의 볼 지급 방식과 사유 코드)
- [ ] 시드 `quest_monthly_target = 20`

## 서버 할 일
- [ ] 퀘스트 완료마다 이번 달 완료 수 확인 → 20개째에 배지 + 성실볼 (1회만)
- [ ] 월 경계는 `BusinessDates.monthStart()`

## 테스트
- [ ] 19개 → 없음, 20개 → 배지 1회, 21개 → 추가 없음, 달 바뀜

## 프론트 전달
- [ ] 월간 진행 표시 · 배지 보관함 화면 · 배지 아이콘(아트 필요)

## 완료 기준
- 배지 · 성실볼 1회 지급 테스트 통과, 기록 갱신. **여기까지가 1차.**

## 정할 것
- 성실볼 1개 `[가정]` 확정 여부
