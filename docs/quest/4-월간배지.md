# 4단계 — 월간 배지

## 목표
그달 퀘스트 **20개 이상 완료** → 그달 배지 + 성실볼 1개 `[가정]`. 기획서 4-3장.
완료 개수 = 일일 · 주간 · 깜짝 · 조건 깜짝 모두 1개씩 (점수 합이 아니라 개수). **선물을 받았는지와 무관하게 "완료"로 센다.**

**3.5단계(선물함) 뒤에 한다** (D-89). 성실볼은 선물함으로 보낸다 — 가방에 바로 넣으면 퀘스트 완료 시점(지갑을 이미 잠금)에 가방을 잠가 잠금 순서(`inventory → wallet → quest`)를 거꾸로 밟고, 가방에 구매 말고 들어오는 길도 없었기 때문 (11-26 검토).
