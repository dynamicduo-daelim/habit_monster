# 2단계 — 퀘스트 기반 + 일일 퀘스트

## 목표
`quest` 모듈의 뼈대(테이블 · 이벤트 · 골드 지급)를 만들고, 일일 퀘스트 4개를 돌린다.
기획서 4-1장 · 7장.

| # | 퀘스트 | 판정 | 보상 |
| --- | --- | --- | --- |
| A1 | 오늘의 기록 | 체크인 첫 제출 (결과 무관) | 3G |
| A2 | 쓰다듬기 | PET 1회 이상 | 1G |
| A3 | 뽀모도로 | 뽀모도로 기록 1건 (집중 ≥ 10분 `[가정]`), **시간 습관 없으면 잠금** | 1G |
| A4 | 말 걸기 | `GET /monsters/{id}/line` 1회 | 1G |

## 명세 변경 제안
- [ ] `GET /quests` — 오늘의 일일(이 단계) · 주간 · 깜짝 · 월간 진행(뒤 단계에서 채움), 칸마다 `status`(`IN_PROGRESS` · `DONE` · `LOCKED`) · 진행도 · 보상 · 잠금 안내
- [ ] 완료 시 지급은 자동 (수령 API 없음). 응답에 방금 받은 골드를 알릴지 정하기
- [ ] 말 걸기는 GET인데 기록을 남기게 됨 → 명세에 "부수 효과: 퀘스트 진행" 적기 (또는 POST로 바꿀지 — 앱 변경 필요)

## DB 변경 제안
- [ ] 새 스키마 `quest`: `quest_def`(마스터: 코드 · 종류 DAILY/WEEKLY/SURPRISE/CONDITIONAL · 조건 코드 · 목표 횟수 · 보상) · `user_quest`(사용자 · 기간 키 · 퀘스트 · 대상 몬스터 · 진행도 · 상태 · 지급 여부, **유니크 (사용자, 기간 키, 퀘스트)**)
- [ ] `wallet.ledger_reason`: `QUEST_DAILY` (뒤 단계: `QUEST_WEEKLY` · `QUEST_SURPRISE` · `QUEST_MONTHLY` · `QUEST_ACHIEVEMENT`) — `ref_id` = `user_quest.id`
- [ ] 말 걸기 기록: `monster.talk_log`(user_monster, 날짜, 시각) 또는 상호작용 로그 하나로 (7단계와 같이 설계)
- [ ] 시드: `quest_def` 4줄 · `balance_config` `quest_enabled` · `quest_daily_gold_*` · `quest_pomodoro_min_minutes`
- [ ] 잠금 순서에 `quest` 추가 (`… inventory → quest → wallet`, D-85) — 스키마 머리말
- [ ] `verify.sql` · 마이그레이션 SQL

## 서버 할 일
- [ ] 이벤트 클래스 (`CheckinSubmitted` · `AffectionGiven` · `MonsterTalked` · `TimerFinished`) — 보내는 쪽 모듈에 두고 `ApplicationEventPublisher`로 발행
- [ ] `quest` 패키지: 저장소(`JdbcClient`, package-private) · `QuestService`(오늘 퀘스트 생성 — 그날 첫 조회 때, 스케줄러 없음) · `@EventListener`(진행도 +1, 다 채우면 지갑 모듈로 지급)
- [ ] 이벤트가 먼저 오고 조회가 나중일 수 있음 → 리스너도 "오늘 줄이 없으면 만든다"
- [ ] A3 잠금: 시간 습관(측정 단위 "분") 보유 여부
- [ ] `quest_enabled = false`면 생성 · 진행 모두 건너뜀
- [ ] `GET /quests` 컨트롤러 · 탈퇴 정리(`WithdrawalStep`)
- [ ] 체크인 다시 체크(PUT)는 진행에 영향 없음

## 테스트
- [ ] 생성: 첫 조회에 4줄, 두 번 조회해도 4줄
- [ ] 진행 · 지급: 각 행동 후 `DONE` · 골드 1회만(원장 유니크) · 같은 행동 반복해도 1회
- [ ] A3 잠금 · `quest_enabled` 끄기 · 날짜 넘어가면 새 줄
- [ ] 퀘스트 오류가 나면 원래 행동도 롤백되는지 (같은 트랜잭션 확인)

## 프론트 전달
- [ ] 홈 퀘스트 진입점 · 퀘스트 목록 · A3 잠금 카드("시간 습관을 등록하면 도전할 수 있어요" + 습관 추가로 가는 버튼, 닫기 가능)
