# 7단계 — 조건 깜짝 퀘스트

## 목표
사용자 상태를 보고 "이럴 때만" 뜨는 퀘스트. 기획서 4-5장. 하루 최대 1개, 깜짝 합계 주 3개 한도에 포함, 개당 3G.
트리거는 **불리한 상태를 벌하지 않고, 소원해진 몬스터를 챙기는 방향**.

## 먼저 필요한 기록 (지금 없음)
- [ ] 몬스터별 마지막 상호작용 시각 (외로운 ○○ — 3일)
- [ ] 파트너 변경 이력 (오늘의 파트너)
- [ ] 말 걸기 이력 (파트너의 한마디 — 2단계 기록 재사용)
- [ ] 포획 실패 (8단계 업적 "아쉬운 이별"도 씀)

## 트리거 (기획서 표 12종)
이미 데이터가 있는 것부터: 호감도 LOW · 진화 1레벨 전 · 골드 300G 이상 · 필드 5마리 미만 + 가방 · 탐색 꽝 2번 · 도감 미발견 · 같은 카테고리 3마리 · 필드 2마리 이상(DRAG) · 해금권 있음.
새 기록이 필요한 것: 3일 못 쓰다듬은 몬스터 · 안 써 본 파트너 · 파트너 3일 말 걸기 없음.
